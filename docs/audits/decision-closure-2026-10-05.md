## Real local Codex Server acceptance

`scripts/test-decision-regressions-live.ts` used `gpt-6.1-sol` with low reasoning. The production Memory pipeline processed a generated 31,264-character Coding conversation in three ranges, after complete overview coverage. Nine actual model queries included independent review and a separate rubric check. All five fixed criteria passed: persistent monorepo constraint, client/Central boundary, Monday correction superseding Friday, unperformed physical tests distinguished from assistant reports, and generated-test privacy. The personal-memory recipe published zero cards for this project case; this is recorded as an allowed admission result, not a nonzero integration result. Completed work did not replay model queries.

`scripts/test-memory-utility-live.ts` separately used the same local provider with four actual model queries: integration, independent review, history query, and empty-history control. It published one consolidated card, applied one version-bound supersedes relation, and delivered both original citations. Random generated gate/tag values prevented answering from model pretraining. The returned `releaseAllowed` function passed four executable cases. The empty-history query returned unknown/null with no code or citations. Original deletion made the dependent card unavailable (404), and a completed tick replayed no model queries. Fixture seeds are owner-authored state, not claimed as live model extraction.

`scripts/test-codex-provider-live.ts` also exercised the production local provider: catalog, probe, feature preset/model override, context retrieval, original evidence and a cited answer.

These targeted live cases do not retroactively validate earlier model judgments, establish general model quality, or complete the broader five-experiment research proposal. Model choices and judgments may vary on other inputs. Physical devices, live ASR and installed third-party app/version compatibility are not measured by these generated tests.

## Release and upgrade boundary

Central, Desktop and Android release independently as 0.0.81. PR #62 requires storage epoch 3 and removes legacy compatibility paths. Back up older profiles using the matching older binary; use a fresh epoch-3 profile or the explicit reset workflow. This release does not migrate or automatically reset an older archive. The reset workflow is destructive and requires the owner's deliberate selection.
