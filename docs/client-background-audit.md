# Android / mac 客户端 UI 阻塞盘点

范围：Android 原生 Activity 的创建、按钮、文件选择结果和状态刷新；mac Electron 主进程 IPC、图片处理、队列与来源存储，以及 renderer 轮询。这里的“后台”指离开 UI / Electron 主线程；网络异步等待本身不会阻塞该线程。

## 已修改的路径

| 客户端 / 操作 | 原来的阻塞点 | 当前执行与 UI 更新 |
| --- | --- | --- |
| Android 首页启动、返回与切换设置页 | UI 读取配置、解密凭据；返回页面重复读配置 | 首次配置后台读取；页面使用已提交配置快照，后台状态刷新送入新快照；旋转前先保留内存中的未保存设置 |
| Android 随手记 | 打开页读取加密草稿；每次输入同步加密 / fsync；保存时等队列锁 | 独立串行写入器，一次正在写入加一次最新待写；保存排在草稿写入之后；500 ms 读取内存进度，关闭页面后已接受的写入继续完成 |
| Android 保存设置、绑定本机资料 | 保存前同步统计待发资料、读取已准备的草稿 | 后台预检查；提交仍校验原配置，保留保存期间用户在其他页面的新输入；预检查被锁住时旋转页面，已确认的提交仍继续完成 |
| Android 连接中央节点、导入邀请 | 页面加载 / 返回时解密凭据；读取“上次测试状态”也会间接解密；联网时只有静态提示 | 后台加载已保存连接及状态，返回页面重新读取；文件解析结果通过任务完成状态交给 UI；连接确认每 500 ms 显示阶段和耗时 |
| Android 开始 / 停止采集 | 配置校验、状态持久化、统计日志写入 | 工作线程处理持久化；立即暂停生产者，停止意图阻止较早的设置操作重新启用采集 |
| Android 已安装应用选择 | PackageManager 查询、读取应用标签、排序 | 后台查询，选择框先显示加载状态 |
| Android 文件 / 日历来源连接、编辑、移除 | 回调内解密来源配置、清缓存、保存、释放 URI 授权、调度扫描 | 后台执行；编辑任务禁止重复提交；原有 2.5 秒来源状态刷新继续运行；关闭页面后排队清理未保存的文件授权 |
| Android 统计重置 / 导出 | 重写统计账本、打开文档提供者、写 JSON | 后台执行，500 ms 显示阶段与耗时 |
| Android 模型导入、重载、诊断导出 | 重载直接调用；导入 / 导出虽已有裸线程但缺少统一状态与重复操作保护 | 接入生命周期感知任务，定时读取状态，完成 / 失败明确显示 |
| Android 更新设置、安装准备、取消、恢复检查 | SharedPreferences commit、安装会话查询 / 操作在 UI | 后台运行；取消使用独立执行器，原下载字节状态仍每秒更新 |
| Android 存储迁移 / 同步恢复 | 迁移已在后台但只有静态提示；恢复入口可能同步读队列 | 迁移报告原目录验证、逐文件复制 / 校验、目标完整性验证；500 ms 刷新；恢复操作后台提交 |
| Android 去重页面 | 进入批量去重、去重诊断页面时读取 / 解密配置 | 配置移入既有执行器；保留 WorkManager 批量任务及 700 ms 进度轮询 |
| mac 队列备份导入 / 导出 | 主线程一次性解析 / 序列化最多数百 MiB JSON，图片 Base64、SHA-256 校验 | archive worker 解析、校验、导出；导入使用私有暂存目录，全部格式、冲突、容量预检通过后逐条提交；报告记录数 / 图片数 |
| mac 缩略图 / 原图浏览 | 主线程 nativeImage 解码、缩放、JPEG 编码；分页克隆所有 OCR 正文 | preview worker 处理编解码与排序；主线程仅复制本页正文；详情按 ID 读取 |
| mac 采集图像处理 | 主线程逐像素遮罩、BGRA → RGB、JPEG 编码 | image worker 处理；保留遮罩在模型 / OCR / 入队之前的顺序，图像仅在本机内存中流转 |
| mac 来源持久化 | 大来源状态 JSON 解析 / 序列化、对整个待发正文深拷贝 | source worker 处理 JSON 读写；更新使用不可变浅快照，分批让出事件循环；保留先持久化再发送与 ACK 规则 |
| mac 状态统计 / 长操作提示 | 状态读反复序列化所有队列元数据；多个定时请求可重叠 | 记录字节缓存和统计快照；后台操作注册表防重复提交；每秒轮询阶段、实际计数和耗时；状态请求最多一组在途，来源轮询不因同步任务停止 |

四条 mac 工作线程通道分别承担备份、采集图片、浏览预览和来源 JSON，防止备份解析排在图片任务前面。每条通道最多接受 32 个在途请求，线程退出会拒绝未完成请求，后续可以重试。`sharp` 从已有开发依赖增加为桌面运行依赖。

## 已在后台执行，保留的路径

- Android 采集记录分页、图像加载、原图解码、日志分页、统计目录遍历、去重诊断图片、WorkManager 下载 / OCR / 批量去重 / 同步恢复。
- mac 网络请求、异步文件 I/O、存储迁移逐块复制、更新下载；OCR、系统日历和应用枚举使用原生助手子进程；模型推理使用已有独立进程。
- 中央网页在独立 renderer 内通过异步请求加载数据。

## 必须保留在 UI 侧的操作

视图创建 / 布局、绘制、系统权限与文件选择器、导航、启动原生系统 UI，以及 Electron 的窗口 / 菜单、屏幕源请求和 NativeImage 像素交接。后台线程不会直接修改 Android View。UI 轮询只读已产生的状态，不在轮询回调里扫描文件、等待任务或执行图像编解码。

小型输入校验、用户配置的精确过滤规则、受限条目的 JSON 编码和进程内对象复制仍存在；本次没有把所有同步语句都改成线程消息。重点是无界或明显耗时的磁盘 / 密钥 / 系统提供者等待和大批量 CPU 工作。

## 验证

- mac：合并 0.0.18 主分支后，全仓类型检查、196 项桌面单元 / 集成测试通过；实际 Electron UI 生成夹具回归通过，包括导航、随手记、来源、图片浏览分页、存储迁移、失败回滚和恢复保护。0.0.19 arm64 安装包构建与签名验证通过，包内工作线程和图片依赖、旧队列 / 草稿保留的生成夹具验证通过。
- Android：0.0.19 开发版与测试 APK 编译、127 项 JVM 单元测试通过；release / development lint 均为 0 errors。API 35 arm64 模拟器的 22 项选定回归通过，覆盖后台任务生命周期、队列 / 设置锁竞争、导航、加密草稿恢复、连接页、配对后继续编辑、更新页、来源页和生成文件 / 日历提供者。
- 新测试包含：主线程心跳、重复提交、工作线程退出 / 重试、备份冲突前不写入、真实 JPEG 遮罩与 BGRA 颜色、输入合并与保存顺序、暂停停止轮询、销毁后不更新旧 View。
- 使用生成图片、生成笔记和临时配置；未执行真机采集、真实个人截图或在线模型验证。未测量真实大存量设备的性能百分位，不能将夹具通过视作所有机型的 ANR 保证。
