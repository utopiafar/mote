# 中央网页登录与设备配对

中央节点同时提供 API 和 Web 管理界面。浏览器登录后查看资料、管理设备和模型；macOS、Android 客户端负责本机采集、隐私设置与同步。Cloudflare Tunnel 只提供可访问的 HTTPS 入口。

## 管理网页

打开节点地址，点击「登录 Mote」，输入部署时生成的管理访问令牌即可。管理请求固定使用当前网站的 API，没有中央节点连接或角色选择配置。管理令牌用于身份验证，不决定服务角色。点击设备、资料库或设置等页面时，未登录会打开登录框；成功验证后继续进入刚才选择的页面。

管理令牌可以用 `node scripts/mote.mjs token --profile dev` 获取；其他部署使用对应 profile 和 home 参数。网页端验证后签发独立、可撤销的完整客户端会话，默认只保存在当前标签页；也可选择 1 天、7 天或 30 天。服务端与本地期限共同生效，浏览器不能延长来自原生客户端的授权期限。退出登录清除本地凭据和显示中的资料，并撤销当前客户端凭据；部署的 `MOTE_TOKEN` 保持不变。

Mac、Android 和浏览器内的所有中央功能共用各自客户端的统一登录。配对、手动令牌或浏览器授权都能获得与节点令牌相同的完整权限，已登录客户端不会再要求填写另一份管理 Token。MCP 使用独立的受限授权。Mac 打开中央网页时通过短期、一次性代码接续登录，不把长期 Token 放进 URL；客户端和由其打开的网页共用该连接的撤销状态。未登录客户端也可以在浏览器中确认登录。详见 [统一客户端登录方案与影响范围](client-login-unification.md)。

服务端本身就是中央节点。管理其他服务时，应打开该服务的网址并登录。旧版保存的其他节点会话不再恢复，避免将旧令牌发送给当前服务；开发前端通过现有同源 API 代理访问开发服务。

## 连接设备

登录后打开「设备 → 扫码连接设备」，确认「本服务供设备访问的地址」指向当前服务，填写连接名称，再点击「生成设备二维码」。已配置公开地址时优先填入该地址。

Android 在连接设置中扫码；Mac 可导入二维码图片。两端也可以粘贴邀请或导入 JSON。邀请有效期 10 分钟，只能领取一次，生成的是可撤销的独立客户端凭据，拥有与节点令牌相同的完整权限，不包含部署的根令牌。需要重新授权已有设备时选择原设备身份。取消邀请使旧二维码失效，撤销已授权连接会阻止该连接的后续访问与同步，已有归档保留。

仅用本机 loopback 地址时，手机访问的是手机自己。跨设备使用 HTTPS 地址，或明确配置开发端口转发。

## 页面错误

未登录与节点离线分别提示。一个数据接口失败不再阻塞其他独立页面：例如回顾接口失败后仍能进入设备、资料库和连接授权。需要节点状态的总览、问答等页面会显示加载或错误及重试入口。
