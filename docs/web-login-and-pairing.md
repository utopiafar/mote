# 中央网页登录与设备配对

中央节点同时提供 API 和 Web 管理界面。浏览器登录后查看资料、管理设备和模型；macOS、Android 客户端负责本机采集、隐私设置与同步。Cloudflare Tunnel 只提供可访问的 HTTPS 入口。

## 管理网页

打开节点地址，点击「登录 Mote」，输入部署时生成的管理访问令牌即可。管理请求固定使用当前网站的 API，没有中央节点连接或角色选择配置。管理令牌用于身份验证，不决定服务角色。点击设备、资料库或设置等页面时，未登录会打开登录框；成功验证后继续进入刚才选择的页面。

管理令牌可以用 `node scripts/mote.mjs token --profile dev` 获取；其他部署使用对应 profile 和 home 参数。网页端登录默认只保存在当前标签页会话；在用户设置的会话页面（`#/preferences`）或登录窗口中，也可以选择 1 天、7 天或 30 天。持久化会话到期后网页会清除本地管理凭据并要求重新登录，退出登录始终立即清除。这个期限只控制网页端本地保存，不修改中央节点的 `MOTE_TOKEN` 或采集端凭据。恢复会话时先验证管理权限，退出登录会清除凭据和显示中的资料。此版本没有新增多用户角色或自定义页面权限，管理令牌访问管理页面，采集凭据仅使用原有设备权限。

服务端本身就是中央节点。管理其他服务时，应打开该服务的网址并登录。旧版保存的其他节点会话不再恢复，避免将旧令牌发送给当前服务；开发前端通过现有同源 API 代理访问开发服务。

## 连接设备

登录后打开「设备 → 扫码连接设备」，确认「本服务供设备访问的地址」指向当前服务，填写连接名称，再点击「生成设备二维码」。已配置公开地址时优先填入该地址。

Android 在连接设置中扫码；Mac 可导入二维码图片。两端也可以粘贴邀请或导入 JSON。邀请有效期 10 分钟，只能领取一次，生成的是独立采集凭据，不包含管理令牌。需要重新授权已有设备时选择原设备身份。取消邀请使旧二维码失效，撤销已授权连接会阻止后续同步，已有归档保留。

仅用本机 loopback 地址时，手机访问的是手机自己。跨设备使用 HTTPS 地址，或明确配置开发端口转发。

## 页面错误

未登录与节点离线分别提示。一个数据接口失败不再阻塞其他独立页面：例如回顾接口失败后仍能进入设备、资料库和连接授权。需要节点状态的总览、问答等页面会显示加载或错误及重试入口。
