- 全工作区 TypeScript 类型检查通过；共享库、中央节点、Web 构建通过。
- 中央新增接口覆盖日期边界、分页、缩略图尺寸、加密图片、设备凭据隔离、撤销凭据、OCR 状态筛选、空文字与旧记录状态。
- OCR 补写覆盖失败后成功、重复确认、原始 pending 记录重试、检索索引刷新、已完成文字防覆盖、导出到新资料库后重投递、已删除记录防复活。
- Mac 和 Web 的 Electron 合成界面检查覆盖本机与中央记录、日期切换、分页末页、缩略图、原图和 OCR 详情；反馈入口仅校验目标 URL 和预填字段。
- Mac 原生构建与 Swift 窗口身份合成检查通过；队列测试覆盖字节配额恰满、缩小配额后补做、永久冲突跳过单条及补写真实载荷计量。
- 隐私网关 22 项合成检查通过。端到端检查通过：合成 Mac/Android 图片进入加密去重资料库，经测试模型与实际工具调用流程检索，读取图片并完成便携归档导出导入。
- 更新、部署回滚与安全测试 15 项通过：验证隔离中央节点更新/回滚、资料与凭据保留、签名及资产校验、路径和备份安全。
- MCP stdio、连接格式、隔离配置、隧道管理、模型资源安装脚本和 Python 归档脚本检查通过；未连接真实 Cloudflare 账户或调用外部模型。

## Android 模拟器

Android 的 65 项 JVM 测试通过，release/development lint 均无错误，debug/development APK 与 instrumentation 构建成功。Lint 仍报告已有警告，不宣称零警告。

专用 API 35 模拟器以只读、不保存快照的方式运行，最终 7 项测试全部通过。4 项导航回归包括真实单次触摸；3 项 OCR、浏览及 HTTP 联调回归只使用生成图片。验证未接电保留遮挡后的图片、关闭可选元数据仍保留 pending 状态、停止采集后接电补做 ML Kit OCR、21 条记录按天分页和文字详情，以及错误 OCR 确认保留本机数据、匹配确认后清理。

## 验证边界与发布

没有执行 Android 真机采集、实际耗电测量、个人屏幕测试或真实视觉安全模型效果评估。模拟器识别测试使用本地 ML Kit；端到端查询模型为本机 fixture，不能替代真实模型质量评估。

发布流水线会重新执行项目检查、构建并签署两种 Android APK、打包 Mac、构建服务器镜像并生成签名更新清单；只有所有发布任务成功，才公开完整 Release。更新时先升级中央节点，再升级客户端。
