## Retained intermediate failures

Earlier logs remain local. They include startup EPERM, an initial strict-schema
bootstrap mismatch, a missing canonical object-size join, a fixture replacement
that omitted M03 `previousRevision`, an attachment descriptor with unsupported
`sizeBytes`, test JSX in a `.ts` file, an async assertion syntax error, and a
literal MIME outside the published pattern. A byte-reader observer also caught
an unrelated automatic extraction while the fixture still enabled processing;
the deterministic fixture isolation above addresses that observation. These
failures are not relabelled as passes.

The first complete 102-original fixture used repeated HTTP workers and took
186 seconds for that case. It passed, but exceeded the repository's per-case
120-second budget. The final fixture uses the real M03 batch publisher for the
remaining page and retains HTTP byte/hash verification; it does not enlarge a
test timeout or skip the case. An initial queue-neighbor invocation omitted the
Web JSX config and failed; the correctly configured invocation passed 4/4.
