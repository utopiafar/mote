# 0.0.75 Agent 视角验证

本版把 Agent 视角作为独立 Cordis 功能放到中央首页。浏览器与接口验证只使用临时生成资料库、生成来源、生成长文、生成记忆及合成追踪记录，没有读取个人资料库、采集或发送个人截图，也没有调用真实模型。

## 行为与权限

- 前端 `mote.agent-view` 贡献首页卡片和按需加载的 `#/agent` 页面；通用 `home` 槽与页面注册随 Cordis 插件卸载撤销。旧 `#/system/agent` 仍可导航。
- 服务端功能通过现有 Cordis FeatureHost 安装；卸载后接口返回 feature unavailable。目录、正文、Memory 与正式资料复用查询 Agent 的只读 Reader。
- 根目录没有全库统计扫描。来源与各层使用游标，来源条目只返回 400 字符预览；原文单页最多 4,000 字符，正式资料读取保持选定版本与范围。Memory 支持原文只传实际核验的区间。
- 新对话预览复用 openingMemories、buildContextEnvelope、systemInstructions 和工具声明。最多五条记忆线索；无模型调用、无对话压缩、无隐式图片读取。
- 实际轨迹只解析已记录的协议事件。缺失、过期或截断不会用当前数据补造；正文区间来自当时的工具返回。目录浏览和手动展开均不冒充一次模型读取。

新增五个接口/前端检查覆盖根目录不扫描、完整来源分页、范围绑定、预览与真实组装契约一致、正文分页、短预览、支持原文区间、插件撤销、截断/错误记录，以及只从成功工具结果读取实际文字。

## 浏览器与性能

`node_modules/.bin/electron scripts/test-agent-view-browser.cjs` 启动独立临时中央服务。17 个生成来源、生成长文和一条生成 Memory 覆盖首页入口、来源两页、来源文件、原文第二页、新对话记忆预览、实际输入运行选择、旧链接和 430 像素布局。脚本还要求没有前端 console error。

性能使用十个独立浏览器 session，清空 HTTP 缓存，通过不加载应用代码的生成 bootstrap 页面预置已登录所有者状态，再首次导航生产构建的 Agent 页面。计时从 navigation 开始，等待三个根目录条目加载并经过两次 requestAnimationFrame 后读取 performance.now，包含认证、脚本加载、目录请求及绘制帧等待。1360 × 1000 的 Electron Chromium 与回环 HTTP 下，最慢 **409ms**，全部低于 **500ms**。这轮与完整本地检查同时执行；不是远程网络、任意硬件或大库的延迟保证。页面首屏只有 configuration、status、devices、agent-view/catalog 四种 API 请求，没有 Memory、文件正文或运行轨迹请求。

本地截图和逐次指标保存在忽略目录 `.mote/agent-view/`，不入源代码。最初的 DOM 就绪探针最慢约 97ms；发布验收采用上面的绘制帧后指标，不能把两者混为同一个指标。生成 bootstrap 和条目标题断言修正后，完整旅程通过。
