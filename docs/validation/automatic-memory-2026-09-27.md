# Automatic Memory iteration — 2026-09-27

Baseline: 0.0.71 (`6fb085c`), implementation branch `codex/automatic-memory`. The broader Mote Goal remains active and incomplete. This record separates the current implementation and checks from earlier releases.

## Implemented behavior

Reviewed Memory becomes effective after the host validates evidence and versions. Valid supersession is applied in the same transaction; historical claims remain readable. User corrections, deletion and evidence navigation remain available without a separate confirmation step. Unreviewed legacy rows remain identifiable and can be reprocessed.

A Memory deletion keeps the original material and records the rejected conclusion with its original evidence identity. Rephrasing, recipe changes and transport identity changes do not themselves supply new evidence. A separate model comparison decides whether a candidate repeats the rejected conclusion and whether genuinely new evidence supports reconsideration. The host checks identity, permissions and commit races. This is not a semantic keyword filter or a ban on unrelated claims from the original.

Queries can opt into bounded, freshly checked original ranges alongside a Memory detail. Only delivered original ranges grant citation authority. See [the disclosure contract](../memory-source-disclosure.md).

## Independent review and live generated validation

Independent review reproduced and then verified fixes for Material deletion authorization, importing a newer deletion into an older archive, retaining suppression after partial evidence cleanup, and clearing private deletion text on explicit source forget. Mixed-source rules are erased when either source is explicitly forgotten, including after pruning that source's originals, restarting and restoring an archive. Source identities are retained separately from original text; old records whose removed source history cannot be recovered are marked incomplete. Deletion metadata participates in the storage quota. Queued review is denied before any model call if a rule's original dependencies lose permission. Generated lifecycle and source-pipeline checks cover these paths.

The first full check failed on two old assertions that expected reviewed cards to remain `proposed`; those expectations were updated to `published` without removing recovery assertions.
