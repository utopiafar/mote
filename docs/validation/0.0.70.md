Date: 2026-09-26. This release implements the review decisions about collection retries, formal-material admission, query pagination, and feature ownership. ## Validation boundaries

No physical-device capture, real personal screenshot or live provider/model-quality test was performed. UI images are rendered from generated fixtures. Model integration tests exercise actual Harness/Codex transports against fixture providers/processes; they do not establish live-model quality.

GitHub Release builds and verifies Mac DEV and signed Android DEV packages. The release workflow is separate from the local test suite. This DEV release does not publish a server archive, GHCR image, or signed update manifest; central nodes use the tagged source. HTTP feature topology remains fixed at startup; this change does not add arbitrary hot plugin installation.
