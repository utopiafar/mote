# 0.0.76 录音插件验证

## 实际覆盖

本版实现飞书妙记、钉钉听记 Provider 与公共同步宿主，复用现有连接器登记、持久 ExecutionEngine、原件资产、Material 和来源 Memory 配方。新增插件的来源能力、所有者接口、设置卡片元数据及释放都经过生成夹具验证。模型使用只读证据，平台内容不决定可执行操作。

## 生成夹具与浏览器

新增检查包括：

- 逐字稿 → 原件/切片 → 完整 Material → 自动 Memory，厂商转写路径不产生 ASR 工作。
- 分页去重、27 天拆窗、精确范围和游标环；未知原始录制时间不伪造成库内创建时间。
- 厂商列表删除后中央留存；重复扫描、断开/重启不重放已完成的模型工作。
- 音频失败与文本/Memory 独立；跨重启保留失败收据，补齐音频不重复调用模型；正文更正保留前后版本的音频。
- 读取期间账号变化阻止发布，暂停撤销在途授权；换账号后必须重新启用范围。
- 原始文本、长段落、说话人标签、推导时间与无时间钉钉段落；不完整产物及目录逃逸拒绝。
- 所有者授权的媒体 HTTP 路由逐字节正确，未授权不能读取。68 MiB 录音媒体超过普通上传限额后仍能完整导出/导入，普通上传保持 64 MiB 限额。
- 2,500 个切片全部进入原件、完整 Material 和 Memory 输入。修复每切片复制整份转写导致的平方级开销；覆盖预算超限仍显式标部分。
- 第三方录音插件贡献设置与能力，释放时卸载来源能力；界面从登记表发现第三方 Provider。

`node --import tsx --test apps/server/test/recordings.test.ts apps/server/test/connectors.test.ts apps/web/test/recordings-settings.test.ts` 的 29 个新增/既有相关检查通过。大媒体归档另以 `apps/server/test/archived-files.test.ts` 验证。

`node_modules/.bin/electron scripts/test-recordings-browser.cjs` 使用独立临时中央节点和生产 Web 构建，全部账号、转写和音频都是生成内容；模型调用为零。验证连接已授权账号、显式启用、后台文本及音频入库、最近归档、点击后才加载音频、浏览器 WAV 解码（1 秒）、430 像素无横向溢出及无控制台错误。截图与结果位于忽略目录 `.mote/recordings/`，不入源码。

## 真实飞书账号与模型

经用户明确授权，`scripts/recordings-live.ts` 复用本机原生 Lark CLI 1.0.85 用户身份和现有 Memory 模型设置；使用 gpt-6.1-sol / Codex 原生协议。仅选择一个可访问的真实妙记样本，没有全量导入个人历史，也没有采集截图。

- 搜索、读取基础信息、CLI 产物导出、转写规范化与后台音频下载完成，持久工作没有剩余失败或等待。
- 完整 Material 为 189 块，覆盖 complete。原始转写整体保留，并有细粒度证据与出处。
- 音频为 10,237,356 字节 Ogg/Opus，SHA-256 校验通过；ffmpeg 整段解码成功，ffprobe 时长 1,263.56 秒。
- 使用录音专用提取与独立复核配方，首次运行 20 次模型请求，产出 28 条有原始证据的上下文 Memory。全部为 observation，归属为 observed/third_party；没有把匿名说话人写成用户个人事实。
- 重复同步、重启后的复测均保持已有 28 条结果，模型请求为零；没有再次下载已有音频。

最初使用普通个人配方时，模型因归属未确认合法返回零条。由此增加来源级录音配方，以保留有用对话上下文，同时保留观察层及身份不确定性；没有用关键词规则、强制数量或测试结果替代真实模型输出。

私有归档、音频、验证报告和 `Memory.md`/`memory-cards.json` 位于本机 `~/Library/Application Support/Mote-validation/recordings-0.0.76/`；不写源码、发布包或公开 PR。该目录是独立验证资料库，没有混入正在运行的用户资料库。

## 仓库检查与发布边界

- `npm run check:local`：国际化、共享库构建、全工作区与脚本类型检查、工作区测试和中央运行器检查。
- `npm run typecheck`：包含新增 opt-in 真实验证脚本和生成浏览器服务。
- `npm run build`：共享包、服务端、Web、桌面及固定 llama.cpp 本地推理二进制。
- `node scripts/release/verify-version.mjs`、`git diff --check`：版本一致与补丁检查。

English 文案及 Android English 目录同步。产品版本 0.0.76，Android versionCode 87。Mac/Android DEV 安装包由 Release workflow 构建并验证发布身份。

钉钉仅依据官方 DWS 1.0.62 文档/源码及生成响应验证，未登录真实钉钉账号。没有执行 A1/D3200 物理按键新录音、离线上传、长期令牌刷新、全个人历史覆盖或手机安装验收。当前媒体大小检查在 CLI 下载完成后进行；极大音频的流式磁盘配额控制仍未实现。以上边界不由生成夹具、一次云端样本或 CI 安装包构建替代。
