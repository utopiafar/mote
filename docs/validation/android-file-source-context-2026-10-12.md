# Android 文件任务与来源说明验证

日期：2026-10-12。设计与替代边界见[文件任务与来源说明 ADR](../adr-file-source-context.md)。验证只使用生成文件、生成录音转写、独立模拟器和隔离数据库，不读取个人屏幕、手机资料或个人模型密钥。

## 回归场景

| 用户路径 / 状态变化 | 验证内容 |
| --- | --- |
| 首页及共享添加 → 导入 / 同步文件夹 | 先进入统一任务页；显式点击才打开相应系统选择器；取消和重建不自动重弹 |
| 填说明 → 音频预设 → 更改保存方式 | 草稿保留；音频只提供范围和新任务默认值；手动保存方式不被预设覆盖 |
| 编辑旧来源 / 重复选择已有 URI / 后台同时确认说明 | 系统文件与文件夹 Picker 复用旧来源；URI、扩展名、过滤、频率、保留方式、读取选项和单次标记保持；并发更新不能覆盖新草稿 |
| 离线已有待发文件 → 说明确认失败 → 恢复 | 先注册来源和确认说明，再发送完整文件；失败保留说明与原字节；仅修改说明不重新捕获或上传文件 |
| 说明 GET 返回 → 暂停全部发送 | 下一次 PATCH 不发送；说明草稿和待发原字节保留 |
| 创建 / 修改 / 清空来源说明 | 精确原文、不可变版本、指纹、CAS 冲突及丢 ACK 重试；正常注册不清空说明 |
| 当前及未来正式资料 / 单份归属纠正 | 当前来源说明继承到既存与未来资料，单份纠正保留；说明不生成全局 Memory 或新的原件回执 |
| 私有存储与便携备份 | 加密、迁移、显式解密、无 capture 的来源说明、历史版本与更新目标冲突 |
| 来源目录 → 上下文展开 | 按模型选择的字面查询检索名称和说明、分页、完整长说明读取、跨版本游标拒绝；元信息不授予原件引用 |
| 文件 HTTP 接入 → 转写 → 摘要 | 实际上传入口、中央处理和上下文读取；说明修改保留原件及 ASR/OCR，撤出旧语义产物，显式重试消费当前说明 |
| 模型处理中修改说明 | 旧摘要、会话压缩、Ask 或委派结果不能晚提交；说明读取单独记版本，不制造 capture 证据 |
| 后续问答 / 重启 / 委派等待恢复 | 保存的来源版本仍有效才复用旧解释；过时对话保留用户问题，当前模型输入撤出旧回答，来源元信息问答的历史版本仍可追溯；重启不自动历史重算 |
| 升级无说明来源 / 初始尚未开始语义处理 | 保持旧摘要指纹兼容；未开始的首轮处理消费最新说明；已开始或完成的历史模型工作不自动重新收费 |
