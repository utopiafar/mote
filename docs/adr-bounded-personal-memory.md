# ADR：导入背景、有限观察与个人回顾

日期：2026-10-11。状态：采纳。

## 决定与用户旅程

沿用现有 Mote 的 Material、MemoryPipeline、独立审核、只读查询和归属控制面。扩大样本的文本评估支持选择 B：复用用户已有的导入说明，在本人对应关系未知时保存有用的来源限定观察，并在 Ask 中逐事实核对原件、主体和时间。此次不引入另一个记忆框架或数据库。

用户仍在「资料 → 导入」的一处可选说明中填写格式、作者及适用范围，例如“这些是我的日记，引用的访谈属于受访者”。原文作为宿主提供的导入背景传到该次导入新增原件所形成的资料；模型解释文字所声明的范围，确定性代码不从关键词、文件名或第一人称猜身份，也不据此将来源的 `ownerRelation` 改为 `owner`。Source Pack 继续按所选固定解析器工作，说明在该路径只提供资料背景，不增加模型解析或确认步骤。

导入通过完整 manifest 校验后，在第一条原件接收前固定说明版本；说明与新原件的绑定在原件提交事务中保存，使后台消费已到达的前缀时也能读取正确背景。绑定属于确切原件，不属于复用的来源 ID；重复原件不会附加另一次导入的声明、改写旧范围或补发处理授权。说明独立于任务进度保存，删除导入任务不丢失仍被原件使用的背景。它与用户回答整理问题所产生的 `ownerStatements` 区分，均不能成为任意模型指令或读取授权。

`mote.personal-memory@3` 使用独立的个人提取器和审核器。已建立本人对应且有意义的表达可以进入选中 Memory；缺少对应关系的有限经历、担忧、事件及资源关联可以进入 `observation`，明确资料中的说话者、时间和身份缺口。背景评估不为了将有用观察个人化而逐条补问。只有关键用户事实会实质改变一个无法诚实表达的有意义结果时，才沿用已有的最小整理问题及暂停、回答、延后生命周期；不强制把任何未读或未审范围标成完成。

标题、陈述和回顾答案都须区分计划、完成、日历安排、实际出席和未知结果。历史心情或过去的观点不直接成为当前心情或永久偏好。Ask 的开场 Memory 线索保留适用范围和有效期，但其 admission、发布状态及模型结论不提供本人证明或原件引用权限；回答前仍需读取当前原件及其声明。未知资料可先给有来源范围或条件的有用答案，仅在必要时澄清。

目录、证据描述和原文分段仅携带声明标识、范围及只读定位符，避免在多个位置重复长声明而使合法原文无法读取。Ask 通过 `attribution_context` 分页读取当前宿主声明的完整序列化文本；每页仍检查当前权限和版本，读取声明不授予原文引文资格。保持既有单次及整次查询预算，长内容可能需要后续查询；分页明确返回总长和下一偏移，未读完的声明不能被当作完整本人对应证明。提问中的预设身份、日期或结果也不能补充原件缺失的事实。

## 固定版本与升级

保留个人 v2、原上下文提取器及 Coding v2 的定义和指纹。个人 v3 使用新的提取定义，只有相同提取器、证据及语境的组合才能共享提取。旧组合不保证与 v3 共享一次模型调用。

新库普通默认选择个人 v3；采集默认仍复制普通默认并追加日常事件 v1。本次有一次明确的内置默认升级：已有普通默认恰好为个人 v2、采集默认恰好为个人 v2＋日常事件 v1 时，未来接收选择 v3。来源覆盖及其他自定义组合不替换。升级保留已授权 v2 收据的执行资格，让在途任务按原定义完成；不创建历史授权、不恢复已撤销工作、不改写已有产物。随后用户显式保存该默认选择时，结束相应旧范围的保留资格，并沿用现有事务撤权及迟到提交校验。升级标记持久化，用户以后明确选回 v2，重启不会再次升级。

来源的显式选择同样结束该来源的旧默认兼容，包括删除覆盖以继承 v3；该来源不能在移除覆盖或重启后重新获得全局的旧范围资格。其他仍继承默认的来源保留其在途兼容。用户仍可明确选择 v2，未来接收按该选择授权。

手工 API 未传 `recipes` 的兼容流程保持原义；现有 UI 和显式任务可以选择 v3。收费历史重做仍需所有者显式发起。安装与合并代码不等于更新运行中的生产服务。

## 验证边界

生成资料回归需要覆盖说明冻结、首批后台消费、未声明输入、混合说话者、Source Pack、重复接收、重试/重启、当前证据读取及纠正撤权。声明工具需覆盖最长合法说明、转义膨胀、完整重建、预算边界、未经授权或失效的定位符及引用资格隔离。固定版本升级需验证已有收据继续使用原定义、来源覆盖保留、自定义组合不升级、显式选择撤权和重启不重复升级。生成 fixture 验证存储、权限和生命周期；真实模型检查另行报告主体、计划状态、历史时间与实际补问，保留请求、结果和 RPC 原始记录。不得使用真实个人截图，也不得用 stub 回答宣称语义质量已验证。
