# 0.0.3 验收记录

验证仅使用生成图片、临时资料库、隔离客户端配置和专用 Android 模拟器。没有采集或上传个人屏幕，没有执行真机耗电或真实视觉安全模型评估。

## 自动化检查

- 共享库构建、全工作区 TypeScript 类型检查、中央节点与 Web 构建通过。
- npm 全工作区测试通过：桌面 187 项、中央节点 109 项、Web 22 项、代理 45 项、诊断 5 项、本地推理 13 项、共享协议 16 项。其后新增的桌面 2 项存储边界测试也已定向通过。
- Mac 设置更新测试覆盖取消旧采集、等待旧任务完成、按新间隔恢复，以及用户同时停止时保持停止。
- 存储事务测试覆盖图片及 OCR／重试／确认／节点归属状态保留、恢复默认目录、迁移期间读写排队、占用位置与符号链接拒绝、提交前失败与提交后异常、目标损坏时保留原目录，以及掉盘后不创建替代空目录。
- Mac Electron 界面 fixture 通过本机文件夹选择器迁移 31 条生成截图及笔记，并恢复默认位置。保存失败注入验证运行配置与持久配置回退；提交状态不确定时保留双份队列，禁止继续重试、导入及提交笔记，并显示重新打开入口。
- Mac 完整构建、Swift 合成窗口身份检查、连接临时中央节点的采集记录浏览 fixture 均通过。

## Android

- 73 项 JVM 测试通过，包括迁移中断恢复、旧队列实例失效、配置恢复状态与投屏授权请求在 Activity 重建后的交接。
- release/development lint 无错误，分别仍有 111／121 条警告；debug、development APK 及 development instrumentation 构建成功。
- 专用 API 35 模拟器执行 `SettingsStorageInstrumentedTest` 4 项和 `NavigationInstrumentedTest` 4 项，合计 8 项通过。新增检查覆盖热更新与并发停止、设置提交失败回退、使用实际 Android Keystore 的内部／外部应用空间往返迁移，以及启动恢复持锁时主线程及时返回进度。
- 模拟器仅使用生成数据，没有启用截图服务。真实投屏会话的尺寸更新、系统授权及旋转流程没有实机执行，其恢复决策与授权交接由 JVM fixture 验证。测试完成后模拟器已关闭。

## 验证边界与发布

上述界面测试保持实际屏幕采集停止，采集中的配置交接由生成数据与受控任务测试验证。实际外接盘突然断电、Android 真机投屏会话与系统授权交互未执行；文件系统失败通过临时目录、移走目录和异常注入验证。

发布流水线会重新执行项目检查、构建并签署两种 Android APK、打包 Mac、构建服务器镜像并生成签名更新清单。所有发布任务成功后才公开完整 Release。0.0.3 客户端与 0.0.2 中央节点兼容。
