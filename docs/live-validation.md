# Mote 0.2.1：真实模型与复杂链路验收

日期：2026-09-13。此前 [0.2.0 基线](validation.md) 保留为历史记录。本轮使用用户明确授权的原始日记样本和 DeepSeek 官方 API；屏幕测试继续只使用生成图片与专用 Android 模拟器。没有采集个人屏幕，未连接 K90 真机。

## 方法与隐私

从用户提供的 Memex ZIP 中仅解析时间戳 Fact 原始正文：518 条原始输入，按长度、日期、多行、数字和附件引用等结构选择 24 条，约 1.58 万字符。没有复用 Memex 的架构、派生总结、配置、附件 OCR 或实际图片。原文按源切片保留并校验 SHA；Fact 没有时区，测试明确按 +08:00 导入，原本墙上时间另存。提取脚本支持显式指定偏移。

样本只写入隔离测试节点，未进入正式 `data/`。完整问题、回答、评分、源切片和模型凭证放在 Git 忽略的 `.mote/live-validation/`，目录 700、文本文件 600；公开测试全部为虚构资料。提交前检查源码中没有模型 Key 或样本文字片段。个人数据不随源码/安装包分发。

8 项固定问题覆盖长文回忆、数值与条件、同日顺序、跨记录关联、尾部细节、不能确认的完成结果、多行提纲、缺失图片。必需证据由原始输入确定；人工逐项核对语义、归属、时间、引用和不确定性，未用关键词命中作为语义通过条件。HTTP 200 和引用 ID 存在只代表协议通过。

## 真实 DeepSeek 结果

使用官方 `https://api.deepseek.com`，由固定 DeepSeek Harness 0.1.5-rc.2 实际执行只读工具循环。每次请求有总时间和工具次数上限；格式问题最多再由同一证据会话中的模型修正一次。

| 固定 8 题 | HTTP 成功 | 人工通过 / 部分通过 / 失败 | 主要发现 |
|---|---:|---:|---|
| 第一轮，Flash，关闭推理 | 5/8 | 1 / 4 / 3 | 3 次格式失败；时区遗漏、内部字段暴露 |
| 第二轮，Flash，关闭推理 | 8/8 | 2 / 6 / 0 | 时区与引用覆盖修正；仍有归属混淆、牵强关联和历史覆盖误判 |
| 第三轮，Flash，high 推理 | 8/8 | 6 / 2 / 0 | 虚构完成、虚构采集空档、附件臆造均未出现；关联与提纲各有一项语义问题 |

第二、三轮均保留全部目标证据引用，时间均正确使用本地时区。第三轮单题约 6.7–43.9 秒；这仅是此次官方模型和样本环境的端到端延迟，不是性能承诺。启用推理增加了延迟，也改善了本组证据理解。

针对残留两题，另外使用最终提示分别复测 Flash 和 V4 Pro（均为 high）。Flash 提纲题通过、关联题仍部分通过；Pro 两题仍部分通过，其中提纲出现新增细节与否定词丢失。更换模型不是事实可靠性的保证。这只是两题局部对照，不能作为模型普遍准确率或完整第四轮的结论。公开报告保留失败，不筛掉坏结果。

| Mac 中央窗口 | 实际设备筛选、浏览器时区传递、两项真实 DeepSeek 问答通过；长文题实际读取 offset 18000 的末页，约 5.45 秒返回正确答案，行内来源号码→引用 ID→完整 20000 字符原文完全匹配。故障注入验证切范围忽略迟到答案、502 保留问题及重试；故障注入不算模型验证 |
| Android 本地 Qwen | 默认策略 3 张生成图片×重载两轮均允许；显式用户图形策略识别蓝方允许、红圆拒绝。红圆两次进入真实 CapturePipeline 后被拦截，OCR 未执行、队列/捕获/上传字节不增加 |

| 多页归档 | 121 条虚构日记，实际跨 100+21 或 30+30+30+30+1 条读取；检查首末计划更正。曾把总数说成 122，增加精确 totalCount 后复测为 121 |

本地模型均为同一固定 Qwen3.5-0.8B 量化权重。生成图的允许/拒绝链路证明本地运行和门控行为，**不构成 NSFW 准确率/召回率测试**。短的“拒绝所有图片”策略曾得到不可用结果，链路保持关闭；随后使用明确图形策略验证真实拒绝。没有使用理由关键词去翻转模型决定。

## 本轮修复

- 长文预览附总长度，Agent 可按 UTF-16 偏移读取后续页面，边界不拆开代理对；实际读取超过原来的 12000 位限制。
- 时间线透传游标与范围总数；完整性和计数有明确证据。
- 工具仅在成功序列化且通过预算之后授权证据，失败响应不能获得引用权；正文引用也须与已检索和声明的来源一致。
- JSON 字符串内的原始控制字符只做无损转义；其他格式错误通过一次模型修正处理，没有合成答案兜底。
- 问答/回顾支持硬设备范围和 IANA 显示时区；记录保留 UTC，模型获得显式显示时间。采样另提供确定的起止区间，避免把采集结束时刻误作开始。
- 明确设备心跳是当前上报状态，不代表历史归档范围；提示模型保留原话归属、时态、计划与结果区别、原文内部解释和后续结果的区别。
- 推理强度与输出预算可配置，默认 high/8192；前端显示可点击来源，切换设备/时间范围清除旧答案并忽略旧请求的迟到结果。
- Mac 修复合法长草稿在序列化膨胀后不能恢复、退出前未等待笔记落盘、输入法组合误提交等问题。
- Android 入队成功但调度失败时保留准备中的原 ID，重试不会创建第二条笔记。

## 重现与边界

公开 fixture 见 Android/desktop 文档的复杂测试命令。私有日记测试需要显式提供自己的节点凭证和备份：

```sh
python3 scripts/extract-memex-facts.py /private/path/backup.memex --output .mote/my-evaluation --time-zone-offset +08:00
python3 -m unittest discover -s scripts -p test_memex_facts.py
node scripts/test-live-agent.mjs --connection .mote/private-connection.json --facts .mote/my-evaluation/sample-private.json --cases .mote/my-evaluation/cases-private.json --out .mote/my-evaluation/round1
```

连接文件包含 `url`、`token`，可附 `model`、`reasoningEffort` 供报告标注。运行脚本会向指定节点写入样本并调用该节点配置的真实模型；只能在授权的隔离节点使用。它精确核对输入往返和引用覆盖，语义仍需按私有 rubric 人工评估。

未验证 K90 Pro Max / 最新 HyperOS 真机后台、长时续航/温升、实际用户窗口过滤、个人截图识别质量。没有把模拟器、电池快照或生成图耗时外推到真机。目标 NAS/服务器卷权限、HTTPS 和生产迁移、Android release 签名/macOS 公证也仍需目标环境验收。模型仍可能出错，少量样本通过不意味着长期洞察可靠性已被证明。

## 保留的模型限制

当前 Flash 仍可能将模糊相对时间换算过度，或将缺少关联证据说成不存在关联。Pro 对照还出现原文否定词/细节理解错误。没有为这些已知问题写关键词分支或固定答案，也没有降低人工评分标准。资料和可点击原文可帮助核对，但不能保证模型每个结论正确；更广泛的语义评测和改进属于后续工作。
