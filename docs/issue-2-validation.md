## 实际边界

- Mac 没有使用私有通知数据库；隐藏、消失或系统不暴露的通知无法获取。配置应用排除/仅活动时不会读取通知中心内容。真机覆盖率待实际授权验收。
- 客户端附件记录使用中央页面，需要联网和所有者登录；本机纯文字草稿和队列保持原离线流程。音频可选择已有录音文件，未新增原生录音器。
- OCR/转写仍依赖已配置且启用的中央处理器；没有配置时保留原件与待处理状态。
- 数据导出不含访问令牌、模型凭据；它是资料导出，不替代全量可恢复的离线数据库备份。超过 HTTP 导出额度使用既有 backup 命令。
- Mac 开发 ZIP 用于独立调试，不参与正式客户端自动升级；正式更新清单保持旧客户端兼容。
