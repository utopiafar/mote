# 上传审查与中央感知

端侧负责应用范围、固定遮挡、轻量去重、可选文字审查和可靠上传。中央归档原图并运行 OCR。查询 Agent 先读取 OCR 文字；只有模型显式请求、用户开启原图披露时才发送对应图片。没有单独的截图语义 Worker，也没有逐张截图的后台图片理解任务。

## 端侧设置

Mac 和 Android 的隐私页面集中显示应用采集范围、固定遮罩、上传文字审查与失败策略。

- 文字审查默认开启、规则为空；空规则或关闭开关不会调用 OCR。每行规则按原文精确包含匹配，不做语义分类或隐式黑名单。
- 明确命中规则：不保存、不上传。审查异常：默认暂存待复核，也可选择不保存或允许上传。
- 待复核截图计入本机容量，普通同步重试、重启和关闭审查都不能放行。Mac 在隐私页查看原图并逐条允许上传或丢弃；Android 在同步恢复页查看本机副本并明确放行，记录页可删除。
- 应用范围和固定遮挡仍按用户设置执行，不受文字审查开关影响。应用身份无法满足已配置限制时，截图前就停止，无法暂存尚未取得的像素。
- 本机 OCR 只为文字规则服务，识别出的文字不写入新事件，不作为中央 OCR 上传。本机 VLM 与附加审查 URL 暂停执行，代码保留 `VisualReviewProvider` 接口。没有提供 NSFW 语义审查保证。
- 新截图不创建本机补识别任务。旧版已存在的 OCR 队列保留兼容处理代码；它们不是新链路的一部分。

## 中央 OCR

中央设置 → 模块与模型 → 中央感知。新截图默认使用受管理的本地 PP-OCRv5 OCR Worker（默认 `http://127.0.0.1:9010/ocr`）。Native profile 启动时在后台自动准备独立运行时（首次需网络），Docker 构建包含依赖；模型需在设置页显式下载或用 CLI 导入。模型缺失时任务显示 `model_missing`，原件仍可靠归档，安装后继续；Worker 尚未就绪时等待，不消耗识别重试次数。旧截图不自动回扫，需预览确认（每批最多 100 张）或单条重试。详见 [安装与验收边界](ocr-asr-implementation-plan.md)。

OCR 使用 Cordis `image.http` 处理接口。HTTP 请求为图片二进制，包含 `X-Mote-Media-Type`；返回 Transcript JSON：

```json
{"durationMs":0,"segments":[{"startMs":0,"endMs":0,"text":"识别出的文字"}]}
```

空 segments 表示成功但没有文字，与失败或尚未处理区分。返回文字最多 100,000 字符，处理超时 120 秒；禁止重定向。受管理 OCR 请求使用 profile 派生的内部 Bearer 令牌；中央感知设置不提供任意自定义 Worker API key 输入，外部服务需自行配置部署层保护。非回环地址必须 HTTPS，且单独开启允许外部处理；不自动改用外部服务。

## 持久性、结果与证据

- SQLite 插入截图的同一事务创建 OCR 任务，可靠保存后即可确认上传。
- `perception_results` 保存 OCR 版本、输入哈希、引擎/版本、配置指纹、生成时间和处理产物，不改写 captures 原始 JSON 或上传指纹。
- 完全相同图像和处理配置可复用 OCR 结果；不同观察事件保持各自时间。近似去重不借用旧图识别结论。
- 处理失败退避重试，最多 4 次，之后等用户重试。重启将运行中任务恢复待处理。配置改变中止旧任务，提交前复查配置与原图存续；删除后禁止写回。
- OCR 就绪立即更新全文索引并触发中央变化流。重算使依赖记忆需要重验。JSON 导出/恢复包含派生版本，原始事件仍保持不变。
- Android 在现有同步期间有界拉取 `/api/capture-browser/updates`，复用中央游标，缓存文字预览和处理状态；不新增高频轮询。Collector 仅能拉取本设备，删除仍走已有 reconcile。完整文字在中央记录页读取。Mac 上传确认后释放本地发送队列，通过中央记录页按需读取处理结果。

## 模型按需看图

搜索和时间线不包含图片字节；显示 OCR 与处理状态。OCR 是机器提取的文字，不足以表达图表、图标、布局等视觉信息。查询 Agent 根据问题和已检索证据判断是否需要原图，不用关键词规则替代模型判断。

`read_image` 只接受本轮已发现并展开文字的记录 ID，不接受路径或 URL；重查时间/设备范围和删除状态，每轮最多 4 张，每张至多 8 MiB 输入。独立的“允许查询模型按需读取原图”默认关闭，开启后图片可能发往所选查询模型服务。需要支持图像的模型；不支持的模型会报错，不以图片地址冒充模型已看图。查询工具保持只读，按需看图不会保存独立的 L2 摘要。

## 验证边界

自动验证使用生成图片和模拟 OCR/模型服务，不采集或传输个人截图。结构与权限测试不能证明真实模型的视觉理解质量；真实模型和物理设备检查应单独记录。
