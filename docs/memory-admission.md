# 资料、理解产物与精选记忆（0.0.44）

原始文件/截图/来源记录 → 解析文本与定位 → 事件和资料理解产物 → 有明确用途的精选记忆。箭头表示可以加工，不要求每份输入逐级提升。原始记录始终可检索；全文和向量索引是可重建的查找设施，不能成为独立事实来源。

`admission.layer` 区分 `observation`（事件与资料摘要）和 `memory`（精选记忆）。`reason` 说明用途，`scope` 说明主体/项目/情境边界，`attribution` 区分用户陈述、第三方陈述、观察和推断。该分类由模型判断，不用应用名或关键词分发。原有 `tier=episode|consolidated` 只表示初次提取/整合阶段，`kind` 表示事件/语义/方法类型，`status` 表示候选/用户确认/失效；这些维度独立。

所有生产提取入口都要求 admission 和逐条精确证据。非空批次通过第二次只读模型调用核对记忆价值与语义支持，模型可以拒绝、缩窄或降级。宿主随后重新检查版本、范围、精确引文与事务检查点。可省略 offset，让宿主在授权范围内定位唯一的完全相同子串；不会模糊匹配、纠正 OCR 或靠引文长度判断真假。模型审核不是事实认证。

长期整合只接收 layer=memory 的未失效 episode。仅重述或将无关约束打包为检查清单不算新增价值。每条结果提供实际使用的 relatedMemoryIds，宿主验证其属于本轮候选、未失效且贡献了引用证据。原始证据仍直接挂在每条结果上。独立审核和生成均计入模型调用账本，reviewRunId 指向最终审核运行，模型字段优先使用宿主生成的用量回执。

旧记录不作语义猜测或批量删除；没有 admission 的记录显示为“旧版未审核”，仍可按 layer=legacy 查询。它们不会自动进入长期整合或默认 Agent 记忆检索。Owner 的 API 不传 layer 时仍能列出所有记录，网页默认显示精选记忆。Agent 的 memories 工具默认 layer=memory，也可显式查询 observation、legacy，或回到 search_context 搜索原始资料。确认状态不会改变分类；用户确认观察不等于将其升级为个人事实。要按新策略重新处理旧资料，手动选取范围建立新任务，新 Skill 版本使用新的检查点；系统不会因升级而发送全部旧私人资料给模型。

提取任务将校验失败的时间、阶段和固定错误码保留在批次 validationFailures（最近 20 项），不额外保存私人模型失败原文。最终成功不会清掉失败历史。

自动调度的 6 小时与 25 次增量 AND 门槛用于启动提取轮次。启动时固定最多 maxItems × drainWindows 条增量的水位（默认 100 × 100），每个 tick 最多处理一个窗口，让其他工作流有机会执行。该轮次的不足 25 条尾部仍会处理；新到达的增量留到下一轮。整个轮次完成后才重新等待 6 小时。drainWindows 可设为 1–1000；停用暂停处理，失败按原窗口退避，水位跨重启保存。该上限是增量数量预算，不是美元或 token 预算；单窗口中的模型批次数取决于原文长度，非空产物还需一次审核。整合、洞察和对话摘要保留原本的独立周期。
