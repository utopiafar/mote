# 产品

[English](product.md) · **简体中文**

Mote 是一个可扩展的个人上下文中心。从用户授权的设备、文件、应用和对话采集资料，统一归档、组织和理解，并提供给应用与 Agent 使用。个人助理是从这个基础上生长出来的应用之一。

此页说明产品方向；当前能力与实现范围见[架构](architecture.md)。

## 定位与边界

采集、归档、记忆、检索和扩展能力构成基础。Mote 既提供自己的应用，也服务获授权的外部应用和 Agent。近期优先利用已接入工具与插件提供行动能力，通用终端、编码和电脑操作可由外部 Agent 使用 Mote 上下文完成。

一实例一所有者，不引入账号、租户或团队协作；短期没有向指定的人分享上下文的路线。互动自然、有温度，陪伴不单列为核心交付承诺。

## 资料与理解

原始资料、工作上下文、长期记忆和回顾结果各有用途。已归档资料可在授权范围内直接检索，不必等待 Memory。默认长期保存原件与设备副本，不设人为资料容量配额；保留规则由用户选择。源端删除不连带删除 Mote 归档。

语义理解与检索选择交给模型，不用关键词或手写语义规则代替。模型结合上下文和有效记忆判断；后果轻、容易纠正时先推进有用的工作，关键缺口才询问。少量重要偏好与约束持续提供，其余资料按需检索。记忆保留主体、来源、时间和有效状态，推断不冒充用户原话。

是否需要额外复核由模型或选定的记忆方案判断，不要求每批固定增加一次模型调用，也不用手写语义规则分流。

隐私过滤、权限、传输、去重、保留期限和实际用量由确定性代码处理。采集内容与第三方资料作为上下文，不因被总结进记忆就成为用户指令。

## 应用与行动

个人助理采用一个长期主对话，承接查询、交办、反馈和纠正。长任务在后台进行，对话保持可用；新的补充优先调整相关工作。纯记录给轻回执，“认识我”以轻入口进入主对话。

模型遵守当前指令、有效记忆和已有授权，明确的约束持续生效。已明确授权的工作不反复确认，缺少必要信息或超出授权时再问。外部 Agent 遵守同一原则。模型按模块或本次任务选择，自动备用须有事先允许的范围。
