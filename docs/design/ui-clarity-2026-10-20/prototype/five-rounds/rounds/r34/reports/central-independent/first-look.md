# R34 independent current first-screen observation

Recorded before deeper interaction. Reviewer had inherited project history and read the frozen contract; this is not blinded human usability testing. Each platform uses a fresh isolated reset context, with DOM captured before its viewport image.

## web

**purpose:** The headline and supporting paragraph communicate saving personal material and later searching/asking with a route back to originals.

**expected first action:** Import the first material; writing a note is an immediately visible secondary action. Neither action is visually gated by a model/provider setup step.

**collection owner:** The first screen explicitly says Mac/Android collect on their own devices and Central receives/organizes them. No Central-local folder collection control is shown.

**density and hierarchy:** Spacious two-column onboarding, one dominant import action, secondary note and example/source actions. Persistent navigation is separate from the main task.

**friction or uncertainty:** Several entry names overlap (top 添加内容/随手记, main import/note, and sidebar shortcuts on Mac); the dominant first action remains clear. “工作台在线” does not by itself explain device connection or authorization.

**limits:** This first screen alone does not prove permission, source configuration, import completion, model optionality across all tasks, or all subsequent newcomer journeys.
