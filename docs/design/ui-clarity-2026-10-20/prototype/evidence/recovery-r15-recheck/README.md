## 范围限制

- 账号场景的脚本通过不表示退出、登录或切换账号完成。
- 提问场景没有点击引用，也没有调用真实模型或验证合成答案的真实性。
- 笔记没有执行离线、重启或读取真实文件的检查。
- 暂停观察没有点击恢复，也没有核对既存资料的阅读；它不抵消范围保存失败。
- 没有生成新的静态图：WeasyPrint 模块、原有静态依赖及字体路径均缺失，按任务范围未安装依赖。DOM 记录不提供布局、遮挡或真实浏览器判断。

这些新结果独立于中断前的 75 分评审、28 条固定场景、9 条补测与原始盲评；不能用来假定丢失的原件已经恢复。
