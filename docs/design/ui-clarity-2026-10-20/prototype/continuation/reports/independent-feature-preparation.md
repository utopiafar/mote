# 独立知情复评：需求核对准备

状态：已准备，等待冻结候选及逐入口浏览器 DOM。此文件不宣称候选覆盖通过。

## 已冻结口径

- 分母：20 类（12 P0 / 8 P1），78 单元（42 core / 36 advanced），4 大区、16 组。
- 首次理解已在 R15 操作前固定；现在允许知情对照需求，后续不称为全新盲测。
- 候选只按 HTML 原型的可见信息、入口与模拟交互评价；真实模型、外部来源和系统权限不冒充已验证。
- C1–C7、G1–G4沿用 [independent-criteria.md](independent-criteria.md)。
- 五维 0–4 整数：Design 20%、Originality 10%、Craft 15%、Functionality 30%、Clarity 25%。总分不覆盖具体失败。

## 每个单元要回答的问题

1. 主要归属是什么？普通用户从哪里发现它，是否和同名入口职责一致？
2. 进入后的可见内容是否真的对应这一能力，而非只到同一通用页？
3. 用户能否看到具体下一步，或清楚知道为何当前状态不能执行？
4. 核心目的是否遗漏了重要部分；与其他入口是否形成冲突、重复管理或范围错误？
5. 证据证明到什么程度：入口/可见语义、模拟交互、完整自然任务，分别记录。

条件态缺少时标未验证并保留分母；不得因没捕获而硬判已通过或删除难项。目录里的旧路径标签不作为必须照抄的文案。
