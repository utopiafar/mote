# 来源 UI 修复与聚焦核对

修改目标为冻结 R15 的独立工作副本 `../work/source-flows.html`。原 R15 与共享集成文件未修改；没有远端操作。全部内容为生成的演示数据，真实权限、文件同步与后端行为不在本检查范围。

## 已修复

1. 屏幕应用范围分为已保存值与编辑草稿。复选框输入被保留；权限允许/拒绝、保存、离页重开、暂停/恢复均不重置应用选择。保存时至少选择一个应用；放弃修改回到已保存值。
2. 屏幕状态由授权、暂停与已保存范围共同决定。未授权和已拒绝都显示当前不在记录；来源卡片显示已保存应用名称/数量，未保存草稿不改变当前采集范围。
3. 文件夹资料使用稳定的 `sourceId` 关联。来源重命名不丢失关联；浏览入口保留来源范围、显示名称和暂停状态，资料详情返回后继续该范围。来源内空态说明具体来源，可清除范围回全部资料。
4. 暂停与持续同步策略分别说明。暂停后已有资料仍可阅读；关闭持续同步时明确显示不接收后续变化。
5. 新建文件夹与已有文件夹管理分开。来源目录和全局添加进入 `setup/folder/new`；创建后分配独立 ID 并进入管理页。可创建多个文件夹，即使名称相同也保持不同范围，原有来源不被覆盖。
6. 来源卡片的已保存资料数量使用当前演示资料集合计算，避免显示数量与实际可阅读材料矛盾。用户输入的来源名称、路径和专属范围名称用 `data-user-content` 标记。

## 修改区域

- `seedMaterials`：为具有实际来源的示例资料补稳定 `sourceId`。
- `state` 初始筛选段：新增来源范围 ID、屏幕草稿、新文件夹草稿和演示 ID 计数器。
- `inputActions`：连接新文件夹的入口。
- 资料列表：`filteredMaterials`、`filterSummary`、`libraryPage`、`emptyLibrary` 与明确的来源筛选/提示辅助函数。
- 来源：`sourcesPage`、`setupPage`、`devicesPage`，以及屏幕范围和来源状态辅助函数。
- `doAction` 中仅来源相关分支；`change` 中屏幕复选框和来源筛选分支；单独的来源草稿输入监听。

`source-flow-replacements.json` 保存 **54 个顺序执行的精确 old/new 替换**。root 可在其他不重叠改动上逐项应用；每个 old 必须恰好出现一次。它们不改变任何记忆、账号、笔记保存或英文翻译函数。新增字符串另列在 `source-flow-new-strings.json`，供英文补齐使用。

## 边界

新建来源会显示尚未收到资料；没有自动伪造“首次同步已完成”的材料。已有示例文件夹提供了暂停后仍能打开历史正文的可核对路径。模拟权限按钮只改变界面中的演示状态。上述检查不提供尺寸、遮挡或原生设备证据。
