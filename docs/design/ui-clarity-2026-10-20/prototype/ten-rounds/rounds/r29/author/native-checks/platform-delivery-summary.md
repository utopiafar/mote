# 三端界面设计与最终核验摘要

## 三端分别解决什么问题

| 平台 | 界面侧重点 | 已完成的差异化处理 |
| --- | --- | --- |
| Web | 在工作台中查找、使用资料，管理服务器来源与已连接设备 | 明确区分工作台服务器目录和设备目录；已有服务器来源先显示状态、范围与暂停/浏览操作，再进入编辑；设备目录交给对应设备完成选择与授权。 |
| Mac | 快速记下内容，在本机持续收集，随时查看收集状态 | Mac 窗口与菜单栏、可操作的菜单栏收集面板、Command K 搜索、Command N 随手记、Finder 风格文件夹选择；屏幕与文件夹分别控制。 |
| Android | 单手进入主要任务，在小屏幕上完成选择、保存、返回与恢复 | 顶部应用栏、底部导航、48px 主要触控目标、底部弹层、手机文件夹选择、上下文返回；长表单预留底部导航空间，新页面回到顶部。 |

三端共享“保存 → 查找/提问 → 沿出处核对”的首次使用说明。手机端将持续收集入口放到示例说明前，文件夹与屏幕保持同级；Mac 的空资料库快捷搜索会解释下一步，并提供首条笔记/导入入口。

## 几个有意保留的状态区别

- 第一次连接与已有来源管理使用不同标题、说明和初始表单，不再提前出现“恢复”或已有来源假设。
- 当前接收状态与已保存同步策略分别说明。暂停保留策略；在编辑器中修改勾选和保存方式，点击保存后才改变运行状态。
- 已保存范围在管理页上方展示，草稿在下方编辑。文件夹选择器会保留名称、路径、持续同步开关和保存方式四项草稿。
- 系统屏幕权限与工作台设备连接授权分别解释。缺少屏幕权限时，禁用保存旁说明原因，并把用户带到实际授权预览控件。
- 内容关系与来源背景属于可选补充，以可展开区展示已保存摘要和未保存状态；保留完整编辑与放弃操作。
