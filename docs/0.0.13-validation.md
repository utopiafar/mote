# 0.0.13 验证记录

## 中央对话与网页

- 工作区类型检查、中央及 Web 生产构建通过。
- `npm test`：481 项工作区测试通过，包括 155 项中央测试、57 项 Agent 测试及 37 项 Web 测试。
- 新增中央历史测试覆盖重启恢复、续聊上下文、继承及清空筛选、所有者访问控制、并发续聊、对话删除竞态、原始证据删除、上下文长度与历史分页。
- `scripts/test-web-conversations.cjs` 使用真实中央 SQLite、浏览器渲染和合成模型，验证新建／继续／删除对话、切页和刷新、中央重启、生成中离页、失败保留问题，以及桌面和手机宽度布局。
- `scripts/test-web-navigation.cjs` 验证设置返回或切页后销毁表单与保存栏，并回归模型配置、合成连接测试、配置冲突与导出。
- `npm run test:e2e` 通过：生成采集、中央加密归档、真实 Harness 的合成模型工具循环、证据读取和资料导入导出。`npm run test:privacy` 的 22 项合成检查通过。

## Mac 设置与配对

- 生成二维码连接 fixture 验证已有 URL → 导入邀请 → 兑换中切页 → 新连接持久保存 → 其他设置保存 → 重新加载。
- UI fixture 验证返回按钮、Escape、主导航都会丢弃当前设置草稿，菜单不显示保存栏。
- 复杂输入 fixture 验证随手记的组合输入、Unicode、超限错误和修改重试不受影响。
- 本机 fixture 保持采集停止，使用模拟安全存储；未验证日常 Keychain 或真实采集画面。

## Android

- 108 项 JVM 测试通过，包括 1 项实际算法指标与说明测试、8 项去重诊断存储测试：图片对与元数据整体加密、重建恢复、数量／实际加密字节／时间限额、关闭清空、删除、损坏文件、路径隔离、加密失败与禁用竞态。
- Android 编译与 lint 检查通过；最终 development 原生安装包和 instrumentation APK 在隔离环境构建。
- 设置、连接、存储、配对、去重诊断及 ANR 模拟器回归共 22 项通过；另有 1 项需要独立中央节点的可选测试跳过。配对 fixture 使用生成邀请和本机 HTTP 响应，验证兑换未完成即返回、最终 URL／凭据刷新、其他页面保存、保存中旋转及设置重新进入。

- 去重诊断 instrumentation 将生成图片交给真实 `CapturePipeline`，验证连续重复引用最后成功入队的基准图、两张 JPEG 都已遮罩、分数和阈值与算法一致、排除应用不留存、默认关闭不留存，以及去重事件不携带诊断图片或分数进入上传队列。实际预览页显示两张图和指标，单条删除、清空与保存关闭后的立即文件删除均通过。

## 验证边界

所有消息、图片、密钥和模型回复都是生成 fixture。模拟器使用专用开发包与临时测试状态；未采集或上传真实个人截图。实体手机、HyperOS 后台稳定性、耗电及真实模型回答质量未在本次验证。发布产物另由 Release 工作流构建、检查并签名。
