# 配置归属与执行快照

中央模型连接由 ModelSettingsStore 管理；文件类型/来源路由和处理服务由 FileProcessing 管理；截图 OCR/语义处理由 Perception 管理；设备本地隐私由采集端管理。全局保存 revision 用于拒绝陈旧编辑，不等于所有任务的内容版本。

文件任务按来源、MIME、所选处理器版本及实际使用的服务、参数生成配置指纹。内置处理器声明传输依赖；未知插件保守地依赖全部配置。修改图像端点不会取消音频请求，相同配置再次保存也不产生新任务。相关服务变更会取消旧授权、重新排队，并在提交前再次核验，丢弃不响应取消的迟到结果。已完成资料保留原结果，通过显式预览重处理更新。

每个文件/配置指纹保存公开回执，包含配置所属模块、首次设置 revision、处理器版本、来源、MIME 和服务 ID；模型分析另外记录 provider/model/revision。凭据仅进入指纹计算，未写入任务输入或公开回执。执行期间的私有配置在内存中复制；分批摘要复用同一个模型配置，实际模型变更后旧结果不能提交，无关预设修改不失效。

启动时对旧全局 revision 任务建立兼容映射，复用可验证的提取缓存；相关配置已变更则重新排队。新记录纳入容量计费和删除级联。配置 JSON 写入使用私有权限、fsync 和原子替换，数据库工作在恢复时协调。

Memory 作业和每个批次现也保存相关模型的公开指纹回执。提取、独立审核和提交使用同一模型配置；中途相关配置改变时阻塞为 `configuration_changed`，进程重启不会静默换模型。显式重试才接纳新配置，已完成批次及检查点保留。无关配置的保存 revision 不使任务失效。问答在选择模型时固定公开回执，与答案一起持久保存；正在运行的问答保留原运行时。统一语义提取同样按相关指纹固定。
