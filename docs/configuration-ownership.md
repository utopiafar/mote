# 配置归属与执行快照

多用户生产路径以 [M04 合同](design/multiuser-configuration.md) 为准：实例文件和每用户文件分别使用原 ConfigService；认证上下文决定私人作用域，共享模型仅为固定资源引用。下文的单所有者领域运行时保留为后续适配参考，不表示旧全局服务已重新开放。M05 负责持久任务授权和恢复，M13 负责客户端设置页接入。

中央系统配置的唯一持久来源是私有 `mote.yaml`。`ConfigService` 统一读取、稳定监听、校验、内容 diff、revision、原子保存和生效状态；各领域注册 schema、默认值、敏感字段及 apply policy，并负责准备资源、应用和回滚。网页设置与手改文件共用同一事务。完整选型、兼容边界与 supersession 见 [统一配置 ADR](adr-unified-configuration.md)，操作见 [服务端配置参考](server-configuration.md)。

不可逆任务取消、重新排队与运行时退休在完整事务提交后执行；后续领域 apply 失败只回滚可逆快照与有效投影，不撤销旧配置已经授权的任务。私有 YAML 删除密钥即删除有效凭据；仅专用页面 API 的遮罩草稿可以按领域规则保留未填写的凭据。插件参数默认值在执行输入解析，不偷偷补写成另一份有效配置。

异步资源安装不能提前暴露候选权限。各领域通过同步 `publish` 一起切换运行快照、诊断与加密策略、SQL 摄取投影和服务的有效值；在等待其他插件应用时，后台任务及新摄取仍读取已提交策略。已发布快照的回滚也必须同步，避免失败事务授权外传或把候选权限写入历史输入。

模型连接由 ModelSettingsStore 提供领域 API；处理类型、服务、来源路由由 FileProcessing 管理；图片行为由 ImageProcessing 管理；Memory 运行预算和调度由 MemoryLifecycle 管理，普通 DAG 通道由 ProcessingRuntime 管理，Action 普通开关和时区由 Actions 管理。这些当前配置都保存到 YAML。Action 审核设备权限与历史授权保留领域数据库，YAML 不能新增设备授权。设备本地隐私、采集队列和客户端偏好由采集端管理，不并入中央文件。

`revision` 是整份配置的编辑版本，用于拒绝陈旧保存，不是所有任务的内容版本。内容相同的保存不生成新 revision，也不产生新任务。需要重启或迁移的字段区分已保存值与当前有效值，不会仅因保存成功就假称已经应用。

文件任务按来源、MIME、所选处理器版本及实际使用的服务和参数生成配置指纹。内置处理器声明传输依赖；未知插件保守依赖全部配置。修改图像端点不会取消音频请求。相关服务变更撤销旧执行许可、重新排队并在提交前核验，丢弃不响应取消的迟到结果。已完成资料保留原结果，通过显式预览和重处理更新。

每个文件/配置指纹保存公开回执，包含领域、首次设置 revision、处理器版本、来源、MIME 和服务 ID；模型分析另外记录 provider/model/revision。凭据仅进入私有快照和指纹计算，不进入任务输入或公开回执。分批摘要使用同一个模型快照；相关模型变化阻止旧结果提交，无关预设修改不使任务失效。

SQLite 中的 `image-file-policy-effective`、`perception-effective` 和 Memory 生命周期有效投影只服务于 SQL 摄取触发器、状态投影和授权判断。启动和领域同步发布从 YAML 重建它们；旧配置键不再覆盖 YAML。文件任务的 `policy_json`、作业、检查点和来源版本仍是业务历史，不能作为新的配置覆盖来源。旧 JSON 文件和 SQLite 配置记录不自动删除或转成新配置。

Memory 策略绑定、不可变版本、授权回执、插件与来源实例保留在领域数据库。修改运行预算只作用于新接纳窗口，在途窗口继续使用冻结设置；修改配置不能扩大历史任务已经获授的读取或披露范围。模型提取、独立审核和提交固定相关指纹，中途相关模型变化阻塞为 `configuration_changed`；重启不会静默换模型。显式重试才接纳新配置，已完成批次与检查点保留。

普通问答在选择模型时固定公开回执，与答案一起保存。正在运行的问答继续使用旧模型运行时；后续请求使用已准备的新运行时。并发上限降低只影响后续准入，不终止在途请求。统一语义提取同样按相关指纹固定。

验证入口包括 `apps/server/test/processing-config-service.test.ts`、`file-config-snapshot.test.ts`、`memory-configuration.test.ts`、`memory-input-authorization.test.ts`、`model-settings-api.test.ts`、`concurrency.test.ts` 和配置服务的故障夹具。所有自动数据夹具使用生成内容，真机、真实模型和实际配置迁移另行验收。
