# Issue #3 / 0.0.37

- 网页构建与服务共用根版本；服务检查 `build-info.json`，阻止旧网页文件混用。自动更新页展示两端版本。
- 导航按日常使用、资料、管理分组。导入在设置入口，空间统计在统计中心，用量可从统计中心进入；保留旧路由。
- 三端支持按 1 小时 / 24 小时 / 7 天导出全部仍保留的日志，包含轮转文件与覆盖范围。轮转前删除的日志不能恢复。
- 三端按文件类型、最后修改日（UTC）显示当前物理存储占用；日期分布不是每日增量。不会读取内容或跟随符号链接。
- 查询、导入、文件分析、行动提取、记忆提取的模型输入明确传递语言。持久化记忆批次保留创建时的语言。
- 无正文的活动或重复画面状态按结构合并；单条最多 720 次 / 6 小时，相邻观察最多间隔 5 分钟。保留每次实测时长、空闲秒数和可用空间，中央按样本计算，不能用首尾跨度替代实测时间。确认丢失和重启不会删掉尚未确认的新样本；新旧协议兼容。
- 文件来源默认“内容索引，原件留本机”，也可选仅目录或原件归档。Mac 文件身份使用设备/ inode / 创建时间；Android 使用提供方文档标识，位置另存。版本、删除、确认重试使用同一文件协议。
- 本机文本、PDF、DOCX 解析；音频需要该设备上的本地转写服务（127.0.0.1:9009）。本机解析上限 16 MiB、100000 字符；更长正文明确标为轻量覆盖，主动轻量模式最多 8000 字符。仅目录不读取正文。Mac 原件归档当前上限 16 MiB，Android 保留可配置的 512 MiB 原件上限。
- 按目录单独开启只读补证。设备主动轮询，不开放入站端口；检查源、版本、范围、根目录、撤销授权。离线 / 版本变化表示证据不可用，不能证明内容不存在。
- 轻量索引不能直接生成 memory；充分正文或补证片段可进入记忆流程。记忆保留来源版本、索引覆盖和实际引用范围；父版本更新或删除会使补证及其记忆失效。

验证使用生成文件、记录、图片和模拟服务；未采集个人截图。物理设备采集和真实模型验收与 fixture 测试分开报告。

本地结果：720 项工作区测试通过，1 项原有跳过；Android 163 项测试与 lint 通过；TypeScript 类型检查、隐私 fixture、检索 E2E、媒体 E2E、MCP 和界面回归通过。发布安装包另由 Release 流水线构建和校验。

发布前补充真实桌面来源至中央只读补证通道验收：验证片段逐字一致、原件不上传、内容改变后返回版本变化，并使先前补证失效。修正记忆 API 测试的配置参数，明确断言资料库位于测试临时目录。

实际 Mac 安装包校验更新为新状态序列协议，并验证两次相同状态合并后重启仍保留全部样本。
