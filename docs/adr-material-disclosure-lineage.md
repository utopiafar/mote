# Material 工具的私有问答依赖（2026-10-08）

状态：实现中，等待部署与实际产品验证。仅细化 Material 目录和分页的宿主依赖收据；不取代归属、隐私、读取授权或处理准入决定。

## 问题与责任

整理后台持续发布资料时，使用过 `material_catalog` 或 `material_read` 的历史问答曾因依赖不完整，被无关证据变更保守清除。工具已经披露固定资料的标题、来源、归属及正文，但 Bridge 没有可追踪这些披露的宿主收据。

EvidenceReader 在范围与暴露规则验证之后，记录所返回资料的原始成员和当前正文锚点。MaterialStore 只提供有界 ID 查询，不为此加载原文。Bridge 校验私有收据并合入回答的 evidenceDependencies；依赖 ID 不加入 discovered、expanded 或可引用 records，也不序列化给模型。完整性只可保持或降低，不能将之前不完整的上下文变为完整。既有 EvidenceStore 继续负责更正、删除和撤权清除。

收据预算为 1,000 个不同证据 ID。缺失、非法、成员无法证明、无成员或超出预算时沿用不完整依赖的保守规则。外部插件不提供收据时继续兼容旧行为；公共 HTTP/MCP 资料响应不增加此字段。

## 取代检查

| 类别 | 处理 |
| --- | --- |
| KEEP | 原文、作者和意图由模型解释；捕获内容是不可信证据。 |
| KEEP | 查询只读、来源与范围校验、原图授权、精确引用、资料版本及隐私删除。 |
| KEEP | 历史回答依赖不完整时保守清除；聚合工具及已有上下文的不完整性不被新收据覆盖。 |
| CHANGE | 已披露的有界 Material 元数据和正文，记录完整宿主依赖后可保留不受相关变更影响的回答。 |
| REMOVE | 仅因使用 Material 工具就无条件标记整个回答依赖不完整。 |
| EXCEPTION | 收据证明范围只用于失效；分页预算未披露的原文仍不能读取、引用或作为 Memory 输入。 |
| EXCEPTION | 没有完整收据的旧问答不会被迁移成完整，也不会恢复已经清除的正文。 |
| UNKNOWN | 原先清除事件的精确触发事务、整库所有聚合路径及实际模型完整旅程仍需验证。 |

同步检查覆盖 EvidenceReader、MaterialStore、ContextReader、Bridge、问答删除回归、分页披露预算及架构文档。模型工具提示、UI 导航、来源设置和后台自动尝试次数保持原契约。验证见 [回归记录](validation/audio-output-and-query-lineage-2026-10-08.md)。
