# 原生客户端导航与设置

当前导航采用 [Slate 设计](ui-slate.md)，共享颜色来自 `packages/shared/design-tokens.json`。

- Android 底部为今天、资料、问一问、本机；本机页管理采集、随手记、来源与设置。中央资料和问答通过共享 WebView 会话访问，另行登录中央。
- macOS 保留本机采集、随手记、本地来源与记录入口，设置集中连接、同步、存储、隐私及开发诊断；中央界面在独立窗口打开。
- 中央 Web 的一级入口为今天、资料库、问一问、行动、连接，运行与模型配置位于系统管理。旧 hash 由 `apps/web/src/navigation.ts` 兼容映射。

保存采集设置后按原开停意图协调执行，目录更改包含已有本机记录迁移。详见 [设置与图片位置](client-settings-and-storage.md)。下面的 2026-09-14、0.8.0 验收记录对应当时导航，不能当作当前页面名称清单。

## 验收清单

以下是回归验收要求，不是已经执行的测试记录。构建、合成 fixture、模拟器、真机与真实模型的结果应分别报告。

| 范围 | 应有行为 |
| --- | --- |
| 首次打开 | 默认停留今天；未配置连接时能直接进入连接设置；不会自动开始采集、请求相机或日历权限。 |
| 主导航 | 一次只显示一个目的地；选中项清楚；切换后标题与返回位置明确。 |
| 页面状态 | 未保存设置与随手记输入在页面切换后保留；恢复设置不清空已保存笔记或队列。 |
| 设置保存 | 所有分类使用同一份配置；无效输入定位到所属页面；运行中保持原有配置修改限制。 |
| 连接返回 | 扫码或邀请成功后显示新节点与设备名称；手工改为另一节点仍清除旧凭据，队列目的地保护保留。 |
| 随手记 | 编辑、离线保存、失败重试与页面重建恢复保持原有行为；隐藏页面不重复绑定草稿监听。 |
| 隐私 | 应用分级、排除、遮罩和文字审查设置完整保留；安全窗口与权限边界保持原有行为。 |
| 来源 | 文件、目录与日历入口可用；编辑现有来源时展现对应设置；进入页面不自动授权。 |
| 开发者选项 | 普通设置可以找到入口；诊断导出、模型参数、调试接口与环境信息可达。 |
| 更新 | 关于页可达；当前 DEV 提供手动下载入口，同包覆盖安装保留数据；安装前保护尚未保存的输入。 |
| 桌面键盘 | `Tab` 不进入隐藏页面，当前导航有可访问名称；`⌘,` 打开设置，错误字段可被聚焦。 |
| 窗口与字体 | 最小桌面窗口、手机窄屏、系统大字体与软键盘弹出时，标题、操作和导航不被裁切或遮住。 |

自动化界面验证只使用新建隔离配置和合成内容；截图只包含应用生成的 fixture 界面。未获得明确授权时，不对个人设备进行真实采集，也不使用个人屏幕作为测试材料。

- Android API 35 专用 fixture 模拟器：3 项 instrumentation 检查通过，覆盖配置与随手记分离、跨页输入与旋转恢复、隐藏无效字段定位、安全窗口标记、加密草稿重建恢复，以及四个主页面的生成界面渲染。模拟器以 `-read-only -no-snapshot` 启动，退出后丢弃临时变更。

- 整个 npm 工作区类型检查与生产构建通过，涵盖共享协议、服务端、Web、Mac TypeScript、Swift / C++ 助手和图标。
- 桌面最终完整回归 **164 项**通过，包含超限心跳聚合、暂停来源的等待状态与显式同步收尾心跳。本机显示真实待传总量，心跳数量按协议上限发送。
- Electron UI、中文输入和连接 fixture 通过：无 URL / 令牌时可请求本地采集（采集 IPC 为测试桩）、四种上传选择、预设保存、合成应用选择器、遮挡滑块、首次积存归属确认、合并笔记与来源待传数量、跨页输入保留和最小窗口布局。
- 桌面真实端到端 `apps/desktop/scripts/offline-sync-smoke.cjs` 通过：Electron preload / main IPC → 临时真实 Mote 服务端与 SQLite。无 URL 时先保存合成笔记和文件，首绑必须确认，手动模式零自动请求，明确上传后两类原始记录获得真实 ACK 并清空待传；中央最终上报为 `manual / idle / 0`。有新待传时更换节点被拒绝且原内容保持。测试阻止真实屏幕采集，并以测试适配器替换 Keychain。
- 共享协议 **16 项**、服务端 API / 元数据 / 连接 / 配置与同步心跳集成 **35 项**通过，覆盖状态保存与重启恢复、旧客户端兼容、参数边界和认证。

- Android development 构建、**60 项 JVM** 与 **14 项 instrumentation** 全部通过，0 失败、0 跳过。其中 10 项覆盖无 URL 加密笔记与生成活动采集、首次绑定和目的地保护、四种策略、来源元数据注册、手动失败不自动重试、错误 ACK / 断连留存及 25 条分块最终 idle；另有 3 项导航 / 应用选择器 / 生成预览检查和 1 项加密草稿重建。专用 API 35 模拟器以只读、无快照方式运行，测试后已退出；原 AVD 未删改。
