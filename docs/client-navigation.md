# 原生客户端导航与设置

2026-10-26：当前导航、首页、页面职责和 A–N 决策统一以 [用户旅程与 UI](ui-user-journeys.md) 为准；[UI IA v1](adr-ui-ia-v1.md) 记录导航与已实现协议。本文不再维护另一份当前导航清单。

当前默认入口分别为 Central 总览、Mac 工作台、Android 首页；活动与同步详情是二级路径。保留显式深链、恢复位置、草稿、原生行为和全部既有能力。首页状态紧凑，必要异常直达详情；日常内容、专业配置、内部执行诊断分层，权限与暂停操作仍易于找到。

2026-10-15 的资料库／内容默认导航和 2026-10-11 的行动优先导航均为历史。以下实现细节和验收记录保留当时名称，只用于理解原生行为、能力与安全约束，不能覆盖当前旅程，也不代表本轮重新通过验证。视觉历史见 [UI presentation ADR](adr-ui-presentation-packs.md) 和 [展示落地记录](design/ui-presentation-rollout-2026-10-15.md)。

## 既有能力与历史实现说明

飞书云同步由中央执行；macOS 飞书入口打开中央 Web 的连接配置，Android 打开原生中央配置。授权、首次预览与范围确认见[飞书接入](lark-integration.md)。

同步文件夹默认持续检查变化；导入文件默认只完成一次发现，单文件仍可明确选择以后修改也自动同步。单次发现完成后，已有待传版本继续按原策略发送；不能通过停用来源阻断这次导入的后续发送。首次没有中央连接时可先保存在本机，连接时仍确认积存资料的目标归属。

Android 文件任务的选填资料说明以来源元信息保存，修改作用于已有和未来资料，单份归属纠正仍优先。它不直接创建全局 Memory，也不自动重新转写或重算历史收费任务。旧来源的选择、过滤、保留方式及持续同步设置保持不变，详见[文件任务与来源说明决策](adr-file-source-context.md)。

中央录音来源详情页和通用来源管理提供同一套选填资料说明，使用该来源的版本化上下文。录音页主保存操作与同步、重试、断开分开；只修改说明不会重启录音导入。说明确认后才提交更改的同步范围，详见[录音来源设置](recorder-connectors-design.md#来源说明与保存)。

任务确认页保留读取范围、已有内容、完整文件的去向和原件保留方式；采样间隔、质量、去重、OCR、打包与诊断留在高级配置。“中央提取正文，不保留原件”仍会发送完整文件，不能写成只上传摘要。

首页用「个人资料库」说明用途，并把本机保存、中央整理、回看和提问的关系放在添加动作旁。Android 文件任务只有地址而没有连接凭据时，仍说明先保存在本机；填写的地址不等于可发送的连接。Mac 未连接中央时，问一问保留输入并提供连接入口。

原生首页、添加、内容和笔记呈现真实来源和原文，历史视觉迭代见 [原创性续迭代](design/ui-originality-2026-10-13.md)。Android 本轮采用统一的原生表面、动作、表单与阅读角色，页面职责与视觉标准见 [反馈续迭代](design/ui-focus-and-consistency-2026-10-13.md)。Android 首页“最近内容”与本机内容页使用相同的全部来源读取方式，包含现存的本机随手记；屏幕日期浏览仍保留原有来源筛选。

用户再次指出三端美术风格断裂后，视觉工作形成 [五轮共同风格候选](design/ui-art-direction-five-rounds.md)，新增跨端统一美术风格指标。2026-10-14 用户选择第五轮作为 [三端全面落地基础](design/ui-rollout-2026-10-14.md)。共享颜色、字体层级、间距、表面、控件和阅读角色；保留上述任务入口、权限及状态责任。历史五轮和模型评分保留，不改写为新的用户研究结果。

Android 从首页打开本机原文时，“关闭详情”只关闭实际对话框，回到该来源和日期的记录页；再点原生返回回到原首页。不会把对话框关闭冒称为直接返回首页。Mac 的原文关闭仍回到原页面与所选条目焦点。

普通设置围绕配置、验证与维护，不承接开始一条记录。Mac 设置族隐藏通用添加主动作。Android 的采集开始 / 暂停、实际运行状态与同步操作位于已有首页的来源 / 同步区域，设置直接显示语言、连接、隐私、权限及维护入口。暂停整体采集与暂停屏幕 / 应用活动分别标明范围；保存配置仍按原有开停意图协调执行，不因此开始采集。设置中有关的配置测试、备份恢复与明确带入的原任务返回保留。

内容详情区分“本机已保存”“中央已收到”和实际处理输出。接收凭据不代表已可搜索；处理与索引状态来自中央真实记录和 Material。缺少中央连接、接口不支持或查询失败时显示对应限制，不推断处理已经完成。暂停屏幕、暂停来源和暂停全部发送分别说明作用范围；暂停和离线均保留已有内容。暂停全部发送独立保存，不更改原发送策略；期间本机记录与来源检查继续，立即同步、来源写入和心跳也受暂停保护。

资料库使用 `#/library?view=<type>` 显式选择类型；这些链接保留资料类型与浏览历史，证据链接仍可直接打开与前进/后退。已安装且受信任的 UI 扩展从资料库工具、来源与连接或设置入口发现。

设备页呈现最后一次收到的采集与同步状态；启动、暂停和隐私范围仍在设备本机操作。长时间没有上报不等同于停止采集。

中央的「全部功能」目录按用户目的给出主入口、相关设置及高级操作，是首页的次级入口；旧 `#/guide` 地址继续可用。目录不再嵌入开始任务的面板，普通设置直接说明配置和维护。链接依赖实际安装的受信任 UI 注册项及中央精确版本的能力清单；未安装、不兼容或暂无法确认时说明限制。明确请求的资料类型失效时保留该类型并显示不可用，不改为其他内容。设置分类、来源接入、厂商详情和插件页签保留 URL 状态与前进/后退；未保存草稿仍先确认，改回原保存值不产生离开警告。

Web 功能目录先展示四类用途索引，键盘跳转同时把焦点移到对应标题。Mac 的「全部功能与设置」打开中央 Web 的目录；Android 在中央内容页提供其已有原生功能的分组入口，并明确支持范围，不把该菜单称为完整 Web 能力清单。入口不会因 Activity 重建再次自动弹出。

Coding 会话的已发布正文属于「全部资料」。接收事件数、原件字节、发布、索引与 Memory 进度是同步状态，Web 来源目录提供同步状态入口，活动的高级区域保留接收凭据；不再以「Coding Agent 上传」作为独立的可见上传入口。Android 的更多功能与内容类型选择器也不把该传输状态列为资料类型；旧 Coding 页面和集合链接继续可用，并明确显示同步状态标题。网页不能启动 Mac 采集，来源目录说明在 Mac「来源 → 连接 Coding Agent」选择实际 Agent。接收成功或流水线完成不代表会话正文覆盖完整。

较长的同步步骤、处理队列、技术详情和高级设置使用摘要、折叠与可滚动区域，并保留真实分页及键盘访问。原始状态码在技术详情中可见，未知错误不推断原因。模型入门依次帮助检查已有连接与相关模块，不强制创建新预设、修改全部模块或付费测试。自动记忆的暂停 / 恢复在「自动记忆与插件」，配方、历史处理和执行并发在「模型与服务 → 模块与模型」的高级区域。

记忆页的执行队列摘要使用真实后台 Agent 数量，展开后保留各条独立队列；读取失败时不展示旧数量，错误在折叠区域外仍可见。三端五轮 UI 迭代的实际验证与限制见 [2026-10-13 验证记录](validation/ui-iterations-2026-10-13.md)。

Agent 视角的片段正文按实际返回字符范围继续展开。每页读取先经过同一 Agent 资料暴露检查，再核对精确版本及设备、时间范围；原始证据续读与片段续读分别验证。相关回归见 [中央功能发现与高级操作旅程](testing-central-discovery.md)。

保存采集设置后按原开停意图协调执行，目录更改包含已有本机记录迁移。详见 [设置与图片位置](client-settings-and-storage.md)。下面的 2026-10-02、2026-09-14、0.8.0 验收记录对应当时导航，不能当作当前页面名称清单或本轮重新验证的结果。

## 验收清单

以下是回归验收要求，不是已经执行的测试记录。构建、合成 fixture、模拟器、真机与真实模型的结果应分别报告。

| 范围 | 应有行为 |
| --- | --- |
| 首次打开 | 按当前端职责进入总览／工作台／首页；无需先配置屏幕或节点即可保存本机笔记和文件任务；尽快引导真实资料连接闭环，不强制模型或 MCP，不自动开始采集或请求系统权限。 |
| 主导航 | 一次只显示一个目的地；选中项清楚；切换后标题与返回位置明确。 |
| 页面状态 | 保留各端既有设置草稿的确认与生命周期规则；随手记输入能恢复；还原设置不清空已保存笔记或队列。 |
| 设置保存 | 所有分类使用同一份配置；无效输入定位到所属页面；运行中保持原有配置修改限制。 |
| 页面职责 | 设置首屏及子页不显示通用新记录动作；纯设置访问没有虚构的提问返回任务。Android 首页状态直达采集与同步详情，设置无需穿过运行仪表盘。 |
| 连接返回 | 扫码或邀请成功后显示新节点与设备名称；手工改为另一节点仍清除旧凭据，队列目的地保护保留。 |
| 随手记 | 编辑、离线保存、失败重试与页面重建恢复保持原有行为；隐藏页面不重复绑定草稿监听。 |
| 隐私 | 应用分级、排除、遮罩和文字审查设置完整保留；安全窗口与权限边界保持原有行为。 |
| 来源 | 文件夹和文件从首页可达，日历与已有其他来源仍可管理；取消选择不建任务，重复范围不重复建来源，并能找到原来源设置；进入页面不自动授权。 |
| 单次与持续 | 单次导入完成后不再发现修改，离线待传和重启恢复仍可发送；保存原始版本与完成标记之间发生中断，也不能重读后来修改的文件；持续来源按原调度发现新版本。 |
| 内容状态 | 本机原文可读，真实 ACK 与中央处理分别展示；权限、网络、未处理、索引失败及归档清理各有实际依据。 |
| 暂停边界 | 暂停屏幕不停止文件来源或发送；暂停来源保留其待传资料；暂停全部发送阻止自动、立即同步及心跳，取消未确认传输而不停止本机记录、来源检查或改动草稿；恢复仍遵循原策略。 |
| 开发者选项 | 普通设置可以找到入口；诊断导出、模型参数、调试接口与环境信息可达。 |
| 更新 | 关于页可达；当前 DEV 提供手动下载入口，同包覆盖安装保留数据；安装前保护尚未保存的输入。 |
| 桌面键盘 | `Tab` 不进入隐藏页面，当前导航有可访问名称；`⌘,` 打开设置，错误字段可被聚焦。 |
| 窗口与字体 | 最小桌面窗口、手机窄屏、系统大字体与软键盘弹出时，标题、操作和导航不被裁切或遮住。 |
