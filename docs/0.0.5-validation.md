# 0.0.5 验收记录

本次模型适配与配置验证使用临时资料库、合成凭据、生成记录和本机模拟模型服务。没有调用真实厂商模型，没有将个人截图、OCR 或笔记用于测试。

## 模型与后端

- 共享库、Agent、服务端与 Web 构建、全工作区 TypeScript 检查通过。
- 全工作区自动化测试通过，覆盖桌面、中央节点、Web、Agent、诊断、本地推理和共享协议；新增协议与探测用例随后定向复验。
- 五种协议均经过真实 Harness 的工具往返验证，未用模型名称或问题关键词分发。通用协议 fixture 覆盖多轮工具结果、Chat 思考字段、Responses 加密推理内容、Anthropic 签名块和 Gemini 思考签名回传。
- OpenAI、Azure、MiniMax 使用相应输出 token 字段；Azure 使用 `api-key`。Responses 固定 `store:false`，远程模型要求 HTTPS，请求拒绝重定向。测试验证高级参数不能覆盖证据、系统提示、工具和输出限制。
- 模型配置事务覆盖原子持久化、重启恢复、并发 revision、显式凭据复用、写入失败、提交后不确定状态及恢复部署配置。API 测试验证采集凭据不能读写模型配置。
- 热切换 fixture 保持旧问答运行，后续问答立即使用新配置；生效配置投影同步更新，调用方启动配置不被修改。
- 连接测试通过实际 `createAgent`、Harness、本机 SSE 模型的「检索 → evidence → 引用回答」完整链路。测试 reader 与资料库独立，另有归档哨兵检查，确认不读取归档内容。
- 错误响应、配置投影、资料导出与安全支持包不回传模型 API key、请求头或高级参数原文。
- 生成 Mac／Android 图片到中央归档、模型检索和便携导出导入的端到端检查通过；隐私网关 22 项合成检查通过，升级与安全脚本回归通过。

## 界面与发布门禁

Web 单元测试覆盖模型草稿、协议与地址、凭据替换／清除／复用以及旧部署配置草稿行为。中央导航 fixture 已扩展为真实临时服务端的保存与恢复，探测和 revision 冲突使用生成响应，检查敏感输入清空、桌面和手机布局。

本机完整 Electron 界面回归受 macOS 锁屏阻塞：首轮已进入模型页面，后续进程停在 `app.whenReady()`；没有解锁、改变系统权限或绕过测试。发布流水线在干净 macOS 环境重新运行完整导航、设置、连接和资料浏览 fixture，任何失败均阻止公开 Release。

发布同时要求 Linux 项目检查、Docker 集成、Android JVM 与两变体 lint、Mac 打包和签名检查通过，再生成带签名的更新清单。Android 版本码为 16；既有客户端逻辑保留，新增设置需要 0.0.5 中央节点。

## 验证边界

协议 fixture 验证传输、工具链和隔离，不代表每个厂商账户、地域或模型都已完成实网认证或回答质量验收。用户仍需填写实际可用模型，并可主动执行连接测试；该操作可能产生模型费用。

本轮没有进行 Android 真机采集、耗电测量、真实大模型质量评估或个人屏幕采集。Mac 和 Android 的原有客户端回归由自动化及发布门禁覆盖，不将其表述为真机检查。
