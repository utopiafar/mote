# 采集隐私与元数据

用户决定采哪些应用和来源；模型理解已获准内容，程序执行精确隐私过滤、权限和传输校验。应用时长、截图、结构化内容是独立选择，不按应用名称或正文猜工作、娱乐或敏感类别。默认仅活动的应用不读取画面、窗口正文或OCR；明确关闭的应用不补算空白时间。

## 本机边界

应用规则按package/bundle ID精确匹配。用户指定的排除和限制在取得画面前检查；无法确认身份而可能绕过限制时跳过。无身份画面不伪造应用归属。固定遮挡与可选文字规则先于保存/上传；字段失败不会扩大截图权限。

文字隐私规则是用户明确填写的精确包含过滤，不承担语义分类。规则为空或关闭时不调OCR；明确命中丢弃。识别异常按用户失败策略处理，默认暂存待复核，不能靠重试、重启或关开关自动放行。查看后明确允许或丢弃。隐私OCR文字不写入新截图事件，也不冒充中央OCR结果；旧端侧VLM/额外审查URL不再执行。

截图、字段、通知、媒体、日历和文件各自授权；屏幕暂停不撤销其他来源。系统授权也不自动开始采集。Android媒体仅活动规则不保留曲目等内容，通知正文不借媒体会话通道上传。具体平台能力见[Mac](desktop.md)、[Android](android.md)和[采集与同步](collection-and-sync.md)。

收紧采集范围后，已确定超范围的待传内容停止上传是已确认方向；当前屏幕队列仍保留旧策略的部分尚待对齐。删除本机副本和Central历史按明确范围处理。现有归档不会因改开关被无声改写。

## 元数据与时间

应用记录保留系统实际提供的`appId`和`appName`；未知名称标注未知，不制造身份。设备元数据可关闭，必要的传输身份、时间和隐私级别仍保留。可选状态包括电量、充电、网络类别、屏幕交互、系统/机型和本次采集方式；不附带序列号、IMEI、硬件MAC、SSID、密码或定位。

每份状态有自己的`observedAt`。缺失不是false或零；最后心跳也不证明持续在线或持续采集。媒体的播放状态/位置是提供方报告，不证明用户听到、注意力投入或读完。设备观察、文件创建/修改/访问、日历计划和事件发生时间分别解释，不能互换。

文件系统ctime不是创建时间，访问时间可能由同步器更新。SAF/网页选择器只保留实际可得字段。完整扫描的缺失只表示本次观察不到；权限、范围或扫描失败不作为删除。日历区间保留其时区/全天边界，不加入屏幕活动时长。

独立时长区间同设备先去重，不同设备分别计入。截图/字段/心跳附带快照不重复增加时长；应用切换、停止、锁屏、过滤或失败断开计时。元数据不能硬编码推断任务完成。详细字段由[协议](protocol.md)和[共享schema](../packages/shared/src)定义。

## Central处理与披露

Central保留获准原件，OCR、视觉解释和Memory是分开的版本化产物。新截图默认走受管理OCR；缺模型等待，原件不丢。空文字可以是成功识别到零段，不等于失败。安装/升级不回扫全部历史，历史预览与重试有明确范围；见[媒体准备](media-setup.md)和[处理](processing.md)。

后台模型授权和查询原图披露分别检查。`allowQueryImages`默认关闭；模型按需请求本轮已发现的获准原图，不接受任意路径或URL。文字/OCR不能代替像素证据，不支持图像的模型明确失败。查询和MCP工具保持只读；外部效果通过授权Actions。

当前身份、来源/设备/时间范围、版本、归属、删除和所有依赖在读取/发布时重新检查，缓存缩略图或旧引用不绕过撤权。归档原始元信息只在获准详情中展开；支持包使用固定安全字段，不把正文、应用名、凭据或个人路径当日志。存储保护见[content storage](content-storage.md)，证据契约见[Memory](memory.md#query-and-disclosure)。
