# 对话历史与继续提问

在中央网页打开「问一问」，完成的回答和失败轮次都持久保存在中央节点。历史列表按最近回答时间排列；选择旧对话即可查看完整问答并继续提问。「新对话」开启独立上下文，「删除此对话」清除该段历史。

切换页面、刷新浏览器或重启中央节点都不会删除已完成的对话。回答失败时保留已有历史，当前问题留在输入框，可以修改后重试；如果网络超时，先刷新历史检查服务端是否已完成回答。生成过程中离开页面后，服务端仍可能完成并保存回答。

首次读取历史、打开尚未加载的对话和展开更早的轮次时显示加载提示。已有内容的后台刷新保留对话、输入草稿和焦点，不重复显示首次加载提示或禁用输入；已确认没有待补充问题时，该区域在轮询期间保持隐藏。普通资料版本变化保留旧回答与引用，并提示当前资料已更新；普通删除保留已提交问答和引用身份，提示「引用原文已删除，历史问答仍保留。」。明确隐私擦除、忘记、到期清理和撤权仍清除或阻止相关内容。

时间与设备筛选用于下一次提问。打开旧对话会恢复它上次选择的设备；时间仍使用页面顶部当前选择。模型结合前面对话理解指代，再在当前筛选范围内检索原始证据。

主对话历史不设 200 轮或 4 MiB 的总量上限；单条提问仍受请求大小限制，界面按页加载（每页最多 50 轮），发送给模型的是工作记忆摘要加最近轮次，默认上下文预算 24,000 字符、摘要预算 6,000 字符、保留最近 8 轮不做周期压缩，实际近期历史最多 20 轮。预算可在记忆设置调整，压力下会尝试在线压缩；单条旧回答最多取 20,000 字符，遗漏显式标记。摘要是对话上下文，不授予未读取原件的引用权限。历史回答可以用于理解当时的提案和用户取舍，携带版本变化或原文不可用状态；当前事实仍需读取有效证据。摘要保留原始隐私依赖，后续隐私擦除或到期仍清除使用过该历史的回答，撤权仍阻止向模型发送相关内容。

历史仅允许中央节点所有者访问，设备配对凭据与 MCP 凭据没有管理对话的权限。历史存入中央 SQLite，并计入资料库容量；完整离线备份包含对话，网页 HTTP JSON 资料导出不包含对话。

普通删除记录、笔记、导入内容或外部来源报告原文已删除，不会清除已提交历史问答。引用保留保存时的身份和摘录；点击时重新检查可用性，不能经旧引用打开已删除原文，也不会转到新版本。本轮详情保留运行、用量、工具次数和已读身份等元数据，删除工具参数中自由文本和原文载荷。历史保留不恢复原文、已擦除内容或新检索权限。外部来源删除后，中央已有的独立所有者不可变归档入口仍按原合同工作；历史引用入口与模型原文读取不因此放行。中央普通删除则物理删除原文。

「仅查这条记录」的已选范围也保留。续聊只从有本会话删除证明的范围中排除不可用原文；部分资料可读时仅查剩余资料，全部已删除时工具层禁止查原文和全库检索，只能讨论已获准的历史问答。用户显式清除范围后才恢复普通检索。未知缺失、隐私忘记或撤权不能冒充普通删除。明确「中央忘记此文件」、来源忘记和保留期限清理仍清除相关回答及摘要，用户提问保留。

## API

- `GET /api/conversations?limit=30&cursor=…`：分页读取历史摘要。
- `GET /api/conversations/:id?limit=20&cursor=…`：分页读取问答，默认 20 轮、最多 50 轮，使用 `nextCursor` 读取更早内容。
- `GET /api/conversations/:id/references/:evidenceId`：所有者检查保存的引用或范围身份，返回 `{id,available}`；不返回原文。客户端历史引用点击须先检查，`available:false` 时留在原对话显示不可用提示。
- 网页用 `POST /api/query-runs` 提交并读取持久进度，见 [进度协议](usage-and-query-progress.md)；兼容的 `POST /api/query` 传入 `question`；可选 `conversationId` 表示续聊。返回答案、`conversationId` 与 `turnId`。
- `DELETE /api/conversations/:id`：删除一段对话。

续聊省略 `timeZone` 时继承上轮时区；`after`、`before`、`deviceId` 省略表示本次未设置该硬范围，不继承上轮过滤。`evidenceIds`/`anchorEvidenceIds` 省略时继承已选范围；显式 `null` 清除对应字段。当前问一问页面没有独立硬范围筛选控件。同一对话同时生成第二条回答会返回 409，避免互相覆盖。

## 加载状态回归

`apps/web/test/read-state-closure.test.ts` 覆盖首次读取、后台刷新、切换未加载对话、恢复已完成运行时的读取合并，以及证据删除、版本变化和撤权。`apps/web/test/owner-questions.test.ts` 覆盖空补充问题列表的定时轮询、新问题出现、失败重试和分页。

构建 Web 后运行 `node_modules/.bin/electron apps/web/test/ask-loading-browser.cjs`，通过真实网页入口和生成 API 响应验证首次进入、持续变更通知、5 秒空列表轮询，以及草稿和输入焦点保留。浏览器默认隐藏；此测试不访问正在使用的中央节点，不读取私人资料，也不调用真实模型。

普通版本失效与隐私清除的责任、历史续问权限和取代检查见 [历史保留 ADR](adr-evidence-history-retention.md)。
