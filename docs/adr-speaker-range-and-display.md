# ADR: Scoped acoustic candidates and transcript presentation

Status: Accepted by the owner, 2026-10-13. Initial live acceptance is limited to five selected recordings whose owner declared a range of one to three participants.

Add the optional, hash-pinned WeSpeaker Chinese embedding component, independently of the installed Whisper ASR and pyannote segmentation assets. Installation does not select it. Existing default profiles, unknown speaker count and `audio.diarize@3` retain their configuration and cache identity. `audio.diarize-wespeaker@1` supports unknown, exact count, or an explicitly declared range; an unknown recording never inherits the pilot's range. Full configuration identity fences publication; extraction cache identity excludes acoustic parameters and uses an independently pinned ASR version. The legacy ASR version string remains its cache identity for compatibility.

A range is owner-supplied context, not an exact count. First obtain automatic acoustic clustering at threshold 0.5. Preserve automatic zero/one-label output when the range includes one; otherwise evaluate explicit K candidates from max(2, minimum) through maximum (K=1 for an exact range of one). Rank eligible explicit candidates by duration-weighted silhouette. The single-cluster sentinel is unavailable, never a zero or probability. Preserve automatic and alternate candidate intervals, internal K, actual output labels, score gap, model hashes, runtime and numerical parameters. All range estimates require listening confirmation, including automatic single-label output. If no candidate meets the range, retain the automatic evidence with a warning. No identity or semantic attribution is inferred by deterministic code.

Owner-only per-file acoustic overrides require the current raw transcript artifact. They persist across restart, are included in generation fencing, and never alter global policy or another file. Explicit acoustic reprocessing reuses matching raw extraction, invalidates downstream acoustic/name confirmations through the existing pipeline, and retains old artifacts. It requires a currently authorized original or recoverable temporary snapshot input. It neither changes retention nor retrieves a disconnected phone's audio. Setting the override to null clears it; explicit full transcription retains it until cleared.

Display grouping joins adjacent known anonymous labels within 1200ms and with matching overlap state, artifact and owner-confirmed attribution. Uncertainty changes do not split the display, but every child's uncertainty, text, ID and coordinates remain available in an expandable group for correction and seeking. Unknown labels and untimed text remain separate. Loaded pages are combined before display grouping. Canonical evidence and Memory references do not change due to this presentation alone.

| Disposition | Inspected responsibility and assumptions |
| --- | --- |
| KEEP | Central execution engine, cancellation/unknown-call guards, original-byte hashes, snapshot recovery, ASR word coordinates, privacy/retention, owner-confirmed identities, correction/Memory lineage, existing optional summary and semantic grouping policy. |
| CHANGE | Optional acoustic model installation/startup/health, profile and per-file count constraints, diarizer fingerprints/receipts, range candidate provenance, expandable transcript display and stale name forms. |
| REMOVE | Installed ASR implies optional embedding is ready; range equals exact owner count; internal K equals observed people; uncertainty changes require separate top-level display rows. |
| EXCEPTION | Legacy defaults and results remain; a range estimate is experimental and requires listening. Failure to meet the range preserves evidence, not invented labels. No successful ASR or paid semantic task is automatically rerun. |
| UNKNOWN | True per-file people counts, time-level speaker truth, recognition accuracy and generalization beyond generated controls and the five selected originals require separate human/live evidence. |
