# ADR：Memory 上下文预算与可引用正文

> **状态：历史。** 本文记录当时的决定与验证范围，不再描述当前实现；当前设计见 [Memory 当前设计](memory-current-design.md)。

日期：2026-10-12。状态：采纳。

2026-10-13 的[范围评估 ADR](adr-memory-range-evaluation.md) 将新配方的逐范围评估与候选选取分开。2026-10-14 的[简化决定](adr-ask-evidence-quality-and-simple-context.md) 随后取消本文的宿主字符容量门槛、预算异常及自动二分责任；无损上下文、精确正文、当前授权和独立审核继续保留。下文的额度与分拆描述记录当时决定，不能作为当前恢复规则。

## 用户旅程与决定

所有者要求修复扩大样本检查发现的复核上下文超限、序列化引文不匹配和不具体的输出修正反馈；保留独立复核、精确引文与完整范围检查。验证先恢复失败长录音，再检查少量代表资料，不自动付费重做历史库。

MemoryPipeline 继续持有完整的成员身份、授权、声明版本、检查历史及发布指纹。Agent 只在请求序列化时进行无损投影：相同归属上下文用局部字典共享；授权目录对完全相同的已列出成员用引用表示，并保留额外 scope。不同声明或版本不合并。模型必须按成员的引用解释范围，局部引用不建立本人身份或扩大读取权限。原件、目标范围、历史检查结果和提取草稿都不截断。

在启动模型会话/运行器之前，对最终序列化请求检查既有 80,000 字符任务预算和 180,000 字符输入预算。预算不足抛出带数值测量的 `AgentContextBudgetError`，不包装成供应商错误。Memory 沿用既有有界分段机制，保存父范围的未完成覆盖、为子范围保留授权与语境，每个子范围重新提取并独立审核。不可再分的范围保留 `host_context_budget` 失败，不重试相同请求，不保存或检查点化未审核范围。

内置 source-item 构建器升级到 12、来源配方升级到 2。`source-record` 为字面正文，元数据存入独立 `source-metadata` 块；source-body 和 source-record 工件只指向正文；有正文时，传输元数据块不授予独立原件引文资格；没有正文的文件仍保留原有 source-record 元数据索引输入，source-body 仍不可用。无 provenance 的 authored 构建器升级到 4，正文与元数据也分离。带说话者/图像定位的文件段使用声明的 `speech-text` 格式：第一行是结构元数据，之后是未转义的字面正文。该段保持原有一个块、原有分段与时间轴；展示层根据声明格式分离结构信息，不从任意正文猜 JSON。新格式的正文坐标直接指向块中的字面字符，旧 JSON 格式的解码和坐标保持不变。

投影变化创建新 Material revision 和 evidence anchors，不改写旧块、旧引文、偏移或草稿。已经固定旧版本的任务不能混用新坐标；明确重做已有正文时先生成新资料版本并按该版本授权。首次部署的历史投影 backfill 必须考虑所有者的处理范围；本次本地升级在停机窗口固定新构建器的历史扫描边界，仅显式选中的资料重建，新到达资料正常使用新投影。此为本次部署操作，不修改通用 backfill 行为。

输出修正保留当前验证链，反馈增加宿主 schema 字段路径、错误类别和实际候选容量。只允许 schema 固定字段名和数值位置，不回显模型提供的坏值或未知键。schema/coverage 提示一致要求完整对象、当前容量及四种覆盖状态，包括必要的 needs_owner_input。不猜测或补写证据 UUID，不模糊匹配，不改变三次会话内修正上限。

## 取代检查

| 类别 | 决定 |
| --- | --- |
| KEEP | 原件、精确引文、独立审核、所有目标范围覆盖、本人归属判断、声明版本、授权和迟到提交 fence、只读工具、预算及修正次数上限。 |
| CHANGE | 模型请求中的重复元数据表达；预算拒绝的类别与测量；内置正文投影版本；完整契约和字段级修正反馈。 |
| REMOVE | 把宿主预算失败当作供应商失败；把宿主包装 JSON 中的转义字符当作普通正文的引用坐标；工作包修正提示中的固定八候选限制。 |
| EXCEPTION | 旧版本 JSON 仍是旧 anchors 的精确证据；正文自身含有 JSON 时保持字面内容；新的结构化语音头部仍是元数据而非说话者身份声明。 |
| UNKNOWN | 模型可能仍抄错 ID、误解身份或漏掉语义候选；真实模型验证必须另行记录。独立复核不等于保证语义正确。 |

细化 [批次上下文 ADR](adr-memory-batch-context.md)、[个人 v3 ADR](adr-bounded-personal-memory.md)。范围控制和历史版本原则不变。

## 验证

合成回归覆盖：大目录＋大草稿的无损共享、不同声明不合并、不可容纳输入在启动 Codex 之前拒绝、分段父任务无产物/检查点、子任务独立审核、不可分输入的准确失败码、从实际 SourceStore/organizer 到 MemoryStore 的换行/引号/反斜杠/Unicode 精确引用、错标点拒绝、旧版本原文保留、旧新语音格式坐标、缺字段/错误 UUID/错误范围 key 的安全反馈。

本地真实模型验收记录在私有 profile 中，不将个人原文或令牌放入版本库。先执行失败长录音的明确 retry，再启动指定代表资料；比对身份问题、宿主预算错误、输出修正、执行重试及所用独立审核版本。整个库不重跑。
