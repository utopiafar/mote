# 页面内容采集与规则贡献

Android 将应用时长、截图和结构化内容作为三个独立选择。`source: ui_page` 表示无图的可见字段观察，使用既有持久队列、批量传输、逐条幂等确认、中央存储、检索与导出。当前 Android 上传格式为 `metadata.uiPage.version=3`。`ocrText` 承载这些观察值的确定性拼接，来源可能是可见文字、安全的无障碍描述、控件状态或明确开启的本机 OCR；它不表示中央截图 OCR 已经运行。

## 按应用配置

Android 和 Mac 用「应用时长」「截图」「结构化内容」三个独立复选项配置默认范围和单个应用，全部取消表示不采集。默认范围适用于没有单独设置的应用，也适用于以后安装的应用。单独设置可以恢复为沿用默认，字段规则的存在或载入不会改变这些选择。

应用列表同时显示已选采集项、默认继承或单独设置，以及结构化规则的状态。可按全部应用、单独设置、字段规则和需处理的应用查看；字段规则列表也保留没有开启结构化的配置，避免把「已配置规则」和「已选择采集」混为一谈。Mac 并排显示应用列表和详情；Android 从列表进入应用详情。

详情集中显示三个复选项、规则可提取的字段、版本要求和当前条件。状态依据本机安装信息、实际配置及对应平台的采集路径产生；缺少安装版本、规则版本不符、读取器不使用某条规则或尚缺系统权限时，不能显示为已经验证支持。已有规则仍需匹配当前页面，规则数量不是覆盖率。没有字段规则也不直接等于不能取得任何结构化内容；另行开启的本机 OCR 和平台专用读取路径分别显示其条件。

修改形成设置草稿，保存后用于后续采样。普通保存不开始已经暂停的采集；首次开始仍经过原有的范围预览及系统授权流程。系统权限与规则可用性不自动取消用户已保存的选择，也不扩大采集范围。

## Android 用户流程

1. 从「按应用配置」选择应用，分别选择应用时长、截图和结构化内容，可任意组合或全部关闭。新安装默认只选择应用时长。加载或导入字段规则不扩大该应用的采集范围。
2. 应用详情显示当前安装版本及匹配的字段规则。规则可以载入、配置或导入；已配置不代表经过真机验证。字段规则按应用、版本和可选 Activity 匹配，仅在已选择结构化内容时运行。
3. 保存配置和普通格式预览不会开启已暂停的采集。预览使用生成示例，不读取个人屏幕。首次开始时审阅应用范围和同步目标；确认后进入权限检查和启动流程。授权后回到原入口继续。
4. 正常使用所选应用。截图选择决定是否保存图片；字段提取成功、失败或没有规则都不改变截图选择。没有选择截图时，不因字段为空而保存截图。锁屏、隐私拒绝、窗口或配置变化、停止采集会使旧结果失效。
5. 可另外开启「使用本机 OCR 补充结构化内容」。它只适用于已选择结构化内容的应用。临时屏幕像素经本机隐私遮罩和检查后识别；未选择截图时，识别后释放像素，不保存或上传图片。本机 OCR 字段与无障碍字段保留各自来源，不据相同文字推定同一对象。
6. 所有接纳的观察先持久保存，上传时机由独立同步策略决定。中央连接不是本机开始采集的前提。投屏模式支持截图及独立时长，不支持结构化字段和结构化 OCR。

同次采样的时长、截图及多个字段观察携带同一 `metadata.captureObservation.id` 和已选择通道。只有独立的活动时长记录累计实测前台间隔；截图、结构化对象和 OCR 观察的 `durationMs=0`，不会按卡片数或关联原件重复计时。观察间隙不补造成连续使用。

## v3 字段规则与上传

规则数组最多 512 条、1 MiB；每条最多 8 个必要节点条件和 32 个命名字段。平台、App 和版本精确匹配。规则只执行结构选择，不运行脚本、网络请求、手势、关键词语义分类或用户意图推断。

```json
[{"formatVersion":3,"id":"generated.message-row","version":"1","platform":"android",
  "appId":"dev.example.chat","appVersion":"1.2.3","kind":"message",
  "repeat":{"resourceId":"dev.example.chat:id/message_row"},
  "fields":{
    "message_visible_body":{"select":{"resourceId":"dev.example.chat:id/body"},"source":"text","cardinality":"many","required":true},
    "quoted_message_body":{"select":{"resourceId":"dev.example.chat:id/quote"},"source":"text","cardinality":"many"},
    "displayed_state":{"select":{"resourceId":"dev.example.chat:id/state"},"source":"state","cardinality":"one"}
  }}]
```

字段名使用 snake_case。`source` 为 `text`、`description` 或 `state`；`cardinality` 为 `one` 或 `many`。标量候选不唯一时不猜测：必要字段失败会拒绝该对象，可选字段则省略。没有观察到实际链接、ID 或标题时，不生成对应值。重复原文不去重，不按相同文字合并消息、订单或帖子。

`region` 必须唯一定位区域；`repeat` 将各容器分别保存；`repeatParent` 限定直接父容器。`ancestor` 限定字段祖先，`childPath` 从容器沿原平台子索引读取，空路径表示容器本身。隐私过滤不会重新编号或把缺失目标换成相邻节点。多个规则可同时产生独立观察，单次最多 64 个对象；超限标明截断。

`repeatSubtreeHash` 是 `SHA256(JSON.stringify([resourceId, role, directChildHashes]))`，按原子索引递归排列子节点。正文、描述、坐标和节点 ID 不参与哈希。过滤后拓扑不完整时允许保守失配，不得删除结构约束来扩大匹配。历史整页哈希含导出专用父 ID，不转换为运行时守卫。

单次读取最多 256 节点、深度 32、总文字 32000 字符及 750ms 软遍历预算；单次 Android IPC 可能超过预算。只读取确认可见、完整落在显示区域内且未受遮罩或遮挡的字段；输入、密码和敏感子树在读取文字前排除。无障碍描述只来自明确匹配且安全的完整可见叶节点，不读取可能包含隐藏后代文字的复合容器描述。本机节点树、像素、坐标和控件 ID 不作为结构化观察上传。

每条 v3 记录含 scope、adapterId/version、App 版本、Activity、status/truncated、observations `{firstAt,lastAt,count}` 及一个对象：`{kind,fields:[{name,values:[{text,source}]}]}`。每个对象最多 32 字段，每字段最多 64 个值，合计最多 128 个值及 64000 字符，单值最多 32000 字符。输出字段按名称的码点顺序排序，值保留观察顺序。本机 OCR 使用 `source: ocr`。`capturedAt` 和 `metadata.observedAt` 等于 observations.lastAt；`ocrText` 等于规范顺序的字段值拼接。

## 中央资料与自动活动

每条接纳的观察立即入持久队列，失败不把未保存内容视为成功。中央按原件组织可读的 `mote.ui-page-object` 资料，保留命名字段、来源、观察时间、规则及应用版本。没有可靠身份的观察独立保存，不凭标题或相同文字进行跨观察语义合并。可见窗口观察始终是部分覆盖，不宣称全文或读完。

「自动整理活动」有独立开关和明确选择的模型连接，默认关闭。启用后处理后续接纳的授权采集原件，使用中央模型组织可读活动资料，保留原始证据与状态变化。它不依赖 Memory 是否启用，也不默认生成长期个人事实。关闭后停止待处理工作并拒绝迟到输出，已保存活动继续保留。历史导入、重建、重复上传和重启不凭空新增处理授权。

Memory 接收仍遵守自身配方、接收凭据、队列及审核。原始字段、正式资料、自动活动、Memory 和只读查询各自保留来源；模型决定事件含义、人物、对象及关联，采集器不以关键词替代。第三方观点和应用生成摘要不自动成为用户观点。外部写入需要对应产品授权。

## 样本与适配边界

[内置包](../adapters/ui/builtin.json) 是唯一规则源，Android 构建复制到 assets，TypeScript 副本由脚本生成。当前含小红书 9.51.0、微信读书 10.2.2、哔哩哔哩 9.16.1、QQ 9.3.75 的 109 个带子树守卫的转换规则、1 个小红书当前可见布局变体及 8 个单独审阅的原生资源 ID 映射；也保留既有文章/商品规则。小红书与哔哩哔哩本次按所有者要求，将此前 9.50.0 / 9.15.0 的声明规则绑定到新版本，保留原选择器、子树哈希与字段路径；具体页面覆盖以真机结果为准。版本变化需要显式重新适配，没有动态脚本或自动放宽机制。

转换器只读取离线声明规则，拒绝不支持的约束并记录排除项。复合描述在 Android 安全门槛下可能被省略，微信读书章节容器等候选可能不产出结果；不能把规则条数当作实际覆盖率。完整来源、限制和排除清单见 [规则说明](../adapters/ui/README.md)。

```sh
npm run build -w @mote/shared
node scripts/ui-adapters.mjs generate
node --test adapters/ui/convert-rule-pack.test.mjs packages/shared/test/named-fields-conformance.test.mjs
node scripts/ui-adapters.mjs replay-all /absolute/path/generated-snapshot.json adapters/ui/builtin.json android
```

提交样本仅保留已审阅的结构事实，正文、描述和坐标均使用生成数据。fixture 分别覆盖正常提取、错误版本、变化拓扑、原始索引、重复值、多个同时匹配规则和安全拒绝。fixture 通过不等于真机适配、实际 OEM 生命周期、权限稳定性或 OCR 质量已验证。Desktop 的具体采集行为由其独立平台实现约束；本次 Android 选择不自动扩展到 macOS。
