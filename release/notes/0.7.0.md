# Mote 0.7.0

- Android 与 macOS 支持按应用设置“采集内容 / 仅应用活动 / 不记录”，默认级别与单应用例外可配置；旧排除规则继续优先生效。
- 仅活动分支在截图前分流，不读取画面、窗口标题或正文；支持离线队列、幂等上传和独立统计。Android MediaProjection 按允许的内容样本挂接画面输出。
- 可配置设备元数据上报，记录实际可得的系统、电池、网络、屏幕与存储状态；文件和日历保留大小、来源时间及删除观察时间，版本可追溯。
- 中央界面可按采集级别筛选、展开元数据；Agent 与 MCP 可读取这些证据，时间统计区分内容与活动采样，不把缺少正文当作 OCR 失败。
- 设备旧健康报告与归档记录分开提供给 Agent；模型查询超时可在服务端配置，超时返回明确诊断，网页查询等待时间随节点设置调整。

请先升级中央节点，再升级客户端。保留原配置、凭据、模型、队列与数据目录，覆盖安装即可；不要卸载应用来更新。新字段不会被旧中央节点接受，未确认的上传保留在本地。

macOS 包适用于 Apple Silicon，当前使用 ad-hoc 签名；Android 分日常版与开发版，沿用原签名。真实设备和测试范围见 [分级采集验证记录](https://github.com/utopiafar/mote/blob/v0.7.0/docs/privacy-metadata-validation.md)，使用方式见 [应用分级与元数据](https://github.com/utopiafar/mote/blob/v0.7.0/docs/privacy-and-metadata.md)。
