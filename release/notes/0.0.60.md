# Mote 0.0.60 DEV

保留 AI 原生个人上下文档案的定位：原始观察持续归档，模型选择检索路径、解释证据，精选记忆服务于问答，不用关键词规则推断人的意图。

- 修复以 `node --eval` 启动中央端时，维护子进程可能继承启动脚本并覆盖 PID 锁的问题；回归检查等待维护进程就绪及退出清理。
- 中央端状态改读事务计数器，磁盘实际占用由独立后台进程测量并提供时间戳；网页按当前页面加载数据，隐藏时停止全局轮询。
- 记忆概览使用独立目录与作用域索引，浏览不再展开历史原文；来源修改、删除及上游产物变化同步撤销相关派生结果。
- 分层处理明确区分原始证据、精确片段、模型解释、精选记忆和长期整理。下游任务只消费显式输入，保留独立溯源依赖；自动记忆从语义产物和少量精确引文提取。
- 交互问答独立于后台 Agent/Harness 队列；提供跨层只读目录、检索与证据展开预算、短时限查询向量及全文回退。
- 处理进度定向更新单批次并节流，任务列表不传所有批次与证据；对话逐轮存储、分页加载，来源列表采用游标。
- Mac 设置保存可取消心跳与同步；Android 停止采集立即更新本机状态，配置切换取消旧网络请求。待传提示统一为“待同步 X 条”。
- Android 普通状态栏、导航栏不再触发 SystemUI 应用规则误拦截；真正的悬浮窗继续接受隐私检查。增加采集记录页启动、重建及返回路径回归，并修复删除 Session 首条记录后旧缩略图未清除的问题。

在本机中央归档的隔离副本（117,467 条既有记录）上验证，迁移前后原始记录摘要完全一致。HTTP 状态接口中位数约 1.2 ms、采集列表约 104 ms；详细方法、范围和真实模型结果见仓库 `docs/validation/0.0.60.md`。性能数字是本机样本，不是跨设备承诺。

MVP 数据迁移在启动时执行，升级前请备份。旧的未完成自动原文抽取任务会退役，新的自动流程从产物日志重新推进；手动导入和原始资料保留。不保证旧版本直接打开升级后的数据库。

本次继续只发布 Mac DEV ZIP 与 Android DEV APK；中央服务从源码部署。未采集新的个人截图，未做实体 Android 设备验证。
