# Mote 0.6.0

本版新增一次性邀请连接和独立设备凭据，并补齐 Android 采集、存储与同步明细。请先升级中央节点，再升级采集 App；原有配置和队列保留。

- 中央「设备」页面生成本地二维码、JSON 邀请与 MCP HTTP JSON，提供每个连接的查看和撤销入口。邀请 10 分钟有效、仅可使用一次，不包含中央管理令牌。
- Android 可扫码、导入文件或粘贴邀请；Mac 可导入二维码图片、JSON 文件或邀请文字。客户端确认节点地址后兑换凭据，原设备身份与隐私设置保留。
- 独立采集凭据仅同步本设备与本设备来源；MCP 读取／指定来源写入凭据单独发放。Mac 内浏览中央资料时使用仅此次窗口有效的所有者授权。
- 同节点重新授权可以保留待同步数据；更换节点前检查截图、笔记和来源队列，避免误传。
- Android 提供持续保存的截图请求、画面入队、笔记入队、确认上传、失败与重试统计，以及最近结果和当前队列、模型、缓存、目录、有效配置。统计不依赖开发者诊断开关。
- 服务端升级与回滚保持独立连接和撤销状态；导出的 MCP JSON 也可供仓库附带的 stdio 桥接读取。

安装包与更新清单使用既有签名身份，覆盖安装时不要先卸载。Mac 仍使用 adhoc 签名；Android 日常版和开发版使用各自包名，数据互相隔离。累计统计从本版首次记录起算，不推算旧版历史。K90 Pro Max／HyperOS 的真机相机与后台行为尚未验证。
