# Mote 0.0.37

修复 Issue #3，并统一文件目录、内容索引和原件归档流程。

- 网页与服务统一版本，检测并阻止旧网页构建混用。
- 重整导航层级，增加中央、Mac、Android 存储统计中心，按文件类型和日期展示空间占用。
- 开发者诊断可导出指定时段内全部仍保留的轮转日志，并注明覆盖范围。
- 模型输入明确指定所选语言；记忆批次重启后保留语言。
- 合并重复状态 JSON，保留逐次采样时长、状态数值和观察时间；支持幂等重试、重启及时间范围查询。
- 文件来源默认使用“内容索引，原件留本机”，统一文本、PDF、Word、音频的索引与版本同步。支持轻量索引，以及按目录授权的只读正文补证。
- 前端区分目录、完整 / 轻量索引和原件可用状态；轻量索引需补足证据才能生成记忆，记忆可追溯到文件版本和正文片段。

边界：日期图表表示当前文件修改日分布，不是每日新增量；已清理的历史日志无法恢复。本机解析每文件最多 16 MiB，完整文字索引最多 100000 字符，超出后明确标记为轻量覆盖。音频内容索引依赖该设备上的本地转写服务；设备离线时只能使用中央已有证据。Mac 原件归档上限 16 MiB，Android 原件上限可配置至 512 MiB。

本地验收：720 项工作区自动测试通过（另有 1 项原有跳过项），Android 163 项单元测试及 lint 通过；通过离线同步、设备凭据、隐私、MCP 和中英文桌面 / 网页界面回归。测试使用生成资料及模拟服务。未执行物理设备采集或真实模型验收，未采集个人截图。

0.0.35 / 0.0.36 候选未公开发布；本版补齐测试隔离、实际安装包中的状态序列兼容性校验，以及桌面至中央的文件补证端到端验收。
