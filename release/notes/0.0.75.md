# Mote 0.0.75 DEV

首页新增 Agent 视角入口，可以逐层浏览模型可访问的目录、预览新对话的首次上下文，并查看已保留的实际输入与工具读取。

- Agent 视角以独立 Cordis 插件注册首页入口、页面和只读接口；首页贡献随插件卸载撤销，旧 `#/system/agent` 链接继续可用。
- 目录支持记忆、片段、来源、来源条目和正式资料，带范围筛选、分页及长文展开；复用查询 Agent 的只读 Reader 与权限检查。
- 首次上下文预览复用实际问答的组装逻辑和记忆线索选择，不调用模型；历史运行只展示当时保留的记录，并明确标注缺失和截断。
- 首页入口不请求正文；Agent 页面按需加载，根目录不扫描全库统计。性能与生成资料交互验证见本版验证记录。

验证范围见 [0.0.75 验证记录](https://github.com/utopiafar/mote/blob/v0.0.75/docs/validation/0.0.75.md)。本版没有执行个人截图采集、真实模型调用或物理设备验收。

发布附件为 Mac DEV ZIP 和 Android DEV APK；中央节点从本标签源码部署。产品版本 0.0.75，Android `versionCode` 86。
