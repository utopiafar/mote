# 0.0.53 — 可配置的页面内容采集

- Android / macOS 新增独立页面文字上报，与截图、应用状态并列；复用持久队列、批量上传、中央文本检索和证据引用。
- 在隐私设置中用 JSON 规则限定应用、页面、版本、必要节点、正文选择器及祖先容器，支持仅截图、双采集、页面优先和仅页面四种策略。默认不启用。
- 提供微信 WebView、知乎内容页、小红书详情页，以及 Mac 微信/飞书静态文字的实验规则；标注部分读取，不自动关闭截图。
- 密码、输入框、遮挡和不可见内容在原生读取时过滤；应用隐私级别、锁屏、停止、窗口切换、配置变更与上传审查继续生效。无点击、滚动、网络脚本或自动化动作。
- 页面来源可在客户端采集记录及中央时间线查看，保存解析器版本与节点证据；UI 观察时长为 0，不重复累计使用时间。
- 新增跨 TS/Kotlin 合成样本回放、无图入库/检索/幂等/权限测试、桌面设置与浏览测试和模拟器合成节点过滤测试。

先升级中央节点，再升级客户端。内置适配只通过生成样本测试，未验证真实 App 版本覆盖率、真实设备耗电或节省比例。macOS 原生读取器完成编译与宿主模拟测试，未采集私人页面或运行真实模型。详见 docs/ui-page-capture.md 和 docs/ui-page-research.md。
