# Mote 0.0.10

完善 Android 采集、记录浏览与同步恢复，并明确中央网页的管理登录流程。

- 通知使用权支持实时、对话、提醒和静音类型；新增可独立开启的通知与亮屏、熄屏、锁定和解锁事件采集，结构化上传至中央归档。通知遵守应用采集规则，系统限制可能使部分内容不可见。
- 屏幕、媒体和系统事件采集共用一个前台通知。
- 应用采集规则采用「完整内容／仅应用活动／不记录」，支持搜索和按实际规则筛选。
- 采集记录增加图片占位、并发缩略图加载、内存缓存、失败重试及列表／网格切换。
- 新增「同步与恢复」：显示待发、等待 OCR 和需处理记录，支持两端检查、全量补传、冲突查看与重试。中断后复用原记录身份继续上传，中央已删除记录不会被自动恢复。
- 同步条件增加「仅充电时同步」「低电量时暂停同步」，与 Wi-Fi 条件共同约束自动同步、立即同步和全量补传，并显示等待原因。
- 中央网页固定管理当前服务，移除登录其他节点入口；管理令牌只用于身份验证。设备配对地址明确为本服务供客户端访问的地址。
- 精简设置保存、配对和随手记等页面的冗余文案。

Mac、Android、中央服务与网页统一为 0.0.10，Android versionCode 为 21。新增通知与设备事件采集默认关闭，新增电源同步限制默认关闭。Mac 沿用项目既有签名方式；adhoc 签名不代表 Apple 公证。

发布前本地验证包括 Android 97 项 JVM 单元测试、Kotlin 与 instrumentation 测试代码编译、lint，以及前端 36 项测试；其他自动化检查由发布流水线执行。测试使用合成数据；未进行 HyperOS 真机通知权限、插拔电源、后台恢复或真实模型验收。
