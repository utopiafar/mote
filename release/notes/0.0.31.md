# Mote 0.0.31

- Mac 来源页可连接本机 Claude Code、Codex、Kimi Code，按完整事件增量归档可读对话与工具记录。支持首次全部/仅新增、离线积存、隐私排除与遮盖；后台线程读取，断点与正文一起持久化，收到匹配确认后才移除待传项。
- 中央自动提炼编码经验，记录踩坑、设计决策、原则或明确偏好，以及会话/项目/跨项目适用范围、验证程度、精确原文和不确定性。没有值得保留的经验时返回零条，默认候选待确认。
- 编码经验与个人生活资料使用独立提炼 Skill，复用只读 Harness、证据授权、可恢复任务及检查点；在既有记忆页、Chat 与洞察中使用。本期不回写 Agent 配置、不新增外部 Agent recall 或会话恢复。
- 合入 0.0.29 已发布功能与最新 main：保留日历行动和资料库修复，并包含用量归属、费用统计、后台问答进度与模型目录等更新。
- 修复后台问答失败提示缺少无障碍告警标记的问题；失败问题仍可编辑重试、历史回答保持完整。
- 产品版本 0.0.31，Android versionCode 42，延续既有签名。Mac 仍为 ad-hoc 签名。调研、设计与边界见 [编码经验设计](https://github.com/utopiafar/mote/blob/v0.0.31/docs/coding-agent-memory.md)。

自动化合成验证与经授权的本机真实会话/模型验收分别记录在 [验收文档](https://github.com/utopiafar/mote/blob/v0.0.31/docs/coding-agent-validation.md)。不将 fixture 或模拟器检查声称为 Android 真机验证。
