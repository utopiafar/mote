# Mote 0.0.16

Android 开发者选项新增「本机图片批量去重」，可检查本机全部采集图片，预览后再决定处理。

- 按采集时间从早到晚扫描，始终与上一张保留图比较。复用精确、保守、均衡、激进四档规则，不设时间窗口；应用切换、尺寸变化或读取失败时重新开始比较，避免逐张微小变化造成连续误删。
- 后台扫描和处理，前台显示阶段、进度与结果；离开页面不取消任务，可主动取消。图片按页加载，支持双图缩放对比、单选、按页选择和全选。
- 支持移入应用内加密的待决定区，之后恢复或确认永久删除。待决定区保留记录、图片和 OCR/同步状态，不参与自动同步和清理，仍占用磁盘空间；恢复时检查本机队列容量。
- 处理前重新核对候选图与保留图；移动时先写入并校验目标副本，再清理来源。共享图片文件仍被其他记录引用时不会删除。
- 仅处理 Mote 本机采集记录，不修改中央归档或系统相册。旧扫描结果会标注旧规则，重新扫描即可使用最新逻辑。

Mac、Android、中央服务与网页统一为 0.0.16，Android versionCode 为 27。沿用现有发布与应用签名身份；Mac 使用 adhoc 签名。

本地验证通过 115 项 Android 单元测试、构建和静态检查，以及后台专用模拟器的批量去重和原有实时去重诊断回归。生成图片覆盖长时间间隔、逐步变化防误删、预览、全选、移动、恢复、删除与取消。未采集个人截图、未调用真实模型，未进行实体手机或生产环境升级验证。发布流水线继续执行跨端构建、回归、签名与包身份校验。

详细范围见 [批量去重说明](https://github.com/utopiafar/mote/blob/v0.0.16/docs/android-bulk-dedupe.md)。
