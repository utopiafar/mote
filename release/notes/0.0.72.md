# Mote 0.0.72 DEV

本版让通过独立审核与宿主校验的 Memory 自动生效，并完善删除意图、资料处理和异常恢复。

- Memory 审核通过后自动进入当前可用记忆，无需用户逐条确认。删除意图持久保存，对仍可核验原件身份的重导入继续参与审核；新增证据可重新评估，原始资料与无关结论保留。
- 多套 Memory 方案按各自依赖独立继续，界面展示等待、失败和已完成结果。有效提取结果可在审核失败、重启后复用；重试提示说明资料或设置变化时可能重新提取。
- 查询支持模型选择图片的原始像素区域，同一查询内复用已交付图像。资料正文按完整工具响应预算分页，保留可继续读取的位置与证据边界。
- 修复 Coding 原样重传导致当前资料反复重建的问题；历史问答与 Memory 使用固定语义时间，同时保留真实运行和用量计时。
- 修复 Android 上传任务收尾时可能丢失新唤醒的问题，并串行化采集数据待上传队列的读取。
- 宿主超时保留明确类型，更早的主动取消保留原始原因；迟到结果不能提交。中断后的未知模型用量不会被误记为完整，历史失败用量继续保留。

验证范围与剩余限制见 [0.0.72 验证记录](https://github.com/utopiafar/mote/blob/v0.0.72/docs/validation/0.0.72.md)。生成资料的界面、模拟器及流程检查分别记录；物理设备后台稳定性、全量私人资料处理、跨场景 Memory 净收益仍未完成。最新生成图文问答仍有一项限定表达未完整保留，本版不宣称已通过完整效果验收。

发布附件为 Mac DEV ZIP 和 Android DEV APK；中央节点从本标签源码部署。产品版本 0.0.72，Android `versionCode` 83。
