# Mote 0.0.1

Mote 仍处于开发早期，功能、交互和协议会继续调整。本次将对外版本编号重新从 0.0.1 开始，保留当前已有功能与代码；此前的试验 Release 已撤下。

- Android、macOS 和中央网页提供分层导航，常用操作、来源、设置与开发者选项分别组织。
- 采集与上报独立运行，未连接中央节点也可保存本地内容；支持实时、定时、批量和手动上报。
- 常用配置提供预设、开关、应用选择和遮罩编辑；中央网页可生成不含凭据的配置变更片段，合并并重启节点后生效。
- 首次上报本地积存需要确认归属；连接切换、失败重试和持久队列保留原有保护。

## 从此前的试验版本切换

旧 Mac 和中央节点的自动更新不会把数值更小的 0.0.1 识别为更新，需要手动更新中央部署、退出并覆盖替换 Mac App。先更新中央节点，再更新客户端；保留原配置、凭据、模型、队列和数据目录，不要先卸载应用。

Android 使用原包名及签名，内部 `versionCode` 递增为 **12**，旧 Android 的检查更新仍可识别此版本，也可手动下载安装包覆盖更新。macOS 安装包适用于 Apple Silicon，使用 ad-hoc 签名。

验证使用合成资料、Android 模拟器及 Electron 交互测试；此次版本编号重置不代表已完成物理设备、个人屏幕采集或真实模型验证。使用方式见 [采集与上报](https://github.com/utopiafar/mote/blob/v0.0.1/docs/collection-and-sync.md) 和 [客户端导航](https://github.com/utopiafar/mote/blob/v0.0.1/docs/client-navigation.md)。
