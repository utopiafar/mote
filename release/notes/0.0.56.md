# 0.0.56 — 通用上下文与可扩展加工架构

- 围绕个人上下文归档重组主链路：观察、内容对象、版本化片段/产物、增量 Memory 与原始证据；准确去重保留每次观察时间及所有引用。
- 新增 Cordis 上下文处理器与持久 DAG，支持多输入多产物、独立队列预算、取消、重试、租约恢复和输入版本校验；提供按需片段语义处理器。
- 真正批量事务入库、事务性容量账本、FTS rowid 更新、有限向量候选及覆盖说明；OCR 复用唯一图像，慢语义任务与 OCR / 提取分别调度。
- NAS 先建立可分页目录，再增量索引正文；桌面大目录回滚避免复制整个目录。Chat / MCP 新增片段与目录入口，Memory 消费准备好的代表原文。
- 新安装默认 100 条或 1 分钟打包同步，已有显式设置保留。
- 已用 2 万条生成观察、10 万文件目录及真实本地 10 万生成文件测试；真实模型检查仅使用本地 Codex App Server 的 gpt-5.6-luna。异常、成本假设和测试边界见 docs/context-architecture-validation.md。

先备份并升级中央，再升级客户端。MVP 不保证旧版本读取升级后的数据库，回退需恢复备份。未执行真实手机采集、真实 NAS 网络或长期电量测量；合成样本去重比例不是生产保证。外部来源按需挂载、目录语义摘要和更多动作插件尚未自动开启。

- 同步协议支持一分钟 heartbeat；手动同步与后台扫描竞争时，强制请求合并排队并等待完成。
- 中央采集记录恢复明确的前后页切换，每页最多 24 条，避免滚动累积大资料库的页面和图片。
- 944 项工作区回归、177 项 Android 单测、生成数据的真实 Electron/中央/API/二维码/更新检查通过。
