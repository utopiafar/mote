# Mote 0.0.40

中央节点连接状态在各客户端的高可见区域统一展示，帮助用户快速判断记录是否仍停留在本机、正在同步，或需要处理连接问题。

- Web 顶部栏新增中央节点状态胶囊：未连接、正在验证和已连接均有明确文案与颜色；点击状态可进入连接详情或连接入口。
- Mac 概览页新增中央节点连接卡片，展示连接状态、待确认记录数量、节点地址和下一步操作；未配置连接时保留本机优先说明。
- Android 概览页新增中央节点连接卡片，使用本地保存的连接与同步状态；明确区分未连接、最近一次验证成功、同步中和需要处理，避免把一次检查误表示成持续在线。
- 新增对应的中英文界面文案与响应式布局，保持各客户端的隐私提示和连接设置入口一致。

设计参考了 OneDrive 的状态图标与操作入口、Figma 的工具栏连接状态与离线提示、Slack 的显著断线提醒，以及 iCloud Photos 的同步状态说明：状态应当持续可见、使用可理解的文案，并能直接到达修复动作。

本地验收：工作区类型检查通过；共享库构建通过；Web 57 项测试通过、桌面端 226 项测试通过；Web 构建通过；Android `:app:compileDebugKotlin` 通过。桌面端构建已通过 TypeScript 与 UI bundle 阶段，但本机缺少固定版本 llama.cpp 源码，未执行本地模型原生助手构建。Electron UI smoke 未执行，原因是本次本地依赖安装使用了 `--ignore-scripts`，未下载 Electron 二进制。
