# Mote 0.0.66 DEV

修复 Android 采集队列阻塞，统一手机中央问答的界面和登录会话，并简化 MVP 阶段发布流程。继续提供 Mac DEV ZIP 和 Android DEV APK；中央端从源码部署。

- 移除采集阶段重复的全局隐私级别判断。合法的仅活动媒体和通知记录可以正常保存，旧版本阻塞在 inbox 的输入可直接恢复，无需清空应用数据。保留按来源定义的记录格式约束和上传审查状态。
- 待处理输入出错不再阻止浏览已提交的历史记录；原输入仍保留供后续重试。
- Android 11 及以上的系统栏识别改用系统窗口边界和 Insets，不再依赖英文窗口标题。未知窗口和受限窗口仍遵循用户规则。
- 补充截图前决策、窗口变化、像素读取及系统截图错误码日志；区分 Mote 自身防截屏与应用规则阻止，单独保留屏幕采集状态。日志不保存画面、正文或令牌。
- 手机问一问直接使用中央网页版，与资料库、工作台共享同一应用进程内的中央会话；移除独立的原生令牌输入页，支持失败重试。切换节点隔离会话，窗口级登录随应用进程结束失效。
- MVP 阶段停用 GitHub 自动测试及主分支必需检查，发布流程不再重复运行测试和 lint；保留构建、签名及安装包身份校验。本地检查命令仍可使用。

本地验证：`npm run check:local`、206 项 Android JVM 测试、开发版 APK 构建，以及 2 项独立模拟器测试（生成页面截图入库、中央会话保留与节点隔离）均通过。模拟器只使用生成内容。物理手机仅进行了只读诊断，尚未验证修复版在真机上的长期采集或真实模型问答；旧日志不足以确定每次漏采的具体窗口原因。

产品版本为 0.0.66，Android `versionCode` 为 77。Mac 安装包随产品版本更新，本次功能修复主要在 Android。
