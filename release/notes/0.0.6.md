# Mote 0.0.6

修复 Android 在已有较多截图记录时，从 0.0.1 升级后打开主界面卡住、出现“无响应”的问题。

- 首页状态读取改为后台执行；读取较慢时只保留一个刷新任务，页面切换和退出不再等待截图队列。
- 队列统计复用未变化记录的统计结果，避免每两秒反复解密全部历史记录。首次扫描仍在后台完成。
- 采集服务的空间检查、诊断采样和同步调度移到后台，并合并重复调度请求。
- 设置恢复验证、手动同步与诊断导出也避免在主线程等待队列。
- 保留原有加密截图、OCR、笔记和设置，无需清空数据或重新导入。继续使用原有安装包签名身份。

Android 内部版本码为 **17**。Mac 与中央节点同步版本号为 0.0.6；此修复不要求升级中央节点。请直接覆盖安装 Android 更新，保留现有应用数据。

验证范围见 [0.0.6 验收记录](https://github.com/utopiafar/mote/blob/v0.0.6/docs/0.0.6-validation.md)。模拟器验证仅使用生成数据，不代表已在用户真机复现或验证。
