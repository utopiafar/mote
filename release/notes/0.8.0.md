# Mote 0.8.0

- 重新设计 Android、macOS 与中央网页的信息架构。首页聚焦状态和常用操作，笔记、来源、归档各有入口，连接、隐私与采集配置归入设置，诊断工具收纳到开发者选项。
- 采集与上报独立运行：没有配置中央节点时，也可在本地采集、记笔记和扫描已授权来源。离线内容先持久保存，首次连接确认后再按所选策略上报。
- 两端统一支持实时、定时、批量与手动上报；提供间隔、批量阈值、待上报数量和运行状态。手动模式不会自动发送内容或心跳，失败保留原记录供重试；暂停或失去权限的来源会单独显示。
- 用选择器、开关和预设替代常用配置的手工输入，包括应用采集规则、图片质量、文件类型和遮罩区域。配置编辑与笔记草稿在页面切换时保持。
- 中央网页区分采集状态、上报状态和最近收到的报告；设置页提供易读的当前配置与可视化配置表单，可生成不含凭据的配置变更片段，合并到节点配置并重启后生效。
- 加固连接切换与离线队列绑定、异常响应处理和文件系统边界，防止待上报资料意外发送到其他节点。

请先升级中央节点，再覆盖升级客户端，保留原配置、凭据、模型、队列与数据目录。新客户端的同步状态字段需要新版中央节点支持；未获确认的内容会留在本地。

macOS 安装包适用于 Apple Silicon，使用 ad-hoc 签名；Android 日常版与开发版沿用原签名，版本代码为 11。

本轮验证覆盖自动化合成数据、Android 模拟器和 Electron 窗口交互；未进行个人屏幕采集、物理设备或真实模型验证。使用方式见 [采集与上报](https://github.com/utopiafar/mote/blob/v0.8.0/docs/collection-and-sync.md) 和 [客户端导航](https://github.com/utopiafar/mote/blob/v0.8.0/docs/client-navigation.md)。
