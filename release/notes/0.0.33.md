# Mote 0.0.33

Web、macOS 和 Android 新增中文 / English 界面，可跟随系统或在设置中选择语言。中央节点按请求语言返回用户提示，不翻译服务端运行日志、原始资料和用户内容；本次不包含 RTL 支持。

- 统一中英文词库，覆盖页面、设置、权限说明、通知与错误提示；语言偏好持久保存，日期和数字随界面语言显示。
- 桌面端切换语言通过可信主进程重载固定页面，保留导航保护；后台处理和中央请求携带当前语言。
- 合并已有的未提交模型配置改动：支持多套模型配置、功能默认模型与单次请求选择，以及中央服务器上的 Codex App Server 登录调用。
- 保留主线现有问答进度、持久化运行、工作记忆与低频记忆调度，并补齐模型配置合并回归。

验证：692 项 workspace 测试通过；Android 单元测试、Release / Development lint、生成数据端到端与隐私测试通过。桌面与 Web 双语界面、登录和模型配置使用隔离生成数据验证。本次未进行 Android 真机采集或真实模型调用验收，不使用个人截图。

---

Chinese and English are now available across Web, macOS, and Android, with a saved language preference or system default. Central responses follow the request language. Server logs, original evidence, and user content remain unchanged; RTL is outside this release.

This release also includes the existing model-profile work: multiple connections, feature defaults, per-request selection, and Codex App Server support on the central server. Existing query progress, durable runs, working memory, and scheduled memory processing are retained.
