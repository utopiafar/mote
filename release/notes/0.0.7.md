# Mote 0.0.7

新增 Android 锁屏与后台媒体上下文，并合入最新的客户端加载状态和诊断入口改进。

- 手机可选择仅屏幕、仅媒体或同时采集。锁屏结束截图会话后，已开启的媒体观察继续运行；无截图权限也能仅采集媒体。
- 记录播放器公开的应用、播放状态、曲目／章节、播放位置以及前后台、本机／远程状态。媒体默认关闭，需主动开启并授予通知使用权；不录音、不采集普通通知正文，沿用应用隐私规则和电量限制。
- 媒体记录支持加密离线队列和原有同步策略。中央与手机可浏览媒体详情，截图及设备报告可附带具有独立观察时间的媒体快照。
- 中央新增独立播放统计和只读 Agent／MCP 工具，可按应用、锁屏和前后台分析并引用原始证据。播放时长与前台使用时长分别计算，观察空隙不补齐；播放不代表已收听、读完或专注。
- Android 的记录与统计页面显示加载进度，新增日志查看入口，并改善繁忙状态反馈；Mac 新增打开日志目录入口。
- 修复权限页初始化时重复添加视图导致的启动崩溃，以及日志页的事件读取引用；权限概要同时显示媒体通知使用权。

请**先升级中央节点，再升级 Android 并开启媒体采集**，旧中央节点会拒绝新的媒体来源。Android 内部版本码为 **18**，沿用原有签名身份；直接覆盖安装，保留设置、加密队列和本地模型。Mac 与中央节点同步版本号为 0.0.7。

媒体采样依赖系统公开的会话与后台调度，权限撤销、系统休眠或不兼容播放器可能造成缺口。自动验证使用生成数据；未在用户真机或真实播放器上验证长期后台存活，也未验证真实模型的内容判断质量。
