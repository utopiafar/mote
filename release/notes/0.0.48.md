# Mote 0.0.48

本版包含 MCP 上下文查询重构、远端 source-sync pre-case、Linux 可移植性修复，以及 SourceSync v2 队列状态兼容的桌面端离线同步 fixture 修复。

- 提供 `mote_browse`、`mote_search`、`mote_read`、`mote_context`、`mote_status` 及其 `structuredContent` / `outputSchema` 契约。
- 包含可恢复来源目录、批量确认、原生 watcher 和生成 fixture；不把实现混入 MCP 的意图分类逻辑。
- 离线 smoke 同时覆盖 `pendingRealtime`、`pendingHistory` 与旧版 `pending` 状态，确保升级后的 source-sync 队列仍能验证完整绑定、上传和确认流程。

本版模型验收使用本机 Codex Server 和生成的虚构资料，未调用 DeepSeek，未读取或上传真实个人截图。物理设备采集未在本次重新验收。
