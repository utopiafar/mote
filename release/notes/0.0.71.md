# Mote 0.0.71 DEV

本版完善真实资料导入、图文与录音证据、可组合 Memory 策略，以及查询的预算和取消边界。

- 已归档的图片附件可按需进入现有文件处理流程，与文字说明组成同一份资料。满足处理器契约的相同原件复用原始 OCR；保留图片位置，附件失败不阻塞无依赖的正文或其他产物。该处理入口目前为 owner API。
- Memory 的提取、审核与整合策略可独立替换和固定版本，个人与 Coding 策略可同时处理同一资料，并共享满足授权条件的提取结果。自动执行按明确启用、收到资料的时间和批次预算授权，安装或升级不自动执行全部历史模型任务。
- 资料保留原始时间、作者内容与引用内容的角色及可追溯证据。普通开发进展与值得保留的 Memory 分开审核，Coding 审核保留适用条件和实际可用的细节。
- 录音处理保留独立语音片段；用户确认的说话人和文字校正沿文件、正式资料与 Memory 传播。更正仅使相关证据失效，未变片段继续有效；阅读界面支持分页、原件和更正历史。
- 查询可读取已获授权的图片原件，保留范围和来源检查；图像工具日志不再保存图片 Base64。执行预算对 Agent 可见，超时与取消使用明确状态并阻止迟到结果提交。
- 新增真实输入的分阶段复核脚本与记录，包括可恢复导入、处理结果复用、独立审核以及有无 Memory 的同题对照。

验证范围和已知限制见 [0.0.71 验证记录](https://github.com/utopiafar/mote/blob/v0.0.71/docs/validation/0.0.71.md)。最后的图文组合复核沿正常导入和处理接口复用已有 OCR，无新增大模型或 OCR 调用。图像问答的完整效果、普通提问的时延/成本目标以及全部真实资料的整体验收仍未完成；本版不宣称这些目标已经达成。

发布附件为 Mac DEV ZIP 和 Android DEV APK；中央节点从本标签源码部署。产品版本 0.0.71，Android `versionCode` 82。DEV 安装包与发布构建不等同于物理设备验收。
