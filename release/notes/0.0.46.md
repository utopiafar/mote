# Mote 0.0.46

本版在 0.0.45 的通用 MCP 上下文查询重构基础上，同步远端 source-sync pre-case，并补齐来源同步错误提示的英文 catalog，确保桌面端与 Android 的本地化校验一致。

- 保留并发布 `mote_browse`、`mote_search`、`mote_read`、`mote_context`、`mote_status` 及其 `structuredContent` / `outputSchema` 契约。
- 包含远端 source-sync 的可恢复目录、批量确认、原生 watcher 和相关生成 fixture；不把这些实现混入 MCP 的意图分类逻辑。
- 继续使用稳定游标、evidence 链和权限前置过滤；查询结果中的 Coding project/session/provider 仍只是范围和解释字段。

本版模型验收使用本机 Codex Server 和生成的虚构资料，未调用 DeepSeek，未读取或上传真实个人截图。物理设备采集未在本次重新验收。
