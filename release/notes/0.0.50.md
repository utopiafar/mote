# Mote 0.0.50

本版修复 Android 打包上传没有真正形成压缩包的问题，并加入服务端解包与逐条确认。

- Android 以 gzip 压缩 JSONL 包上传记录，服务端限制解压大小、校验完整包和设备权限，再逐条入库并返回 ACK；旧节点自动回退 JSON 批量或单条接口。
- 批量同步现在遵守配置的批量数量，不再固定只处理 25 条；无图片的短状态记录可按时间戳窗口合并，默认 10 分钟，并提供设置项。
- 保留每条本地队列记录直到收到对应确认；诊断上传字节数改为统计真实网络包大小。
- 服务端与 Android 覆盖 gzip JSONL、权限边界、幂等和旧协议回退测试。物理设备与线上发布验收另行记录。
