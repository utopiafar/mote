# Mote 0.0.25

## 大资料库性能

- Android 连接本机存储后即可开始采集，索引升级和孤立文件清理在后台继续，首页不再等待全库扫描才更新开始／暂停状态。
- 库存与采集记录复用元数据索引，统一记录数、含图记录数、独立图片文件及待决定区的统计口径。浏览先显示当前页，再逐步加载缩略图；无关记录变化不再重建当前页，快速切换会丢弃旧请求。
- 批量相似图片删除不再每删一条就读取全部剩余记录。共享图片引用计数、合并索引写入、参考图片校验复用和进度限频减少重复工作；保留图、OCR／上传状态、恢复容量检查与取消后的已完成结果保持原有语义。
- 扫描复用相同图片的紧凑特征，精确哈希使用分块计算。选择全部候选不再重新加载整页缩略图，后台工作期间仍可翻页预览和离开页面。

## 内容加密可选，默认关闭

- Android、Desktop 和中央服务端的新内容默认明文保存。显式开启加密只影响后续写入，关闭后也不会自动改写旧文件；明文与旧密文可共存读取。
- 各端开发者页面提供一次性批量解密，显示进度和结果，支持取消、重试；成功校验并原子落盘后才替换旧文件，失败保留原件。
- 中央节点即使配置了 `MOTE_DATA_KEY`，也不再默认加密；可使用 `MOTE_CONTENT_ENCRYPTION=1` 或开发者设置主动开启，界面保存的设置优先。SQLite 元数据保持明文。
- Android Keystore 和 Desktop 系统存储继续保护连接凭据。旧内容解密完成前仍需保留原安装密钥或中央内容密钥。HTTPS、访问授权和隐私过滤保持有效。

## 验证范围

- 增加 2,000 条生成图片记录的库存／分页与实际 WorkManager 扫描、1,900 个候选批量删除、界面响应和共享参考图保留验证；覆盖历史签名兼容及进度更新次数边界。
- 增加旧密文与明文共存、迁移恢复和凭据保持加密的回归检查。独立模拟器实测：2,000 条记录首屏 885 ms，第二页 287 ms；2,000 张生成图片扫描 2.56 秒，删除 1,900 个候选 1.73 秒。结果与限制见 [Android 大资料库性能](https://github.com/utopiafar/mote/blob/v0.0.25/docs/android-library-performance.md)。
- 未把生成图片模拟器结果当作物理设备、个人图库或在线模型验收。产品版本 0.0.25，Android versionCode 36，沿用既有发布签名。
