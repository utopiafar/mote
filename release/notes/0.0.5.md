# Mote 0.0.5

中央节点新增完整模型配置，可在 Web 的「设置 → 问答与回顾」中直接保存、测试和切换服务商。

- 23 个服务预设：DeepSeek、通义千问、火山方舟／豆包、智谱 GLM、Kimi、MiniMax、百度千帆、腾讯 TokenHub／原混元、硅基流动、讯飞星火、阶跃星辰，以及 OpenAI、Claude、Gemini、Azure、xAI、Mistral、Groq、OpenRouter、Ollama、LM Studio 与自定义接口。
- 支持 DeepSeek、OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Google 原生协议，保留多轮工具调用所需的推理字段和签名。
- 可配置服务地址、模型 ID、API Key、推理强度、输出上限和运行期限，高级配置支持自定义请求头与厂商 JSON 参数。
- 保存后立即用于新问答、回顾和记忆提取，正在进行的问答继续使用原配置；重启后自动恢复。可随时恢复部署配置。
- 凭据与高级参数不回显；切换服务商或地址时需明确选择替换、清除或复用已有凭据。连接测试只发送生成数据，不读取个人资料库。

预设代表接口适配，不保证厂商的每个模型都支持工具调用。请填写账户实际可用的模型 ID；测试连接会向所选服务发送少量生成内容，可能产生费用。自定义接口需符合上述协议，暂不支持任意请求／响应字段映射。

Android 与 Mac 同步发布 0.0.5，保留现有客户端功能和签名身份。Android 内部版本码为 **16**；Mac 延续 ad-hoc 签名方式。使用新增模型设置须升级中央节点。

使用方式见 [模型服务商与配置](https://github.com/utopiafar/mote/blob/v0.0.5/docs/model-providers.md)，测试范围见 [0.0.5 验收记录](https://github.com/utopiafar/mote/blob/v0.0.5/docs/0.0.5-validation.md)。
