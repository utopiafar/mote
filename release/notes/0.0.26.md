# Mote 0.0.26

从上传和持续采集中发现日程，逐条核对后添加到已有日历。

## 日程建议与多端执行

- 中央网页新增「行动」：开启后台发现、选择默认时区、授权设备查看跨来源建议与原文片段。支持主动上传、持续 OCR、通知正文及文件正文/转写；本地限定文件不进入远程分析。
- 每条建议展示原文依据和待确认信息，可修改标题、日期、时间、时区、地点、备注并选择已有日历。日期不明时不自动编造；全天日程和夏令时歧义有明确校验。
- Android 新增「日程建议」及原生日历读写接入；Mac 中央窗口支持连接可写日历并执行已确认日程。Android / Mac 可拉取各自已确认的投递，离线保留队列，手动同步设置继续有效。
- 日历备注带 `#Mote` 和稳定行动 ID，便于跟随现有账户同步并追溯来源。首版仅创建，不自动改期、取消、发送邀请或创建重复规则。

## 权限与可靠性

- 日程分析使用独立的 calendar-extraction Skill 和既有 DeepSeek Harness，只读工具表不增加写入权限。建议、确认、版本与执行回执由宿主管理，为后续行动类型保留扩展边界。
- 跨来源建议需要额外设备授权。确认绑定具体版本、目标设备与日历，多端竞争确认不会重复派发。
- 本机在写入前持久保存操作记录，回执丢失后可重发；中途崩溃后仅核实原事件，不盲目重复插入。无法核实的操作明确显示待核实。
- 来源变更使未执行建议失效；原文删除立即清除相关引句，已确认的日历事件不会随原文自动删除。

## 验证范围与使用

- 使用生成资料和模拟供应商覆盖上传/通知、证据校验、重复、逐条确认、设备隔离、丢失回执、崩溃恢复、日期与夏令时；真实 Harness 配合本机合成模型服务验证 Skill 和只读工具边界。
- 真实网页渲染验证查看证据、选择已有日历、确认排队与保存回执；Android 编译、单元测试和两个分发变体 lint 通过。发布流水线另外执行各端构建、全仓检查及既有回归用例。
- 真实 DeepSeek Flash 合成文本评测 6/6 通过：明确日程、历史相对日期、他人安排、模糊邀约、取消和缺少结束时间。首次运行曾产生一条正确标为历史日期的候选，已补充 Skill 指令与宿主过期校验并回归验证。
- 未进行真实个人日历写入、物理手机或跨账户同步验收；六个合成模型案例不代表总体提取准确率。首次使用需在中央「行动」开启发现、授予设备访问，再在客户端连接日历。
- Google 写入、iOS 原生客户端和自动改期/取消不包含在本版。已有日历的备注同步取决于日历提供者；语义重复检测有上下文范围限制。
