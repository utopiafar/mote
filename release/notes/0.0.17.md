# Mote 0.0.17

## 文件归档与中央处理

- 手机目录文件可原样归档到中央，支持分块续传、SHA-256 校验、版本历史与 Shadow 元信息。来源删除保留中央归档；收到确认后只清理 Mote 暂存，保留手机原件。首次同步可选择全部分批归档或仅同步新增。
- 文件处理接入真正的 Cordis 常驻插件运行时。开发者可以部署独立处理器；用户可按文件格式和来源选择处理方式。
- 录音支持云端/自托管 HTTP 转写适配器，以及严格本地的 faster-whisper + pyannote/3D-Speaker 处理。新增预期人数、匿名说话人、时间对齐、试听片段和未校正记录导出。
- 分步处理持久化，分离失败可继续重试并保留转写；本地模式不会自动调用云端摘要或云端向量服务。
- 可选本地语言模型合并自然发言轮次。场次关联、术语校正和说话人姓名需要用户确认；校正版单独保存，原件与未校正记录保留。
- 网页增加处理设置、阶段状态、试听、导出与复核；沿用现有引用、检索和记忆提议机制。
- 包含最新 Android 本地图片清单同步修复。

## 部署

本地音频运行时及模型按 [部署文档](https://github.com/utopiafar/mote/blob/v0.0.17/docs/file-processing.md) 单独安装。发布包不携带模型权重。云接口采用 Mote 的转写协议；厂商专用协议通过 Cordis 插件适配。中央、音频服务使用同一主机/网络命名空间。

## 验证范围

通过文件协议与插件回归、Android 模拟器跨端同步、实际本地双声线合成录音处理、网页试听与导出验证。测试使用生成内容。物理手机、中文复杂场景、长时录音与重叠说话识别质量仍需后续验收；可选本地语义模型的真实推理未在本轮验收。

升级前停止中央服务并备份数据；加密密钥与服务密钥单独保存。
