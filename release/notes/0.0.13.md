# Mote 0.0.13

新增中央对话历史与续聊，修复设置草稿和重新配对后的状态更新，并提供 Android 图片去重调试预览。

- 「问一问」自动保存完整问答，可查看历史、新建或删除对话，并在刷新页面、重启中央节点后继续旧对话。续聊结合此前问答理解上下文，再按当前筛选检索原始证据。
- Android、Mac 和中央网页的设置草稿随页面离开或返回而丢弃，设置菜单不再残留保存栏；随手记草稿继续独立保存。
- 重新扫码或导入邀请后同步已提交的连接配置，避免旧页面覆盖新 URL／凭据；Android 在兑换尚未结束就返回、或保存中旋转页面时，也能更新到最终保存的配置。
- Android 开发者选项可开启图片去重调试，临时保留被去重画面和实际基准画面，展示哈希相似度、差异指标与判定阈值，支持单条删除和全部清空。默认关闭，图片仅在本机加密保存；最多 20 组／32 MiB，保留 24 小时。

对话历史随完整 SQLite 离线备份迁移，网页 JSON 资料导出不包含历史。原始资料删除或到期后会清除历史模型回答，保留提问。去重调试仅保留通过既有隐私检查与遮罩处理的画面，不上传中央节点。

Mac、Android、中央服务与网页统一为 0.0.13，Android versionCode 为 24。沿用既有发布与应用签名身份；Mac 使用 adhoc 签名。

验证使用生成数据、隔离中央节点和模拟模型；实体手机、HyperOS 后台行为与真实模型效果不在本次验证范围。发布流水线负责完整构建、跨端回归、包身份校验及签名清单发布。详细范围见 [验证记录](https://github.com/utopiafar/mote/blob/v0.0.13/docs/0.0.13-validation.md)。
