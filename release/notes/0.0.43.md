- 修复工作记忆大批次误用用户问题长度限制；上下文压力触发及时压缩，超长单轮分段处理，失败不推进摘要进度。

- 缩短发现阶段预览并定位词法命中；记忆详情与原文读取解耦，保留分段证据及版本状态。
- 增加统一宿主上下文预算与组成统计；移除行动存储的重复初始化。
