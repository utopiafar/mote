# Mote 0.0.41

Mac 与 Android 客户端改进采集、上传和问答体验。

- Mac 截图去重新增保守、均衡、激进档位，与 Android 使用相同的灰度、差异哈希、缩略图区域变化和阈值判定。完全相同模式比较处理后的像素；所有比较都在隐私过滤后执行，并限制在同应用的连续采样间，不累计被跳过的时长。
- 两端上传界面显示最近两秒的上传速率，按实际交给传输层的请求体字节计量，包含编码开销；停传后归零。截图、文字和来源文件上传均纳入计量。
- 上传设置新增“打包上传”，把多条采集记录合并成有大小上限的请求，逐条验证中央回执。未确认记录继续保留，旧节点不支持批量接口时回退单条上传。此开关独立于实时、定时、积攒一批和手动上传策略。
- Android 更新页新增“删除已下载包”，清理 APK 与未完成下载，保留应用设置和采集记录；活动安装期间禁止清理，下载写入和清理串行执行。
- 修复 Mac 录屏授权主体不一致：移除独立 mote-helper 的录屏权限申请，统一使用主 Electron App 的权限状态。权限页提示修改授权后完全退出 Mote（⌘Q）并重新打开，并显示实际 Bundle ID 与 App 路径，方便区分正式版和 DEV。
- 两端权限页增加绿色已授权、醒目的未授权和待系统确认标记。Android 投屏只报告本次会话状态；系统无法可靠检测的权限不显示成已授权。
- 两端“问一问”直接调用中央 API。Android 使用原生控件；Mac 使用客户端自身界面，均不再为问答嵌入中央网页。支持历史、继续提问、进度、停止和引用证据。问答需要所有者权限；临时输入的所有者令牌仅保存在会话内，设备采集凭据不会被扩大权限。

验证：工作区类型检查与测试通过；Mac 原生助手及客户端构建通过；生成数据界面验收覆盖直接问答、停止、输出转义、权限标记、上传选项持久化和中英文切换。Android JVM 单元测试、Release/Development lint 和 instrumentation 测试代码编译通过。发布工作流再次执行跨平台检查和签名产物校验。

未执行物理 Android 设备采集、真实 macOS TCC 授权/撤销/重启循环或真实模型验收；自动化验证仅使用生成数据，权限状态在界面测试中模拟。新增 Android instrumentation 测试未在本地设备上运行。

产品版本 0.0.41，Android versionCode 52。沿用既有签名身份、Bundle ID、包名和用户数据目录。
