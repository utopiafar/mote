# Mote 0.0.30

Memory 整理统一为“定时到达且有足够增量”触发，减少高频上传带来的模型调用。设置中的“问答与回顾 → 记忆与洞察的节奏”可直接调整各流程的开关、间隔、门槛和单轮处理上限。

- 新增独立的对话工作记忆、事件记忆提取、长期整理和周期洞察组件，复用 DeepSeek Harness 原生 Skills 与只读工具。
- 默认提取间隔 6 小时，长期整理和洞察 24 小时；运行窗口、增量进度和重试状态持久化。导入不再立即启动记忆提取，手动入口仍可立即运行。
- 文本记忆支持中文/英文全文检索、层级筛选、游标分页和 Markdown 下载。按概览、详情、原始证据逐层披露，保留人物归属、版本、适用日期和不确定性。
- 来源修订或删除会同步处理依赖记忆、洞察、工作摘要及其索引，避免旧结论继续被引用。自动整理只生成待确认候选。
- 修复大资料库中先截断全文检索候选再应用范围可能漏掉旧资料的问题，补齐新增工具的集成验证，并消除旧洞察设置入口的歧义。

升级说明：首次初始化新的生命周期设置会采用以上低频默认值；已有非零洞察环境变量用于初始化其间隔，之后以界面保存值为准。自动流程都需要同时满足周期和增量门槛，剩余少量增量可等待后续变化或手动处理。

验证使用 480 条完全虚构的原始记录，跨 180 天，包含 24 次修订、12 次重复上传和 8 次隐私删除。模型与物理设备验证范围见仓库的 `docs/memory-lifecycle.md` 和验证报告；不使用个人截图。
