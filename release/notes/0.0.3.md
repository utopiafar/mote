# Mote 0.0.3

本次改进客户端设置的即时生效与图片保存位置。

- Android 与 Mac 保存设置后自动协调采集、OCR 和同步任务，应用新参数后保持原开停状态，不再需要手动暂停后重新开始。
- 采样间隔、画质、隐私规则和识别参数不会混用新旧配置；旧规则下未完成的画面在更新时失效。
- Mac 的“采集与存储”可通过系统文件夹选择器更改图片队列位置，并查看、打开当前位置。
- Android 的“采集与存储”可选择应用内部空间或系统提供的本机／存储卡应用专用空间，并查看实际位置与容量。
- 更改位置时迁移现有图片、待 OCR 记录、上传确认及节点归属，校验后再切换；失败保留已有资料，外部介质缺失不会新建空队列。

保存位置控制客户端本机队列，中央已归档图片仍使用中央节点的存储位置。模型、凭据和中央资料库不会随客户端图片队列迁移。Android 需要新投屏会话时仍会显示系统授权。

安装包延续原签名身份，Android 内部版本码为 **14**。从 0.0.2 升级保留既有配置与队列；与 0.0.2 中央节点兼容。Mac 延续现有 ad-hoc 签名方式。

使用方式见 [客户端设置与图片位置](https://github.com/utopiafar/mote/blob/v0.0.3/docs/client-settings-and-storage.md)。

测试范围与未执行的真机检查见 [0.0.3 验收记录](https://github.com/utopiafar/mote/blob/v0.0.3/docs/0.0.3-validation.md)。
