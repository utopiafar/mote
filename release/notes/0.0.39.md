# Mote 0.0.39

中央模型设置拆分为「模型 Provider」和「模块与模型」，连接凭据可供多个模块复用。

- 独立 Provider 页面管理连接预设、默认模型、模型目录与连接测试，支持创建、编辑、复制和删除。
- 部署文件与环境变量作为单独的只读预设；可复制成独立可编辑预设。旧版已保存配置与分配继续保留。
- Chat、Memory、个人回顾、资料导入、文件分析分别选择预设，可跟随预设默认模型或指定同一 Provider 下的其他模型。
- 复制凭据仅在服务器内部完成，不回显密钥；支持不带凭据复制。正在被模块使用的预设不能删除。
- 本机 Codex 自动读取 App Server 模型目录并使用本机登录调用；修正非默认预设加载目录时的凭据归属。
- 记忆批处理保留模块指定的模型，问答结果记录实际使用的预设和模型；新增中英文文案与手机宽度布局。

本地验收：723 项工作区测试通过，1 项原有可选测试跳过；类型检查、国际化检查、中央与网页构建、Provider 与导航界面回归通过。Fixture 测试仅使用生成资料。

真实模型验收：本机 Codex CLI 0.154.0，模型 gpt-6-astra；完成模型目录、合成连接测试，以及「创建/复制预设 → 模块指定模型 → 正式问答 → search_context → evidence → 有效引用」调用链路。使用临时合成笔记，未读取个人资料库或采集个人截图。未执行物理移动设备采集验证。

升级沿用现有私有 model-settings.json，并增加模块模型覆盖字段；保存新配置后不应直接降级至不识别这些字段的旧服务端。Mac 发布继续采用仓库既有 adhoc 签名模式。
