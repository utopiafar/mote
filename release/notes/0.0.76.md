# Mote 0.0.76 DEV

新增录音归档：连接中央节点已授权的飞书/钉钉账号，选择首次历史时间，之后在后台同步厂商转写和原始音频。厂商端删除、暂停或断开连接都保留中央归档。

- 录音 Provider 通过现有连接器插件登记，复用公共分页、检查点、持久任务、重试、账号授权、版本归档与观测能力。新增 Provider 的设置卡片自动发现，无需修改核心页面。
- 完整厂商转写直接形成细粒度证据和 Material，跳过 ASR。后台音频备份独立运行，失败不阻塞文本或 Memory；补齐音频及重复同步不再次付费提取。
- 来源级录音 Memory 配方独立提取与复核，保留有用的日记、对话计划、约束和未决事项。匿名说话人不自动认定为用户，未确认的归属保留在观察层。
- 支持归档原音回听/下载、日期范围、后台开关、同步状态及失败重试。长录音测试覆盖 2,500 个完整切片；浏览器验证了连接、后台同步、按需音频解码和 430 像素布局。
- 真实飞书云端样本已完成转写 → 音频备份 → 完整 Material → 模型提取/独立复核，得到 28 条带证据的观察层 Memory；重复同步复测没有模型调用。真实内容仅保存在本机私有验证目录。

钉钉适配器参考 DWS 1.0.62，目前仅模拟契约验证，尚未完成真实钉钉账号、A1/D3200 物理录音笔新录音和长期授权刷新验收。初次连接需要中央节点安装并授权官方 CLI；本机已有飞书授权可直接复用。
