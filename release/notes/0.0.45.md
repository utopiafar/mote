# Mote 0.0.45

本版重构了 MCP 的通用上下文查询层，保留原始归档、不可变 revision 与 evidence 链，同时为 Agent 提供统一的候选集合、检索、分段读取、上下文打包和状态水位工具。

- 新增 `mote_browse`、`mote_read`、`mote_context`、`mote_status`；`mote_search` 返回稳定 `ref`、命中片段、UTF-16 定位、来源和 evidence 引用。
- MCP 查询使用 `structuredContent` 与 `outputSchema`，旧客户端仍可读取兼容的文本内容；读凭据仍只暴露只读工具，写凭据仍只暴露受限的 `mote_put_item`。
- 加入稳定游标、查询条件绑定、索引计数与来源同步水位；Coding Agent 的 project/session/provider 只作为查询范围和解释字段，不作为硬编码意图分类器或 canonical project identity。
- 新增合成 fixture、查询分页/隔离/预算/性能回归，以及通过本机 Codex App Server 的真实 MCP 外部调用验收。

本版模型验收使用本机 Codex Server 和生成的虚构资料，未调用 DeepSeek，未读取或上传真实个人截图。物理设备采集未在本次重新验收。
