# Mote 0.0.73 DEV

本版修复后台同步影响前台阅读的问题，并补齐资料处理取消、恢复和证据阅读流程。

- 后台采集与同步使用独立的请求限额，避免补传占满额度后影响普通资料阅读与纯文本随手记保存；访问鉴权和限流保护继续生效。
- 中央接口限流显示“请求过于频繁”，不再误报为模型服务限流。
- 文件处理支持取消：保留原件及已完成产物，阻止迟到结果发布；旧请求仍在运行时等待收尾，状态未知时显式确认后重试。导入取消与确认也修复了相关竞争问题。
- 改善 Memory 手动整合、历史与来源阅读、时间范围选择保持，以及洞察取消和引用显示。修复资料入口跳转与 Markdown 表格在窄屏上的阅读。
- 完善 Android 节点切换、随手记恢复、采集原件保留与跨端证据导航；内置处理选项随界面语言显示，附件提示明确归档与识别的区别。

详细验证和剩余限制见 [0.0.73 验证记录](https://github.com/utopiafar/mote/blob/v0.0.73/docs/validation/0.0.73.md)。混合资料的原件归档与处理已验证，但部分前台并发覆盖、ASR 语义准确率、完整保留集 Memory 净收益及物理设备验证仍未完成；本版不宣称完整 Goal 已通过。

发布附件为 Mac DEV ZIP 和 Android DEV APK；中央节点从本标签源码部署。产品版本 0.0.73，Android `versionCode` 84。
