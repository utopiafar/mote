# Android 0.0.84 DEV (versionCode 95)

Start with “按应用配置” in Local. App details show the installed version and
configured article/product fields, with version-specific rule setup/import. The first
start previews the saved scope and generated record formats before permissions and
collection. Saving or cancelling a preview does not start capture. The permissions
page offers return to Local or the original settings page.

Page settings offer two choices: screenshots only, or pages first with screenshots
when content is unavailable. This mode applies to all content-authorized Apps;
rules still match each App and version. Field setup and import select the global
pages-first mode without expanding App authorization. Legacy `hybrid` and
`page_only` appear as pages-first and are normalized only when that page is saved.
Choosing and saving projection selects screenshots only; each new projection
session still requires system consent.

Accessibility capture prioritizes exact-version article/product fields. A usable
visible fragment replaces that sample's screenshot; no matching rule, missing
required fields or read failure falls back to the existing filtered screenshot.
Privacy rejection, lock, stop and stale App/configuration callbacks do not fall
back. Explicit screenshot-only and projection remain supported. App content scope
is unchanged by rule loading.

New records contain article title/body and any observed author, or product title
and actually exposed URL/item ID, without UI nodes or coordinates. Every observation
is immediately queued; the collector only performs bounded reliable-identity overlap merging.
Central performs organization and downstream interpretation. Long visible nodes
are retained within bounds instead of being dropped wholesale.

Built-in WeChat 8.0.78 article and Taobao 10.66.22 card rules are based on historical
structure and generated regression data. Their historical trees expose no reliable
URL/ID; no link or cross-observation identity is guessed. New App versions need
their own adapters. Physical compatibility and live model results are not claimed.

Deploy Central 0.0.86 first, then install this DEV APK over the same DEV package.
Legacy queued v1 pages and current local-format settings are kept. Validation and
remaining acceptance scope: `docs/validation/android-page-fields-2026-10-10.md`.
