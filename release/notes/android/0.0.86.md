# Android 0.0.86 DEV

- 导入文件与文件夹同步使用统一任务编辑页；进入页面不弹文件选择器，点击选择按钮才打开。取消和页面重建保留草稿，导入明确为一次性任务。
- 音频目录收为文件夹的「音频文件」预设，新任务默认保留中央原件，用户可修改。范围、资料说明与保存方式更集中，过滤和频率收进高级设置。
- 选填资料说明以带版本的来源元信息保存，修改作用于已有及未来资料，不直接生成全局 Memory，不自动重新转写或重算历史收费任务。
- 旧来源设置保持。离线说明、版本冲突和丢失确认保留本机草稿及待发文件；中央确认来源和说明后才发送文件。

请先部署 Central 0.0.87，再覆盖安装此 Android 版本。公开 DEV APK 由组件发布流水线签名并校验包名、版本码及 16 KiB 对齐；无需卸载或清空资料。

生成数据的处理链和独立模拟器验证见[验证记录](https://github.com/utopiafar/mote/blob/main/docs/validation/android-file-source-context-2026-10-12.md)。没有将模拟器与合成模型结果当作真机或真实模型验收。
