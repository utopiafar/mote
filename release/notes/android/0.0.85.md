# Android 0.0.85 DEV

- 采用「首页 / 内容 / 问一问」导航；同步文件夹、导入文件、记录屏幕和随手记作为平等入口，设置和来源管理收进对应任务。
- 单个文件默认一次导入，可明确选择持续同步；固定快照与待传版本在重启、离线和重试时保留。
- 内容详情区分本机保存、中央收到和实际整理状态，发送状态从首页展开；屏幕记录、单个来源和全部发送分别暂停。
- 采样频率、画质、OCR、去重、打包和诊断参数放入高级设置，任务确认保留范围、完整文件去向及原件保留方式。

验证记录见 [客户端行动优先验证](https://github.com/utopiafar/mote/blob/main/docs/validation/client-action-first-2026-10-11.md)。公开安装包由组件发布流水线构建和校验，DEV 版本仍采用手动覆盖安装。
