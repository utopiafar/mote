# Mote Android 0.0.82 DEV

- 修复恢复备份时待人工复核截图被自动放行的问题；保留隔离状态，同 ID 合并不得放宽授权，异常授权标记拒绝导入。
- 移除文件来源轻量索引及本机转写说明，统一上传中央处理。
- 文件快照明确说明完整文件上传范围；旧来源缺少确认时暂停，需在来源设置重新确认。
- 文件快照与原件归档支持 512 MiB 分块暂存，严格校验上传确认字段。
- 页面替代截图时保留独立应用活动计时，通知正文应用用户配置的确切文字规则。
- 移除失效的通用 OCR/视觉模型入口、本机 VLM 进程、JNI 引擎及文件解码依赖；保留用于隐私文字审查的 ML Kit OCR。
- 修复状态刷新与保存设置之间的锁顺序死锁，避免设置页面永久等待。
- 清理通知移除采集的旧授权说明、无效本机处理状态及相关中英文文案。

版本码递增至 93。本版本提供同签名身份的 DEV APK，覆盖升级可保留数据。自动化使用生成数据；物理设备、真实录音与真实模型验收另行记录。
