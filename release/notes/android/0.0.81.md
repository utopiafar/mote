# Mote android 0.0.81 DEV

- 普通文件快照只采集与上传，改由中央提取和理解，退役本机文件解析 worker 与 read poller。
- 快照过期输入可恢复同一版本，重供前核对当前权限、字节和隐私；策略变更生成新版本，旧授权不会恢复。
- 通知只记录 posted/updated；移除回调在平台入口和收集器两层拒绝，不再制造删除事件。
- 配置备份完整保留 uploadGate 与 packedUpload 隐私设置；无效设置不会静默退回宽松默认值。
- 安全字面遮罩不支持的复杂文件格式会显示上传阻止原因。
- UI 页面采集增加共享生成矩阵，核对 app identity、页面变化与排除规则；同步新增英文提示。

版本 0.0.81，versionCode=92。Android JVM 255 项单元测试和 API-35 模拟器 20 项连接、配对、导航及页面测试通过；development APK、测试 APK 构建和 lint 通过，全部使用生成数据。物理设备、第三方 App 实际版本兼容、live ASR 和个人截图采集未在本次验证。公开附件保持原 DEV 包名与签名，可覆盖安装。

建议先升级中央端。中央版需要 storage epoch 3；先用旧版备份现有 profile，再使用新 profile 或明确选择重置，不提供自动旧库迁移。
