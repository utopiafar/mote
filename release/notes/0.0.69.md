# Mote 0.0.69 DEV

本版把中央功能的上报、上传、读取接口、操作入口、UI 页面与模型只读能力按功能包组合，保留现有采集和处理行为。前后端分别使用 Cordis 宿主，新增资料与模型观察入口。

- 资料库新增「正式资料」与「Coding Agent 上传」：查看接收原件、聚合正文、版本、处理产物、索引及记忆工作状态。
- 系统新增「模型可见目录」：使用问答 Agent 的真实只读接口查看当前可见资料；运行输入与工具事件单独展示，未开启追踪、已过期或截断的数据明确标注。
- 页面、资料库集合、正文渲染器与详情面板可独立注册；专用正文视图缺失时回退通用阅读。扩展面板显示实际注册的能力。
- 合入问答全库检索与有界记忆上下文、移除独立截图语义 Worker，以及 Android 权限/后台状态展示改进。

验证使用小型生成样本。全仓 `check:local`、实际浏览器导航与 26 个页面通过；本地 Codex App Server 的 `gpt-6-luna` 通过模型探测、检索、证据读取和引用检查。没有采集或上传真实个人截图；没有执行物理设备采集或真实外部账户操作测试。

GitHub Release 提供 Mac DEV ZIP 和 Android DEV APK；中央端从本标签源码部署。产品版本 0.0.69，Android `versionCode` 80。
