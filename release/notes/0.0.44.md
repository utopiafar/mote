# Mote 0.0.44

本版将可检索的事件/资料摘要与精选记忆分开，避免普通文章页面、通知和设备状态被反复提升为个人长期记忆。

- 每条新产物标明用途、适用范围、归属与分类；原始资料仍可检索。旧记录保留为“旧版未审核”，不自动成为精选记忆或参加长期整合。
- 提取和整合增加独立的只读模型审核，核对标题、意图、主体、时间与证据覆盖；严格验证每条原始引用，允许拒绝或降级。
- 长期整合只处理精选候选，拒绝换句话复述、无关约束拼单和低价值观察；每条结果只关联实际使用的候选及原始证据。
- 记忆模型来源采用实际调用账本，避免配置默认模型与实际生成模型混淆；批次保留最近的结构/引用校验失败记录。
- 自动提取启动后持续处理固定范围的积压，每分钟检查一次、每次一个窗口；每轮最多 100 个窗口（可配置），轮次完成后才重新等待周期。失败、停用和重启仍保留进度。
- 独立审核增加非空批次的模型调用；每轮窗口上限可用于控制积压处理成本。

真实模型验证使用本机 Codex App Server 和生成的虚构文本，未读取或上传真实个人截图。物理设备采集未在本次重新验收。验证记录见 `docs/memory-admission-validation.md`。
