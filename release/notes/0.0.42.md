# Mote 0.0.42

端侧专注采集、过滤与可靠上传，完整 OCR 和图片语义理解迁入中央。

- Mac 与 Android 的隐私设置集中提供可选文字规则审查、规则列表和失败策略。规则按原文精确匹配；没有规则时不调用 OCR。审查异常默认暂存待复核，可配置丢弃或允许上传。待复核记录不会被普通重试、重启或关闭审查自动放行。
- 本机 VLM 暂停执行，保留扩展接口；新截图不再创建本机完整 OCR 任务，也不要求下载审查模型。升级前的旧 OCR 队列继续兼容处理。
- 中央设置新增 OCR／语义 Worker 地址、处理版本、实时／分批／手动调度和逐条重处理。截图先归档，持久任务独立产出版本化结果，OCR 就绪即可检索；识别失败不丢失原图。未配置 Worker 时任务等待配置，不会自动提供 OCR 服务。
- 查询先读取 OCR／语义证据，必要时由模型显式请求原图。原图披露默认关闭，外部 Worker 处理也需单独开启。模型读图使用真实图像内容项，保持只读工具和证据范围限制。
- Android 在既有同步流程中增量缓存中央识别预览；Mac 从中央记录页按需读取。原始上传保持幂等，导出恢复包含派生版本。
- 保留 0.0.41 的原生问答、截图去重、打包上传和上传速率功能。

配置、Worker 协议和升级说明见 [中央感知文档](https://github.com/utopiafar/mote/blob/v0.0.42/docs/central-perception.md)。使用前需配置遵循 image.http 协议的 OCR／语义 Worker；查询读图需要支持视觉的模型。

验证使用生成截图、模拟 Worker 与模拟模型，覆盖隔离队列、中央持久任务、缓存、中文检索、删除、导出恢复、权限隔离和真实多模态请求结构。工作区类型检查、单元测试及 Android lint／测试代码编译通过；发布流水线再次验证界面与跨平台产物。未执行真实个人截图采集、物理手机功耗测试或真实 OCR／VLM 质量验收。

产品版本 0.0.42，Android versionCode 53。沿用既有签名身份、Bundle ID、包名和用户数据目录。
