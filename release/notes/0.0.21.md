# Mote 0.0.21

## 中央文件类型策略

- 设置页增加类型策略、独立处理方案、来源与类型覆盖。录音、图片、文本、PDF 和精确 MIME 类型可分别选择方案；同一目录中的不同类型独立处理。
- 服务地址和密钥集中管理，多个方案可复用服务并保留各自参数。支持本地服务、远程 HTTPS 服务与独立语言模型；本地多人录音继续禁止自动云端摘要和云端向量处理。
- Cordis 插件声明参数后，页面自动生成配置表单。支持复制方案、规则试算、服务检测和配置冲突校验。
- 文件详情和导出显示实际使用的规则、方案、参数与配置版本。修改默认策略保留已完成结果；批量重处理需先预览，再明确提交预览中的文件。
- 兼容既有处理配置：首次打开转换为方案预览，保存后启用。凭据不回传页面，服务变更时要求清除或更换旧密钥。

- 修复 Mac 发布测试的异步缩略图等待：明确验证加载中与加载完成两种状态，避免在进度阶段误判最终总数。

## 验证

- 完整工作区回归、类型检查、中央与网页构建、隐私和跨层端到端测试通过。
- Android 发布 lint、127 项单元测试，以及专用模拟器生成文件跨端测试通过；核对 3 份原件、205 份 Shadow、断点续传、新增/回填和保留源文件。
- 使用生成录音验证真实本地 ASR、说话人分离、试听样本与导出，并验证真实 DeepSeek 摘要和检索引用。记忆提取首次返回 502，单独重试后成功生成 8 条候选记忆。
- 浏览器验证方案复制、参数隔离、来源与类型覆盖、规则试算、重处理预览以及桌面和窄屏布局。
- 真机验证后补；未验证真实云 ASR 厂商接口、真实本地语言模型推理或长录音质量。Mac 包沿用当前 adhoc 签名。
