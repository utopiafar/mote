# Mote 0.0.61 DEV

本版集中修复长期归档、断点恢复、后台处理、证据检索与跨端操作的一致性问题。原件、来源版本和用户确认仍是事实依据；模型解释不会替代原始证据。

- 统一执行步骤、Operation 任务中心、取消与提交保护。文件、采集、Memory、行动分析、导入、问答、洞察和向量索引共用持久执行机制，重试保留检查点，配置变化只使相关结果失效。完成任务会释放超时定时器，避免长期运行积累；可选向量失败保留原因且允许问答降级完成。
- 修复多 SQLite 连接下检查文件权限可能释放现有进程锁的问题；备份恢复清除失效租约，保留已完成导入步骤及 Memory 批次，不自动重发中断的交互模型任务。
- 十万条目录采用增量扫描和 SQLite checkpoint；Mac、Android、Web 分片轮转上传，历史积压期间新资料仍能推进。归档成功、中央加工和来源覆盖分别显示。
- PDF、DOCX、XLSX 共用有界解析器；原件始终保留，缺失文本层、未知作者/时间和部分覆盖明确标记。清单验证、哈希及格式处理移到 worker。
- 统一跨协议引用、版本与范围校验；修改一段只使相关后代失效，历史洞察保留固定快照、版本与覆盖缺口，跨设备重叠时长不重复当作工作时间。
- 统一语义产物中的候选记忆与行动线索；增加长期记忆的矛盾、替代、用户纠正及历史查询，项目限定不自动扩大。外部采集不能伪造宿主生成的用户纠正标记。
- 日历支持跨来源关联与改期、取消、完成提议；写入仍须显式确认。原生写入绑定原目标与操作标记，结果不明时只读核实，避免重复写入。
- 增加每日、服务与任务 token/金额预算，HTTP 请求前事务预留，重试、审核、压缩及 embedding 纳入计量。Codex 提供累计 token 回执；无法逐请求拦截其内部循环，因此启用硬预算时明确阻止该运行时，而非声称能严格限额。
- 页面读取采用认证会话隔离、取消和版本检查；统一资料详情、任务订阅、恢复入口与中英文状态。新增预算编辑、Memory 纠正和行动变更旅程。
- Gmail 只读来源支持 OAuth、增量历史、重扫、撤权及备份恢复。本轮按用户要求跳过真实邮箱测试，合成邮件夹具仍执行。

验证方法、生成数据规模、真实 LUNA 对照和未验证边界见仓库 [验证记录](https://github.com/utopiafar/mote/blob/v0.0.61/docs/testing-0.0.61.md) 与 [逐项清单](https://github.com/utopiafar/mote/blob/v0.0.61/docs/implementation-backlog.json)。功耗及实体 Android 设备旅程没有实测，不把模拟器结果当作真机结果；有限质量样本不构成普遍准确率保证。
