# Mote 0.6.1

修复 Mac 在依赖系统网络代理时检查或下载更新超时的问题。更新器改用 Electron 的网络传输，支持系统代理；请求不携带登录 Cookie，继续验证允许的下载地址、发布签名、文件大小和 SHA-256。

本版包含 0.6.0 的二维码／JSON 配对、独立可撤销凭据和 Android 采集与存储统计。请先升级中央节点，再覆盖安装客户端，保留原设置、队列和模型。

如果旧版 Mac App 的检查更新因网络超时而失败，可从本页下载 ZIP，用 Finder 替换 App。Mac 仍为 adhoc 签名；Android 日常版与 Dev 使用各自包名，继续使用既有签名身份。K90 Pro Max／HyperOS 的物理扫码和长期后台行为尚未实测。
