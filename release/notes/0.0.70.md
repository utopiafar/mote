# Mote 0.0.70 DEV

本版修复采集重试、正式资料到 Memory 的处理边界，以及查询和功能生命周期问题。

- Mac 文件读取失败后会重试变化内容；单文件「仅新增」完成首次基线后继续识别修改；重启后可从持久目录索引定位文件证据。
- Android 调整排除规则后清理旧候选和待上传原件，每次上传重新核对当前来源与待传版本。
- 手动 Memory 按时间范围选择当前正式资料，包括 Coding 会话，并沿用已声明处理依赖；后台截图读取使用有范围和指纹约束的授权。只读校验复用结果，独立模型审核保留。
- MCP 返回包遵守实际字符预算，分别续读 Memory、Coding 会话和记录；洞察快照纳入正式资料版本，会话数量不计为活动时长。
- 资料库活动视图自行加载数据，功能列表请求失败可重试；导航和页面来自同一个注册表。
- 功能包统一释放后台定时器、执行处理器和查询能力；新增只读工具可集中声明 schema、版本、权限及预算，并在每次运行固定工具集。
- 减少来源整理重复读取；统一 500 条采集包限制；保留流水线存储约定以支持缺失旧插件时替换；按当前配置重处理录音复用未改变的 ASR，图片服务迁移保留凭据。
- 清理旧依赖双写、空方法、同步向量扫描、不可达设置分支与过期 action 变更记录；暂停的本地内容审查不阻碍普通设置，推理进程按需创建。

验证范围和回归记录见 [0.0.70 验证报告](https://github.com/utopiafar/mote/blob/v0.0.70/docs/validation/0.0.70.md)。全仓检查通过 1,416 项测试，Android 通过 214 项测试，另完成页面、采集、媒体、隐私及 MCP 端到端回归。所有采集和页面验证使用生成数据；本次没有执行物理设备采集或真实模型调用。

发布附件为 Mac DEV ZIP 和 Android DEV APK；中央节点从本标签源码部署。产品版本 0.0.70，Android `versionCode` 81。
