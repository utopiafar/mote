# Mote 0.0.68 DEV

本版修复 Mac DEV 客户端连接中央端 v2 时的身份确认错误，并让 Codex 模型设置按接口返回的目录显示推理挡位。GitHub Release 提供 Mac DEV ZIP 和 Android DEV APK；中央端从本标签源码部署。

- Mac：接受中央身份响应中可选的 `capabilities.ingressVersion` 数值字段，避免邀请码兑换后把有效响应误判为格式无效。
- Android：客户端原有校验已兼容该新增字段；配对测试使用中央当前的响应格式。
- 中央与网页：读取 Codex App Server `model/list` 中各模型支持的推理挡位和建议默认值，按所选模型展示选项，保存后向 `turn/start.effort` 传递所选值。旧设置的“关闭”继续对应接口的 `none`。

升级前请备份中央数据；Mac 和 Android DEV 客户端与中央端应使用同一版本。此前配对失败的邀请码可能已兑换成功，需在中央为该设备重新生成绑定邀请。

验证：两个改动的 `npm run check:local` 均通过。Codex CLI 模型目录做过只读查询；Mac 配对使用生成数据的测试中央通过；Android 开发版单元测试与仪器测试编译通过。未运行真实模型推理、物理设备测试或 Android 模拟器配对。Mac 本地原生打包缺少固定的 `llama.cpp` 源码，发布流水线将按现有流程获取并构建安装包。

产品版本为 0.0.68，Android `versionCode` 为 79。
