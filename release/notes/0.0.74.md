# Mote 0.0.74 DEV

本版修复 Android 本地同步等待和文件处理状态未知时的重试确认。

- Android 连接本机中央节点时，避免系统网络验证条件阻挡本地补传；手动同步可以启动等待中的队列。自动远程同步仍遵守 Wi-Fi、非计费网络、电量和充电设置，发送各类资料前都会重新检查当前条件。
- 文件处理状态未知时，使用应用内重试确认弹窗，支持取消、Escape、键盘焦点保持和返回原按钮；确认仍针对原处理阶段，切换节点后清除待确认操作。
- 保留随手记原件、离线队列和处理产物；补齐相关回归与有界测试执行检查。

详细结果和限制见 [0.0.74 验证记录](https://github.com/utopiafar/mote/blob/v0.0.74/docs/validation/0.0.74.md)。完整跨端界面验收、混合输入前台重叠、ASR 语义准确率及完整 Memory 盲测仍在继续，本版不宣称完整 Goal 已通过。

发布附件为 Mac DEV ZIP 和 Android DEV APK；中央节点从本标签源码部署。产品版本 0.0.74，Android `versionCode` 85。
