# Mote 0.0.2

本次完善采集记录的回看与 OCR 节能处理，并修复 Android 导航和桌面页面采样。

- Android 底部四个 Tab 单次点击即可切换，保留页面草稿与滚动位置。
- Android 与 Mac 新增“仅充电时 OCR”：未接电时先保存图片，接电后自动补识别。停止采集不影响已有图片的补做；任务和图片持久保存，重启后可继续。
- 默认完整内容采集支持系统桌面、启动器及没有明确前台应用的画面；用户显式排除、仅活动规则、遮挡和锁屏保护继续生效。
- Android、Mac 和中央 Web 可按天浏览采集记录、加载缩略图、展开原图及文字详情。客户端区分本机记录与中央已归档记录，明确显示待 OCR、已完成、已关闭、失败与旧记录状态未知。
- 设置新增“反馈”，直接打开 GitHub 问题表单并预填版本、平台等基本信息；图片和日志可在 GitHub 页面自行添加。

## 更新顺序

请先更新中央节点，再更新客户端，以启用本设备归档浏览和 OCR 补写接口。继续使用原配置、凭据、模型和资料目录；不要卸载应用或清空队列。Android 内部版本码递增为 **13**，延续原签名身份。Mac 包使用现有 ad-hoc 签名方式。

OCR 文字由采集端本地识别，中央只接收结果并更新检索索引；补做不会重新采集屏幕。开启节能选项不代表已测得具体省电比例。未完成 OCR 的图片即使已传中央，也会暂留本机并占用原有存储配额，直至补写确认完成。

验证范围与具体结果见 [0.0.2 验收记录](https://github.com/utopiafar/mote/blob/v0.0.2/docs/0.0.2-validation.md)。真机耗电、个人屏幕及真实视觉模型效果不以合成测试替代。
