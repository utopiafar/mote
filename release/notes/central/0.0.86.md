# Central 0.0.86 DEV

Android article/product capture now uploads selected original fields rather than
the raw UI tree. Central accepts field-page v2 on the existing capture transport,
retains immutable original observations and publishes searchable page Materials.
Real URLs/source IDs support aggregation within a device and App; identity-free
observations stay separate. Exact overlapping paragraphs can merge, while changed
headers and disjoint text remain available. Field pages bypass compressed screen
summaries and do not trigger OCR or a new automatic model authorization.
Android timestamp variants are normalized together, so retries, archive export
and import preserve the page protocol's observation-time invariant.

Legacy v1 page records remain readable. Deploy this Central version before Android
0.0.84; older nodes reject v2 and the Android durable queue keeps pending records.
No storage reset or historical raw-content rewrite is required.

Validation uses generated fixtures and real HTTP capture ingestion, including
retry, restart, deletion, identity isolation, long original text and invalid-field
rejection. The final local check and emulator results are recorded in
`docs/validation/android-page-fields-2026-10-10.md`. Physical App and live model
acceptance are separate; this release does not claim those checks.
