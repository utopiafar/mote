# Mote central 0.0.79 DEV

- 统一 Mac、Android 和浏览器登录（#58）：新配对及历史客户端凭据拥有与节点 Token 相同的完整客户端权限，问答、资料库、设置、连接器、导入导出和后台同步共用登录。有效期、撤销和提交前权限复核继续生效；MCP 凭据维持独立权限限制。
- 网页导入支持连续添加独立批次、并发上传、单项暂停与重试、页面切换后继续处理（#57）。限流后按服务器等待时间自动续传，丢失回执通过请求身份对账；原件保留、解析预览及确认策略沿用既有后端队列。未完成的本地文件上传需要保持当前浏览器会话，刷新或关闭后需重新选择。
- 上传确认与内容处理解耦（#59），云录音音频备份和转写独立执行、独立恢复；转写失败或未完成不阻塞原音频归档。保留来源授权、输入身份、去重与删除复核。

公开附件为中央源码包。建议先升级中央端，再更新 Mac 与 Android；旧客户端的重复登录界面需要随客户端升级才能消除。历史配对凭据升级后也可跨设备读取、管理、删除和导出完整资料，请在中央连接管理中撤销不再使用的设备。旧中央不能直接读取新增 owner/有效期注册条目，回退请按统一登录说明恢复旧连接配置并重新授权。
