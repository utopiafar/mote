# Central 0.0.87 DEV

Source descriptions are now owner-controlled, versioned private metadata. The
current description applies to existing and future Materials while preserving
individual ownership corrections. Read-only source discovery, attribution reads,
file summaries, Memory and Ask share these declarations. Descriptions do not
directly create global memories or identify anonymous speakers.

Changing or clearing a description withdraws outdated current interpretations and
rejects late results that read the previous version. Originals and ASR/OCR remain
available. Completed historical processing is not automatically reauthorized or
recalculated; the owner can explicitly retry it. Conversation and delegated-work
lineage also records source-only reads without manufacturing capture evidence.

Deploy this Central release before Android 0.0.86. Existing sources with no
description retain their settings, and ordinary registration cannot clear a
description. Metadata synchronization supports version conflicts and lost ACKs;
portable backups preserve private description history.

Validation uses generated fixtures, real HTTP upload/processing entry points and
separate Android emulator checks. See [the validation record](https://github.com/utopiafar/mote/blob/main/docs/validation/android-file-source-context-2026-10-12.md).
Physical-device and live-model acceptance are separate and are not claimed here.
