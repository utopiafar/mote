# Mote Central 0.0.93

- 登录前只显示当前能用的操作。聊天发送有状态反馈，返回 Web 时保留聊天草稿。
- 资料详情在宽屏从右侧打开，在手机上从底部打开。关闭后焦点回到原处。界面遵循系统的减少动态效果设置。
- 返回 Web 时，已变化的时间线只读取一次。文件来源的保留设置会在中央支持时显示。
- 删除原资料会清除未完成问答的旧输入。撤回一条资料的授权后，同批其他仍可回答的问题会留在活动页。
- 中央重启后处理积压的记忆任务时，复用已核验的策略版本，减少重复计算。

Central 与 Web 同版本。更新前备份现有配置和资料，按[更新指南](../../../docs/updating.md)替换程序。发布验证使用隔离的 Central、生成资料和本地模拟的模型服务。
