# Mote Central 0.0.84 DEV

- 新增持久化自主委派运行时。问答模型可以提交有界工作分支、释放等待期间的模型名额、读取私有结果并恢复协调；分支支持独立取消、重试和重启恢复。仍由既有 ExecutionEngine 管理租约及提交权限。
- 自动记忆整理由模型选择工作包，支持兼容授权下的跨来源合批；有界目录穿插来源，避免单个来源的积压独占规划。每份输入保留独立授权、修订和范围，事务内领取全部成员；逐输入覆盖与候选容量校验防止缺失或截断被误报完成。零候选同样经过独立审查，拆分和恢复复用有效草稿与检查点。
- 背景不足会触发持久模型反馈规划：仅在原授权范围内补背景或重组未完成目标，背景不重复计入成果与覆盖。两轮仍未解决或背景越界时等待输入，重启与重试保留计划、授权和成功检查点。
- 新增“活动”主入口，按目标、工作分支、成果和原始证据展示工作。确定输入显示实际覆盖份数，开放问答展示阶段与计数；技术处理记录保留在高级入口，Agent Inspector 继续提供读取范围与实际输入。
- 记忆任务列表新增游标分页；问答提交、跨进程取消和证据删除校验与委派共享持久记录。子任务结果不能自动扩大原文引用权限，宿主重新验证交付的原始证据。
- 纳入上一版之后的图片统一处理、独立 OCR 与图像理解就绪状态、录音内容查询范围修复，以及移除每日处理和模型硬预算。

本版本为 Central DEV 预发布，提供中央源码包。不会自行修改模型、推理强度或用户配置的并发，也不会为历史输入补发自动记忆授权。A2A 保留为外部适配边界，本版不部署外部 A2A 服务。
