# Mote Central 0.0.82 DEV

- 修复网页导出后无法导入的问题，便携 JSON 使用实际 v2 契约。
- 便携归档保存正式资料的版本、正文、证据锚点及血缘，恢复后可核验依赖这些资料的 Memory；缺失证据、内容损坏与历史冲突会整体回滚。
- 转写修正、说话人确认使旧摘要失效；摘要固定输入指纹，拒绝晚到的旧结果。
- 文件快照与原件归档统一执行中央 recipe；通知正文进入正式资料与自动上下文分段。
- 删除原始证据后撤下已展开的旧对话页，防止分页缓存继续展示旧答案和引用。
- 手动 Memory 整理在入队事务中核对用户选中的版本；导入详情与文件详情共享处理等待、取消及未知结果重试确认。
- 更新中央正文读取、索引覆盖及文件保存范围说明。
- 关闭中央时保留待执行任务、已完成检查点与未知处理请求，重启可安全恢复；文件与语音设置集中到设置页，profile 启动支持环境代理。
- 本机语音、图像处理及状态探测强制直连，避免环境代理接收本机处理原件或授权头。

本版本为 DEV 预发布，提供中央源码包。验证使用生成数据，物理设备、真实模型与真实 ASR 检查另行记录。
