# Mote desktop 0.0.80 DEV

- 清理历史 GitHub 发布后，重新提供当前整合版本的 macOS DEV 安装包。
- 包含统一的问答、资料、来源同步与设置登录；中央浏览器通过一次性代码接续登录，退出、过期和撤销同步更新状态。
