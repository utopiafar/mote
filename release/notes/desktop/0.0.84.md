# Mote Desktop 0.0.84 DEV

- 新增「上传同步」页面：当天 / 最近 7 天接收确认、实际传输量、本机待传及待处理汇总，支持按日期、来源、结果筛选与分页。
- 每轮同步可查看接收凭据，并逐条预览截图、页面文字、随手记、应用活动、通知、文件、日历和 Coding Agent 内容；已上传内容从中央读取，失败记录读取仍保留的本机副本。
- 同步历史按当前中央节点与设备隔离，保留 30 天，仅记录元数据与接收标识。升级后开始记录，无法补齐旧版本历史。接收确认与中央识别、索引、整理分开展示。
- 保留重试与中断凭据，同一条记录的重试确认不会重复计入汇总。中央内容过期后仍可查看同步结果。自动重试不会绕过隐私复核。
- 补齐中英文界面文案。

验证：桌面类型检查、`npm run check:desktop`，以及真实 Electron 窗口中的合成数据 UI 验证（分页、来源筛选、生成截图预览、内容转义、归档过期、弹窗切换与最小窗口布局）。`npm run check:local` 初次并发运行有两项中央测试出现异步状态断言失败 / 超时，两项均已单独复跑通过；未修改中央实现。未采集个人截图，未进行真实个人数据上传、物理设备或 live-model 验收。

本版本为 DEV 预发布，手动覆盖安装并保留现有配置与数据。此次仅发布桌面客户端，中央节点无需随此次更新。
