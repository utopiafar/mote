# Mote desktop 0.0.81 DEV

- 普通文件快照改为上传临时字节，由中央提取、ASR 和理解；退役本机解析/轮询处理通道。重试、断线与丢失确认保留传输队列恢复能力。
- 手动本地扫描保持离线；实际上传时才恢复过期输入，同版本保持观察时间，隐私变更拒绝重用旧授权。
- 用户配置的字面隐私遮罩只在能安全处理的格式上上传；复杂格式无法保证遮罩时显示阻止原因。
- 相同屏幕去重后仍保存不含图片的实际观察，保留可测时间，不重复存储截图。
- UI 采集内置适配器增加与 Android 共用的生成覆盖矩阵。
- 更新共享中央界面：索引失败可读正文并单独重试、Actions 固定核对版本、Insight 双条件，以及派生历史隐私错误的恢复提示。

桌面 387 项测试通过；快照、传输恢复和页面适配验证使用生成 fixtures。三组真实模型验收通过本机 Codex Server，未使用个人截图。第三方 App 的实际版本兼容、物理设备和 live ASR 未在本次验证。Mac DEV ZIP 使用既有 DEV 签名方式。

此版随中央 storage epoch 3 更新，旧库不自动迁移。先用旧版备份现有 profile，再使用新 profile 或明确选择重置；建议先升级中央端。
