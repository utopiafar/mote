# Mote 0.5.0

本版增加客户端应用内更新、中央节点的版本检查与受控升级，以及 GitHub Actions 构建、签名和 Release 发布流程。

- Mac：检查与下载新版本、验证发布签名和 ZIP、退出后替换 App，并保留 profile、Keychain 配置、草稿、队列与模型。无法安全替换时保留旧版本并说明原因。
- Android：检查、下载和验证实际 APK 的签名、包名及 versionCode，交由系统安装界面确认；不卸载旧应用，不重置设置或待同步内容。日常与开发版分别提供安装包。
- 中央节点：管理界面检查新版本；命名部署环境通过 CLI 校验发布清单、准备独立程序目录或不可变容器镜像，备份后升级并验证健康状态。回退保留当前外部账户授权并重建同步游标。
- 所有更新清单使用内置公钥验签，安装包另校验 SHA-256 和大小；未通过验证的下载不会安装。GitHub 检查不携带中央令牌或个人资料。

Mac 本次发行采用 **ad-hoc 签名**，尚未完成 Apple Developer ID 签名和公证。系统可能要求允许应用运行或重新授予 Keychain/日历/屏幕权限；程序不会据此删除原设置。安装包文件名标明 CPU 架构。

Android 保留本项目此前安装包的签名身份，发布构建关闭 debuggable；开发版使用独立包名。若设备上安装的是别人重新签名的构建，系统无法直接覆盖，Mote 会拒绝自动安装且不会通过卸载解决冲突。

服务端源码包需要 Node.js 24 与 npm，在目标架构构建；容器镜像提供 Linux amd64/arm64，具体不可变 digest 记录在已签名清单中。独立发布源码包不包含个人资料、配置、模型权重或签名私钥。
