# Mote 0.0.8

完善 Android 与 Mac 客户端的加载反馈、记录浏览和本地日志查看。

- 采集、记录读取、缩略图与详情加载显示阶段或进度；失败明确提示，详情读取不再排在整页缩略图之后。
- Android 采集与存储详情按页浏览记录，长说明可折叠；本地日志支持信息、警告、错误筛选和分页，两端均可直接查看，不必先导出文件。
- 权限页面显示当前授权状态，返回应用后刷新；区分无障碍授权、服务连接与投屏会话。
- 点击采集中通知复用现有任务，保留当前页面与草稿，不重复打开详情页。
- 修复日志筛选重复行和损坏日志被误判为空的问题，保留原始文件并显示读取失败。

保留 0.0.7 的后台媒体采集功能。Android 内部版本码递增至 **19**，沿用既有签名身份，覆盖安装保留设置、队列和模型。

验证使用生成数据及专用模拟器；未进行真机长期后台、个人截图或真实大模型质量验证。完整范围见[客户端验证记录](https://github.com/utopiafar/mote/blob/v0.0.8/docs/client-feedback-validation.md)。
