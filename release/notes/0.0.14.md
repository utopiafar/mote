# Mote 0.0.14

Android 采集记录改为两级 App 相册，减少进入页面时等待完整记录解密和图片加载的时间。

- 一级按 15 分钟时间段与 App 分组，显示应用图标、采集时间、记录数和截图张数；图标异步加载。
- 点击相册后立即显示网格占位，缩略图在后台逐张加载；点击单张再查看原图、OCR 和完整上下文。
- 本机新增加密的轻量浏览索引和缩略图缓存。旧记录首次自动补建索引，原始记录和图片格式保持兼容；索引可重建，缩略图跟随记录清理并计入存储用量。
- 中央归档新增轻量相册接口与 SQLite 浏览索引，图片权限校验不再加载完整记录。Android 中央相册需要配套更新中央节点。
- 相册与图片使用游标分页，持续新增采集不会挤动已浏览的图片页；切日期、切来源或返回时，旧页面的图片任务不会覆盖新页面。

Mac、Android、中央服务与网页统一为 0.0.14，Android versionCode 为 25。沿用既有发布与应用签名身份；Mac 使用 adhoc 签名。Mac 与中央网页的采集记录布局保持原样。

本地验证通过 113 项 Android 单元测试、156 项服务端测试，以及专用模拟器的相册入口、即时占位、翻页与单张详情测试。1,000 条生成记录的冷启动目录与两页网格查询只解密 16 个索引文件，未读取完整记录。该测试不代表真机耗时；本次未采集个人截图、未调用真实模型，尚未验证实体手机与 HyperOS 后台行为。发布流水线继续执行完整构建、跨端回归、签名与包身份校验。

详细范围见 [相册改动与验证说明](https://github.com/utopiafar/mote/blob/v0.0.14/docs/capture-albums.md)。
