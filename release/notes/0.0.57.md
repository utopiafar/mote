# Mote 0.0.57 DEV

跨端 Slate 界面与导航重构：

- 中央工作台收敛为今天、资料库、问一问、行动、连接；系统管理、设置、帮助固定在底部，记录始终可达。
- 资料、来源、设备、授权与系统页面按作用域分组；旧链接继续可用，证据支持浏览器返回、前进和焦点恢复，原图按需展开。
- 新增真实上下文处理任务与处理器列表，显示依赖、失败原因和等待额度；仅提供后端允许的重试/取消操作。
- Mac 聚焦本机采集、记录、来源、隐私与同步；Android 改为今天、资料、问一问、本机四个入口，保留独立中央授权。
- 共享 Slate 颜色与状态语义，改善窄屏布局、键盘操作和配置草稿离开提醒。

开发阶段每次发布仅附 Mac DEV ZIP 与 Android DEV APK。校验元数据留在 CI，不发布正式客户端、服务端源码包或哈希/签名附件。DEV 客户端从 GitHub 手动下载安装；不绕过旧签名更新机制安装未签名清单的包。

Mac 使用 `dev.mote.collector.dev`，Android 使用 `dev.mote.collector.dev`，与原正式应用分开。旧正式应用的数据不会自动迁入 DEV；已有 DEV 数据目录与身份保持不变。中央服务继续从源码部署，升级前请备份。

验证使用生成资料与临时环境；未进行真实个人截图采集、实体 Android 设备或在线模型验证。
