# Mote 0.0.67 DEV

本版把中央端的来源接收、处理、正式资料发布和 Agent 读取统一到后端 v2 流程，并同步升级 Mac DEV 与 Android DEV 客户端。Release 仍只提供两个 DEV 安装包；中央端从本标签源码部署。

- Coding Agent 的一段对话整理为一份完整的逻辑 Markdown 资料。正文可分页，索引和 Agent 以会话资料为入口；逐条原始事件不作为独立模型资料暴露。追加事件只更新资料尾部与新版本。
- 接收入口返回持久化收据；版本化配方、受控原件读取、执行提交栅栏和正式资料版本共同处理重试、取消、删除与重组。Mac、Android 和 CLI 使用 v2 协议。
- 查询可以读取当前合法可见的部分资料及处理状态；Memory 按来源声明的命名产物依赖等待。对话随附图片可在本次查询授权范围内按需读取，高频截图原图默认不进入 Agent 目录。
- 文件导入在高置信且无歧义时自动发布；低置信、部分覆盖或有歧义时保留预览等待确认。内置或本地受信 Python Source Pack 在受限子进程执行。

**断代升级：**旧客户端不能连接 v2 中央端，必须同步安装本版。旧中央库不自动迁移；先备份并停止中央服务，再按 [后端断代说明](https://github.com/utopiafar/mote/blob/v0.0.67/docs/backend-plugin-rearchitecture.md#mvp-断代操作)显式清空旧库，之后用本标签部署中央端。便携 JSON 导出不包含完整历史；清空会删除旧资料和旧连接。客户端首次运行 v2 会清理旧待传队列并重新扫描来源。

验证：生成数据的 `npm run check:local`、服务端和 Web 构建，以及 Android JVM 测试通过。未在物理设备、真实模型或真实个人资料上验证；本地 Desktop 原生打包缺少固定 `llama.cpp` 源码，发布流水线会按现有流程下载后构建并核验两个 DEV 安装包。

产品版本为 0.0.67，Android `versionCode` 为 78。
