# Mote 0.0.24

## 从原始资料到记忆与洞察

- 中央网页新增导入、记忆任务进度和洞察报告。支持提交多个文件、ZIP 或服务器目录，用自然语言说明资料的来历和解析要求。
- 先保存原件，再由独立导入 Agent 使用通用解析工具和脚本理解格式。预览列出记录、附件、未纳入与暂不支持的文件；用户确认后才保存可检索记录。解析失败或模型未配置时保留原件。
- 记录保留原始时间、内容角色、来源版本及附件关系；可区分作者原文、转述、摘要与引用文章。来源设备离线时，仍可检索已经归档的资料，并下载原件。
- Memory 使用持久分批任务，独立显示提取进度和失败原因。候选记忆引用原文精确引句和位置；保存检查点避免重复处理，来源变化使旧结果失效。记忆默认待确认。
- 洞察 Skill 生成带原文引用的静态 HTML 报告，同时保留 Markdown 文字版。报告在隔离的网页框架中展示，原文入口由宿主提供。

## 恢复与兼容

- 模型输出格式或引句位置无效时，最多自动重新生成一次；无效结果不入库。原始证据删除、变更等冲突不会被当作模型格式错误重试。
- 部分导入失败后保留逐条进度及本次新增证据，Memory 失败不影响已保存的原件和记录。删除整次导入时保留其他任务仍引用的资料。
- 完整离线备份兼容通用导入原件与客户端分块文件，保留加密字节、处理历史和额度记录。恢复时清理上传缓存、恢复中断的文件处理阶段；未完成导入重新分析并确认预览，不使用旧目录中的生成脚本。
- 合并最新主线，保留客户端文件同步、文件处理方案、原始日志和后台任务进度；纳入 Android 采集与批量同步优化，以及中央开发启动时重建依赖的修复。

## 验证与升级

- 合成回归覆盖通用解析、版本及原件引用、任务恢复、严格引句校验、报告清理和两种文件布局的加密备份恢复。发布工作流继续执行完整构建、集成检查和签名验证。
- 另用真实 DeepSeek 对合成日记、ZIP 收藏、CSV 偏好变化和多版本资料进行多轮导入、问答、Memory 与洞察核对；记录并修复了格式、引句位置和事实范围问题。模型输出仍需回到证据核对，候选记忆不等于已确认事实。
- 未进行真实个人资料导入、物理设备采集验收或真实 NAS 断电验证。详细范围见 `docs/central-memory-validation.md`。
- 产品版本 0.0.24，Android versionCode 35；沿用既有发布签名与用户数据目录。升级前停服备份，保留已有数据加密密钥。
