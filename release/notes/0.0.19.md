# Mote 0.0.19

## 客户端后台处理与进度刷新

- Android 将设置与凭据读取、加密草稿保存、保存预检查、文件和日历来源管理、模型导入、诊断导出、更新安装准备等耗时操作移到后台。主界面定时显示处理阶段与耗时，存储迁移报告文件进度。
- 随手记输入合并为最新待写草稿，保存按顺序提交。页面暂停后停止轮询，关闭后停止更新旧视图；保存预检查等待存储期间旋转页面，已确认的提交仍继续完成。
- Mac 使用独立工作线程处理备份解析与校验、图片遮罩与编码、缩略图和来源 JSON 读写。备份、采集图片、浏览预览与来源保存各自排队，界面每秒刷新后台操作状态。
- 减少队列状态与图片分页的重复正文复制；阻止重复提交和轮询请求积压，下载期间仍可取消。
- 保留 0.0.18 的文件原件归档、首次同步范围、Cordis 处理插件、录音转写与复核功能，以及 Android 10–12 文件回执兼容修复。

Mac、Android、中央服务与网页统一为 0.0.19，Android versionCode 为 30。沿用现有发布与应用签名身份；Mac 使用 adhoc 签名。

验证使用生成内容，覆盖后台任务生命周期、主线程响应、队列与设置锁竞争、页面旋转、连接与来源操作、备份和图片处理；发布流水线继续执行跨端构建、回归、签名与包身份校验。未采集真实个人截图，未进行实体手机采集或在线模型质量验证。

详细范围见 [客户端 UI 阻塞盘点](https://github.com/utopiafar/mote/blob/v0.0.19/docs/client-background-audit.md)。
