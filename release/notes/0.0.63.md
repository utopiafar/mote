# Mote 0.0.63 DEV

本版把零散采集整理为有稳定身份和版本的正式资料，并补齐端侧与中央的接入扩展点。继续发布 Mac DEV ZIP 和 Android DEV APK；中央端从源码部署。

- Mac 和 Android 的来源适配器、采集预处理阶段可注册和组合。阶段支持拆分、聚合、跨批次状态及重启恢复；既有隐私检查、状态合并、队列确认与重试仍由宿主负责，新来源可复用这些能力。
- 中央连接器改为带版本的 manifest 注册，新增可信模块可提供来源类型、同步与只读接口，而不需修改现有连接器分发逻辑。
- 新增正式资料存储：稳定 ID、不可变修订、分块正文/资产引用、成员定位、覆盖和保真状态。内置组织器分别处理来源条目、Coding Agent 会话、屏幕片段、状态序列与普通采集；上传确认与资料发布分开。
- 中央处理器现在可按固定资料修订读取有界页面，按实际正文计入预算；资料修订或撤回会使依赖它的处理产物失效。
- Owner API、MCP 和问答 Agent 提供有界资料目录及按修订分页读取。模型看到的是获准范围内的资料表示；要引用具体事实，仍需展开对应原始证据。采集文本始终是不可信证据。
- 文件按单个来源项保存原件和转写/解析块；录音不跨文件合并。屏幕与状态按各自规则组织，Coding Agent 事件按明确会话身份组织。

资料整理是异步的，刚上传的数据可能先出现在原始证据层。长会话和超大文件在当前资料页上会标明覆盖不完整，可继续通过原始证据检索。端侧阶段顺序目前由应用注册确定，尚无按来源编辑流程的界面；Mac 暂不支持跨批次持有图片。现有 Memory/洞察任务仍保留其原始证据校验路径；正式资料读取先用于目录与按需展开。便携 JSON 导出目前不会保留正式资料的历史修订；完整数据库备份可以保留。未进行物理设备长期运行或在线模型验收，测试使用生成的合成数据。

产品版本为 0.0.63，Android `versionCode` 为 74。升级中央前请备份数据。
