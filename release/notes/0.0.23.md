# Mote 0.0.23

## 原始日志中心

- Web、macOS、Android 直接显示日志文件原文，保留顺序与字段；不再解析成摘要表格或翻译卡片。
- 支持文本选择、全选、复制全文、手动刷新与自动换行；Web 可切换当前和历史轮转文件。Web/macOS 剪贴板不可用时自动全选并提示键盘复制。
- 日志读取有大小上限，中央日志接口继续使用管理身份鉴权并禁止缓存；支持包仍使用安全字段白名单。

## 分级日志与故障定位

- 采集、模型、OCR、隐私审查、入队、上传、来源扫描与桌面管理操作增加阶段开始、完成、耗时及失败日志。
- 新文件流程覆盖扫描、准备、上传、分块、提交、提取、说话人分离、轮次对齐和摘要。中央任务记录关联编号、尝试次数、重试间隔和缓存复用；配置/预算阻塞与取消有独立事件。
- 文件、处理设置与会话请求有明确路由类别及 HTTP 方法。4xx 阶段失败为 warning，正常配置变更取消不再被标作执行错误。
- Android 后台界面任务与批量去重增加分级日志；修复执行器拒绝任务后一直显示忙碌的问题。

## 验证与兼容性

- 合并至 0.0.22 最新主线，保留文件处理方案、后台进度、去重及会话功能。
- 工作区类型检查与合成回归、中央诊断/文件处理回归、Android JVM 测试、仪器测试编译与 release lint 通过；发布流程继续执行完整打包与集成检查。
- 未进行个人截图采集、Android 真机验证或真实模型调用。日志仍不写入截图、文件正文、OCR、令牌、模型对话或任意异常原文。
- 产品版本 0.0.23，Android versionCode 34，沿用发布签名与用户数据目录；macOS 使用仓库配置的签名模式。
