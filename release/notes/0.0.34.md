# Mote 0.0.34

修复 Issue #2 中的客户端崩溃，并完善问答、随手记、用量统计、资料浏览和导出。

- Android 采集记录页不再因空子视图崩溃；统一动态弹窗样式，点击输入框外收起键盘。文件来源可设置 1–512 MiB 单文件上限，新的文件来源默认归档原件，包含常用录音、图片及文档类型。
- macOS 和 Android 增加中央问答与附件随手记入口。问答在中央继续运行，离开页面不取消；需要终止时可点击停止。已有对话支持删除。
- 问答可临时切换已保存的 Provider 连接及其模型，不改变默认模型或复制密钥。模型目录使用对应连接凭据；Codex 保留原生 Max 推理强度。
- 用量明细增加分页和每页条数；增加 Provider 分组、Provider 到模型钻取、每日趋势柱状图及日期筛选，分页不改变总量统计。
- 随手记移除心情输入，支持图片、音频附件与文字。附件通过现有中央文件上传、OCR / 转写流程处理；客户端选择已有音频文件上传。
- Web、Mac、Android 资料记录增加列表 / 缩略图切换，补充记录状态与大小。中央及客户端提供元数据或资料导出入口，包含中央导入文档的原件。
- 移除 Android / Mac 本地内容加密开关及批量转换入口，新内容明文保存；兼容读取旧密文，访问令牌保护保留。
- Mac 新增可选通知中心采集，并通过已有通知事件协议上报。Android 沿用通知监听与中央处理。
- Release 新增独立的 **Mote Collector Dev** Mac ZIP，独立 bundle ID，默认 dev 数据目录，提供 DevTools 菜单及 SHA-256 校验。

验收使用生成资料：711 项工作区自动测试、桌面 / Web 界面回归、Android 模拟器导航与采集记录回归、单元测试和 lint。另使用本地 Codex App Server 的 **gpt-5.6-luna / max** 完成生成笔记检索和引用验证。

使用边界：Mac 通知仅能读取系统通过辅助功能公开的可见通知，需要主动启用和授权，不能保证获取隐藏或已消失通知。客户端附件入口需要连接中央并使用所有者权限；音频转写及图片 OCR 需要启用相应中央处理器。元数据导出包含文字记录及描述，不含二进制原件；资料导出追加原件，超过 HTTP 导出额度应使用离线备份。Mac 开发版单独下载更新，不参与正式版自动升级。本次未做 Android 物理设备采集或 Mac 通知真机覆盖率验收，未使用个人截图。
